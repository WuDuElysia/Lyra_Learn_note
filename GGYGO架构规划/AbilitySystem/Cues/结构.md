## 职责与依赖

`UGGYGOGameplayCueNotify_HitImpact : UGameplayCueNotify_Burst` 消费一次 Cue 载荷，验证表现输入并选择表面粒子/声音。配置和播放属于 AbilitySystem 的反馈子模块；本类不重新查询碰撞、不去重命中、不应用伤害 GE，也不维护能力或移动状态。

| 提供者 / 所有者 | 输入、接口与产物 | 接缝 |
| --- | --- | --- |
| [[Combat/结构\|Combat / MeleeTrace]] | `OnMeleeHit(HitActor, HitResult)` 提供窗口内去重命中；查询请求 PhysicalMaterial | 碰撞事实与窗口归 Combat；Cue 只消费载荷。 |
| [[Physics/结构\|Physics]] | `UGGYGOPhysicalMaterialWithTags::Tags` 描述表面；普通 `UPhysicalMaterial` 没有项目 Tags | 材质提供语义数据，不拥有 Cue 或伤害执行。 |
| [[AbilitySystem/结构\|GA / GAS]] | `BuildHitEffectPayload(TargetASC, GE, Level, Hit, Origin)` 统一 Context、可选 Spec、表面/目标 Tag 与 Cue 参数 | 命中 Cue 消费同一 HitResult 与 `AggregatedTargetTags`；伤害仍走 GA → GE → Execution → AttributeSet。 |
| HitImpact Cue / BP 资产 | 位置模式、表面策略、`SurfaceEffects` / `DefaultEffect` 与继承的 Burst 配置 | 资产表达表现选择；C++ 维护执行入口、校验与调用期资源。 |
| [[Audio/结构\|Audio]] / 引擎播放 API | 提供声音资源；Cue 在合法位置调用 `UGameplayStatics::PlaySoundAtLocation` | 本类不增加另一音频时序链、缓存或资源加载器。 |

数据传递方向为载荷提供者 → Cue 输入 → 表现 API。GA 读取 Physics 材质语义；Cue 继承引擎 Burst 并调用表现 API，不向 Combat/Physics 写回状态；Physics 不反向依赖 Cue。图中表示的是职责、继承与数据/接口关系，执行时序见流程图。

## 类与数据

| 类 / 数据 | 关键字段或接口 | 所有权与生命周期 |
| --- | --- | --- |
| `UGGYGOGameplayCueNotify_HitImpact` | `HandleGameplayCue`、`OnExecute_Implementation`、`ResolveImpactPresentation`；私有 `ValidateInheritedPlacement` / `ReportFailure` | 持有资产配置和有限诊断标记；没有 Tick、计时器、命中记录或第二 Cue 调度器。 |
| `FGGYGOHitImpactEffect` | `SurfaceTag`、`ImpactEffect: UNiagaraSystem`、`ImpactSound: USoundBase` | Cue 持有 `SurfaceEffects` 数组与一个 `DefaultEffect`；粒子和声音均可作为明确的可选输出。 |
| `FGGYGOHitImpactResolveResult` | `Failure`、有限 `Location` / `Normal`、只读借用 `Effect`、`Detail`；`IsSuccess()` | 按值结果描述本次输入；不是权威命中状态。成功须 `Failure=None` 且 Effect 非空。 |
| 引擎 `UGameplayCueNotify_Burst` | `DefaultSpawnCondition`、`DefaultPlacementInfo`、`BurstEffects`、`OnBurst` | 继续负责其原生反馈与条件；本类继承并调用 Super，不另建父类播放器。 |
| OnExecute 调用期数据 | 选定位置/旋转、参数副本；所选粒子/声音的 `TStrongObjectPtr`；原 Target/World 的 `TWeakObjectPtr` | 不跨调用存入成员。强引用在退出时释放；弱身份不延长 Actor/World 生命周期。 |

`ResolveImpactPresentation` 是只读 C++ 接口，没有 BlueprintCallable 包装。资产通过 EditDefaultsOnly / BlueprintReadOnly 字段配置正常模式。解析结果中的 Effect 指针借用当前 Cue 配置，调用方必须在外调前复制所需资源并结束借用；不能保存数组元素引用跨 Super、K2 或 OnBurst 重入。

## 关键接口契约

| 接口 / 调用者 | 关键输入 | 作用与输出 |
| --- | --- | --- |
| Cue 路由 → `HandleGameplayCue(Target, EventType, Parameters)` | 有效原 Target、其 World、原 Cue 参数 | 消费Cue事件及原载荷；Executed须满足表现输入契约，其它事件使用引擎原路由。无效输入不提供反馈。 |
| 原生直接调用 / 原生 OnExecute 路由 → `OnExecute_Implementation(Target, Parameters) const` | 同一输入契约；不能依赖已经经过 Handle | 同步表现执行接口，直接调用同样要求有效输入；返回值描述同步派发，不证明媒体可见或网络到达。 |
| 两入口 → `ResolveImpactPresentation(Target, Parameters) const` | 资产模式所选依赖、`AggregatedTargetTags`、父类空间配置 | 不播放、不写 Context、不修改权威状态。返回明确失败原因或有限位置/法线与所选 Effect 借用指针；失败不保留 Effect 指针。 |
| Resolve → `ValidateInheritedPlacement` | 选定参数副本、继承的已配置空间效果与 Placement | 只读检查原生落点是否兼容；不提前执行 `ShouldSpawn`。冲突为 `InheritedPlacementConflict`；反射字段缺失/类型变化为 `InheritedConfigurationUnavailable`。 |
| 执行入口 → `ReportFailure` | Cue 资产路径、Target、位置/无表面模式、目标 Tags、原因与详情 | 当前日志类别为 `LogGGYGOAbilitySystem`。每个 Cue 对象生命周期每种原因最多一条；标记只用于限频，不保存目标或计时器。 |

蓝图覆写 `OnExecute` 时，父实现提供本类原生表面反馈；蓝图自行编排的播放路径归相应资产。两原生入口的调用和分支见 [[GGYGO_流程_HitImpact.canvas|执行流程]]。

## Blueprint 默认值与正常模式

| 配置 | 默认值 | 必需输入 / 可见行为 |
| --- | --- | --- |
| `LocationMode` | `HitResult` | 必须有原 Context 的 HitResult，使用 ImpactPoint / ImpactNormal；缺失明确拒绝，不改用 Target。 |
| `LocationMode=ParametersLocation` | 资产显式选择 | 使用传入 Location / Normal；位置为世界原点仍合法。 |
| `LocationMode=TargetCenter` | 资产显式选择 | 使用有效 Target 的实际 ActorLocation，法线来自 Parameters.Normal。 |
| `NoSurfacePolicy` | `Generic` | 没有 SurfaceType Tag 时正常选择 DefaultEffect；普通材质无项目 Tags 可走此模式。 |
| `NoSurfacePolicy=Reject` | 资产显式选择 | 无表面 Tag 时返回 MissingSurfaceTag。 |
| `bAllowUnmatchedSurfaceGeneric` | false | 有 SurfaceType Tag 却没有映射时返回 UnmatchedSurfaceTag；只有明确启用才允许 DefaultEffect。 |
| `SurfaceEffects` | 资产数组 | 按原顺序作层级匹配，首个匹配项生效；更具体 Tag 排在宽泛 Tag 前。遍历到无效/非 SurfaceType 映射项时拒绝。 |

所有模式都要求有效 Target/World，以及实际所选位置/法线有限；不按零坐标判断有无输入，也不要求 bBlockingHit。零法线是当前允许的有限输入。所选非空粒子/声音引用失效会拒绝；可选输出为空不会暗中换成另一资产。

`SurfaceType` 根必须已注册，否则返回 InvalidSurfaceConfiguration。`DefaultEffect` 的 SurfaceTag 不参与通用模式匹配。普通材质的无 Tag 情况与已有表面 Tag 的漏映射是两个分支，不能统称“默认回落”。

## 父类定位与反馈边界

已配置的父类空间输出包括粒子、声音、世界空间 CameraShake / CameraLensEffect / ForceFeedback，以及 Decal。检查默认 Placement 和每项 Override、Socket/Attach、旋转/缩放有限性及附着后的落点。非空间反馈仍由原生 Burst 执行。预检不消费随机概率或条件缓存；资源已配置就检查布局，即使本次原生 SpawnCondition 最终不播放。

本机原生定位优先使用 BlockingHit，其次非零 Parameters.Location，最后 TargetComponent 的 Socket。因而合法原点 Overlap，或显式 Parameters/Target 模式仍携带另一 BlockingHit 时，父类可能得到不同落点。当前实现明确拒绝整次 Executed 反馈，并说明配置冲突；不把命中本身判非法、不伪造 BlockingHit、不静默跳过 Super。冲突配置不提供自动定位适配。

`DefaultSpawnCondition` 仍只控制父类 Burst / OnBurst 路径，不额外控制本类 SurfaceEffects 的粒子/声音。Burst 原生 OnExecute 即使播放也固定返回 false，本类不将其解释为播放失败或空配置。

回调后原 Target/World 或所选资源失效，本类诊断并中止剩余自身反馈；已经发生的父类/蓝图反馈不回滚。OnExecute 返回 true 仅表示校验通过并完成同步派发，不证明粒子可见、声音可听或网络到达。
