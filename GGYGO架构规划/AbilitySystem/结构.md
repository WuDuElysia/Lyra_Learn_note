## 精确Montage播放归属（K3：已编译，派生与生产未闭合）

UE的Local／Rep／GA字段和Animation的Guard仍分别是原权威。ASC新增的唯一`MontagePlaybackProvenance`仅认证一次完整原生Local写入：不透明Handle的私有不可变Proof记录原ASC、GA／Spec／PredictionKey、Montage及Guard生命周期／非复用CallId／CreatedInstanceId；ASC当前资源持有原ActorInfo allocation与实际来源快照。8位Local PlayInstanceId仅核对一致性，不作唯一播放身份。

| 调用方 → 实际接口 | 输入、作用与输出／边界 |
| --- | --- |
| Task::Activate → `TryPlayMontageWithOwnership(Ability, ActivationInfo, Montage, PlayRate, StartSection, StartTimeSeconds, IsOriginalCallerCurrent)` | 必需同步纯原调用方查询。复用完整限定Super／GuardScope，Scope封存并退出后，Accepted且原源／GA／Local一致才返回Succeeded及新Playback；失败保留Guard／Duration历史，无有效Handle，非Guard不走播放兜底。Task已消费单一栈Result；失败诊断并结束自身，不猜实例或改用旧Play。 |
| 原资源持有者 → `CheckMontagePlaybackOwnership(Original) const` | 纯核对原Proof／当前provenance、ActorInfo来源、GA激活来源、Guard生命周期及实际Local／GA字段；不依赖Montage仍活动或GA IsActive，停止不会凭空抹去原清理资格。无活动实例不是“可以清任意新播放”。 |
| GA 原终止捕获 → `CaptureMontagePlaybackOwnership(OriginalAbility, OriginalSpecHandle, OriginalActivationInfo) const` | 首次终止只取该原GA的既有认证播放。NoOwnedPlayback是正常无认证播放，其他失败明确拒绝，不签Handle或接管Task停止。Combo/Boss已消费原任务与Context清理；正式资产与原严格重入边界仍未闭合。 |
| 混出／原GA收尾 → `TryClearMontageAnimatingAbility(Original)` | 先Check原Handle；成功仅限定基类GA setter写CurrentMontage=null并清Local AnimatingAbility，再退休原证明。避免virtual业务setter重入后误清后继；不Stop、不延迟到技能结束，调用时机仍归原消费者。 |

同GA同Montage接续A→B时，B证明替换A；B停止后仍只允许B的原清空，A晚回调不能借相同资产认领B。完整原生Init（含同端点）实际重置Local，写入前退休；Clear同理。Refresh前后仅按真实来源核对，无Local／来源改变则保持播放证明，不用发布Context修订强制延期。原生复制、模拟、动态Montage及旧Clear在实际可截获入口核对／退休；拒绝、无写入失败或Superseded外层不凭空清除已接受后继。

组件只持一份当前 provenance，替换/真实写入/精确Clear/OnUnregister释放；Handle不强持ActorInfo或维持播放。未观察Owner ABA与qualified native绕行不作完整保障，不改UE/GAS。ASC/Task及GA原捕获已编译，Combo/Boss已迁原资源消费者。Gate79有限正常/故障链不关闭K3原严格重入、正式AnimClass/资产/网络及任意捕获析构重入。

依赖为ASC→[[Animation/结构|Animation Guard]]，无反向GAS依赖；结构和关键调用见 [[GGYGO_结构_AbilitySystem.canvas|结构图]]、[[GGYGO_流程_AbilitySystem.canvas|精确播放支线]]。阶段顺序见 [[AbilitySystem/计划_AbilitySystem#当前精确Montage增量（K3）|迁移计划]]。

## Task原实例与资源消费（已编译，专项与迁移边界保留）

`Activate`捕原ActorInfo allocation与Ability／ASC／Owner／Avatar／Mesh／Anim来源，先注册自身取消及事件订阅，再调用ASC `TryPlayMontageWithOwnership`。同步纯查询只读原关联和Task存活；ASC／Guard各自认证原生写入与实例。Task不再维护全局播放尝试表、token或“唯一新实例”扫描，也不签Handle。

| Task接口／资源 | 输入、作用、输出及清理责任 |
| --- | --- |
| `FNativeCallbacks` → `RegisterNativeCallbacks(Callbacks)`／`UnregisterNativeCallbacks(Token)` | 包含Completed、BlendOut、Interrupted、Cancelled、EventReceived五个可选原native单播，Tag/Data签名保持。只在原native AwaitingActivation、Ready前接受非空且无既有注册的包；空包/重复/迟到明确拒绝并诊断，不替换原包。返回FDelegateHandle，解除只匹配原token，先脱包再释放；捕获构造/析构重入后不覆盖后继注册。调用方按值捕原Activation、弱GA/弱原Task；Task只持订阅资源，不签GA身份或授Ready/后继结束权。 |
| private `DispatchOriginalCallback` | 复制载荷并共享不可变原包快照→native执行→释放快照且捕获析构返回→重取弱原Task，核弱Ability/ASC及本路径资格→既有BP。Event核IsNotifyValid；BlendOut/Interrupted/Completed核原Guard、ActorInfo及Task资格，Completed不Check当前ASC归属或活动实例。Cancelled允许尚未安装ActorInfo/Guard的启动失败，仍核同原Task及ShouldBroadcast。无native注册时普通BP保持；BP外调返回后的旧收尾只重取弱原Task，不写后继。 |
| `PlayMontageAndWaitForEvent`／`ResolvePlayRate` | BP工厂／委托与速率语义保持；TaskRate只含一次全局缩放，EffectiveRate再乘Montage RateScale。窗口／组合仍归Montage和GA。 |
| `Activate` → 原Result | 成功且原Task／Ability／ActorInfo有效才保存Handle／Guard，按CreatedInstanceId重取原实例，直接绑定带原Guard载荷的委托，获取自身缩放lease。最后`SetWaitingOnAvatar`外调后无成员写。 |
| private `FInFlightMontagePlayCleanup` | 只是一份与调用栈共持的原停止义务；原生外调中Cancel／Destroy先记录，返回后凭Result.Guard清原实例。已结束Task不安装资源；不是播放状态、进度或GA生命周期权威。 |
| `IsNotifyValid` → EventReceived | 原ActorInfo及Task有效、未混出、精确实例播放且ASC Check原Handle成功才接事件；Montage／instance ID过滤保持。复制Payload后广播，监听随自身销毁清理。 |
| `OnMontageBlendingOutForInstance` | 匹配原Guard → 释放自身缩放 → `TryClearMontageAnimatingAbility(OriginalPlayback)`。A晚回调不能清B；保留原混出清空时机，不Stop／延期。有效原上下文才发布原BlendOut／Interrupted事实。 |
| `OnMontageEndedForInstance` → OnCompleted | 原Guard委托身份／生命周期、原ActorInfo及AbilityTask资格成立且非Interrupted，发布原自然结束事实。**不Check当前ASC播放，不要求原实例仍活动或存在**，正常混出已退休归属不会吞Completed。调用方须另证原GA生命周期，不能据此End后继。 |
| `ExternalCancel`／`OnAbilityCancelled`／`FailAndEndTask`／`OnDestroy` | 三取消入口在回调前标记bCancellationRequested，native/BP各至多一次；启动失败不硬核尚未建立的ActorInfo/Guard。OnDestroy先关闭Task、脱native包/token，再撤自身Event/Cancel句柄及精确实例委托、释放原Character/token缩放；旧cleanup及Super返回后释放脱出的包，捕获析构后无Task访问。按明确Stop策略处理原实例，栈仍共持在途停止义务；普通EndTask不擅自改成AbilityEnded。 |

停止按原Guard生命周期＋CreatedInstanceId重取。只有ASC认证原Handle且资产当前活动实例正是原ID，才用`CurrentMontageStop`保留GAS复制更新；否则仅释放有效的**精确原本地实例**，不Clear新GA／ASC、不换Avatar找资源。Guard失效明确诊断，不猜后继；原实例已释放无需替代清理。外调返回时Task仍活但原ActorInfo失效，同样诊断并清原实例。

N0已编译，Combo/Boss实际在Ready前注册FNativeCallbacks，闭包捕固定Original、原Task与所持资源；清理先脱自己的token，再TaskOwnerEnded释放自身原播放/监听/缩放。Gate79正常Combo纠正及Boss Mesh/Cleanup/原Completed链0E0W，RuntimeHit资源断言通过；不等于完整Boss Montage/命中、native捕获析构重入、旧nonGuard夹具或正式资产/网络验收。Task依赖ASC与[[Animation/结构|Guard]]只读身份，无反向依赖、第二能力/播放状态或帧调度。
