## 2. Profile数据与EvaluateInterval契约

Profile保存 `SpeedCurve`（cm/s）、`DirectionXCurve/DirectionYCurve`（UE局部X前、Y右）、`YawCurve`（累计角度）、`Duration`、`bLoop`、`SourceAssetIdentifier`、`SourceFingerprint`。当前求值不读取AnimInstance的Cfg/Pos/Dist，也不由源动画的本地播放位置决定时间。

接口为：

```cpp
bool EvaluateInterval(float StartTime, float EndTime,
    FGGYGOLocomotionCurveSample& OutSample, FString* OutError = nullptr) const;
```

- 入口先 `OutSample.Reset()`，提供OutError时先清空。要求t0/t1有限、非负且t1≥t0；每次调用都执行Profile校验，包括有效Duration、四曲线必需keys、key顺序/有限值、原生模式与有效权重等。
- **非循环**：t0、t1分别Clamp到[0, Duration]；Speed/Direction取Clamp后的t1，YawDelta取区间两端Yaw差，YawTotal取t1的Yaw值。
- **循环**：Speed/Direction按t1相位取值；Yaw按非负无界输入时间解绕。若D为Duration，q为周期数、p为相位，则 `Yaw(t)=q*(Yaw(D)-Yaw(0))+Yaw(p)`；YawDelta为解绕后的Yaw(t1)−Yaw(t0)，跨周期不会靠动画帧基线猜测回绕。
- **成功**：全部结果有限，Speed非负；正Speed必须有有效归一化方向。全部检查通过后一次提交完整 `FGGYGOLocomotionCurveSample` 并返回true；OutError若提供保持为空。样本包含Speed、Direction、Velocity、DirectionAngle、YawTotal/Delta、ClipLength=Duration、loop/authored-direction/source标志，`bHasCurveSource=true`。合法零Speed仍成功，允许零方向。`PositionDelta` 保持默认且 `bHasPositionDelta=false`，本接口不从Pos曲线积分位移。
- **失败**：返回false，OutSample保持完整Reset；OutError若提供则包含失败字段/曲线与原因。Profile自身不记录日志，也不以默认速度、方向或另一Profile把失败变成成功。CMC消费bool与原错误：普通Before拒绝原执行请求，CurveRMS通过原Origin报告；成功后才提交候选。当前机制与动态／网络未验边界见第6节。

## 3. CMC移动模拟与WalkRun共相位

本地UE5.8的权威/自主移动路径在 `PerformMovement` 中先调用 `UpdateCharacterStateBeforeMovement`，随后准备原生RootMotion并进入物理。求值与时间推进属于移动模拟的每次调用，不能写成“一次渲染帧在TickComponent采样”。

1. Before先处理原CurveRMS重放上下文，见第5节。非重放路径清理结束Action；独立合法动作／RootMotion走原权限路径。未接受配置、来源失败或无执行请求清自有Locomotion源并明确地面准入，保留重力／独立动作。
2. 非Proxy → `TryUpdateLocomotion`。`CaptureLocomotionCandidate`复制16个既有字段到栈内；候选ResolveGait、混合和选择保留Start/Stop/TurnBack拓扑，无持久第二状态。`IsCurrentMotionFinished(candidate,out,error)`区分合法完成与无效依赖。
3. 普通单段由 `EvaluateLocomotionProfile` 校验有限非负Delta，并取既有 `min(Delta, MaxClampedDelta)`，再调用 `GGYGOLocomotionEvaluation::EvaluateSingleInterval(Profile,t0,t1,Scale,out,error)`。成功写候选段时间／样本；失败不推进。Profile的区间Clamp与CMC的普通Delta限制分别保留。
4. 普通WalkRun由 `EvaluateWalkRunInterval(Walk,Run,phase,acceptedDt,alpha,Scale,out,error)` 求值，双侧必需（含alpha端点）；共相位乘各自Duration，按混合周期返回未回绕末相位。全部求值／插值／缩放成功后，CMC才回绕并写候选；缺一侧不替代。数学层不持有时钟／状态／缓存／日志。
5. 曲线Stop／TurnBack进入 `StageLocomotionCurveRootMotion`：校验原请求，暂存原Input及候选、挂载原Origin的Source，等待实际Prepare，不先求整帧Profile区间。**同段Completed Origin例外**：原物理资源已自然完成，Stage用普通CMC求值／提交完成剩余clip语义；即使后续速度重新为正，也不重挂同一物理执行。这是明确生命周期分支，不是错误后的业务兜底。
6. 普通成功 `CommitLocomotionCandidate` 在Before写回段、时间、共相位、混合、转身与样本；只有没有待Prepare Input时才继续普通刹停／转身源更新。曲线RMS在原生Prepare里请求CMC按实际区间求值，正常模拟由CMC一次Consume；重放Prepare只形成结果，由Before一次Consume。两条提交路径都不等于完整物理事务已经验收。
7. 普通失败 `RejectLocomotionEvaluation(capturedSerial,error)` 终止原非零请求、清自有源；0号仅拒绝不补号。RMS失败使用原Origin校验后报告，只能失败仍匹配的原请求；过期Source只退自身，不能清后继请求。失败不提交候选、不自动重试，也不转fixed。

Proxy不在上述普通Before路径独立推进。现有来源／请求机制与本地原RMS实现不能证明生产Hero／ABP／Run、Cold／Rearm／StartProof整条真实输入接线或完整网络验收；这些边界继续分开记录。

## 4. 速度、Yaw与原生RMS消费

C26的三个getter源码已冻结；统筹第35次完整Editor构建实际Succeeded，并运行真实消费者专项 `GGYGO.Movement.Locomotion.AuthorityAndMapping`，结果Success / 0 Error / 0 Warning / entries空。**有限覆盖合法零速度、极小正速度、零Scale的资格与GetMaxSpeed/ForceWalk，以及显式fixed模式；失败/溢出只证明资格拒绝，完整失败传播未关闭。** 原“未编译/专项”是第35次门禁前的历史状态，不能继续作为当前结论。

| 消费接口 | 当前源码行为 |
| --- | --- |
| `IsCurveDrivingSpeed` | 活动Action不参与；要求已接受MovementSet、启用曲线、样本bHasCurveSource，且Speed、RootMotionScale及乘积均有限非负。资格不以正速度阈值决定。 |
| `GetScaledCurveSpeed` | 有资格时返回真实Speed×Scale，无资格时返回0。调用方须结合资格判断区分“合法零值”和“没有合格来源”。 |
| `GetMaxSpeed` | 被移动Tag禁止则0，非地面交Super，地面未接受配置则0；合格曲线返回真实缩放速度，ForceWalk请求仅按配置Walk上限限制。固定步态只在显式fixed模式；曲线无资格、失败／无来源地面门禁返回0，非地面交原生。 |
| `FGGYGOLocomotionCurveSample::HasUsableSpeed` | 仍为“有来源且Speed大于KINDA_SMALL_NUMBER”的幅值判断，用于刹停/RMS。它不是Profile成功资格，合法零速/极小正速/零Scale不能因此变成另一速度来源。 |
| `PhysicsRotation` | 非SimulatedProxy的转身曲线阶段消费YawDelta，以 `MoveUpdatedComponent` 带扫掠转角；活动Action等先走各自权限/准入规则。 |

CMC通过 `StageLocomotionCurveRootMotion` 暂存Input，再用 `ApplyCurveRootMotionSource` 安装Source；只复用仍活动且持有同一原Origin的自有Source。同名／LocalID不是来源证明，Clone复制同一Origin引用仍须校验原关系。Origin记录原Owner、Binding、InputRequest、非零ExecutionRequestSerial、MovementSet、MotionType／Sequence及固定时间锚点／BaseYaw／Scale／结束策略；Input持有该move的起始候选、加速度和输入／地面事实及MovementTickTime，不另建准入状态机。`BaseYaw` 固定：转身取入口Yaw，刹停取首次安装组件朝向，不每帧叠加已转后的组件Yaw。

原生调用RMS `PrepareRootMotion(SimulationTime, MovementTickTime, Character, CMC)` 后，RMS请求原CMC的 `PrepareLocomotionCurveRootMotion`。要求原Owner和实际角色／CMC匹配，原Input／Source／请求／配置关系仍有效，SimulationTime有限且≥0、MovementTickTime有限且>0并匹配原Input。时间映射为：

```text
NativeStart = Source.GetTime()
NativeEnd   = NativeStart + SimulationTime
MotionStart = Origin.MotionTimeOrigin + (NativeStart - Origin.SourceTimeOrigin)
MotionEnd   = MotionStart + SimulationTime
```

CMC以真实Motion区间调用无状态单区间数学，检查Profile结果、Scale、追帧比例及合成速度；不把partial／zero／catchup补成整帧Delta，也不套普通求值的MaxClampedDelta。Profile自身非循环Clamp仍保留。Prepared携带原Input、有界候选State、原生／Motion两端、实际sim／tick、样本、OverrideVelocity和结果；正常模拟由原CMC `ConsumeLocomotionCurvePrepared` 对同一引用只提交一次，重放路径见第5节。它们是原执行资源的输入／派生结果，不是与CMC竞争的时钟或请求权威。

正常曲线执行的世界速度为固定BaseYaw旋转后的缩放端点Velocity，再乘 `SimulationTime / MovementTickTime`；RMS只消费返回的Prepared，写RootMotionParams translation并 `SetTime(NativeEnd)`，不读取当前CurveMotion或自行求值Profile。该translation表示速度，**不是对区间精确积分出的位移**。挂载发生在Before，是否当帧Prepare仍受引擎早期Source快照及clientUpdating／serverIgnore等原生门禁控制；跳过准备不伪造成功区间。

刹停Source的 `bEndOnZeroSpeed=true`，在真实准备／结束条件满足时Finished并保留退场帧动量；转身Source为false，低／零速可留场输出零水平速度，退出由转身语义控制。离地也按原生生命周期Finished并保留动量，Z不参与Override，后续原生清理摘除。同Completed Origin的剩余clip普通分支不重新发行物理执行。当前失败只报告仍有效的原请求；Stale／UnsupportedOrigin退源并明确诊断，不以默认前向、固定速度或另一个来源成功。自然完成与安全清理不是失败业务兜底。

## 5. 预测恢复与Animation只读Capture

`FSavedMove_GGYGO::SetMoveFor` 保存步态／输入请求、运动类型、Stop类型、`LocomotionMotionTime`、`WalkRunCyclePhase`、`WalkRunBlendAlpha`、Sequence及转身相位／elapsed／入口Yaw等普通起始基线。`PostUpdate` 在原生更新后另记录本move的 `LastLocomotionCurvePrepared`，以及它的原Input或尚待Prepare的Input，因此也覆盖本move首次挂源但准备被跳过的记录；有原Input时禁止合并。Prepared内含样本和有界候选，不能继续统称“不保存CurveMotion结果”，也不能把它当独立当前样本或准入权威。

`PrepMoveFor` **先** `BeginLocomotionCurveReplay` 安装原Input／Prepared及该move的原Source组上下文，再调用native Super；Super可能已经准备SavedRootMotion。原CMC校验Origin、原tick、配置和组内Source，重放Prepare只形成结果，不在此提交；随后 `FinishLocomotionCurveReplayPreparation` 清临时组指针。进入Before时，只一次消费匹配的已有或Super实际生成的原Prepared；没有可消费区间就Reset CurveMotion，不用整帧dt猜测原Prepare区间。普通非RMS重演仍恢复起始基线再求值；当前FAILED不能被旧结果恢复为准入，旧Origin不能失败后继请求。SavedMove `Clear` 清本move Input／Prepared，`EndLocomotionCurveReplay` 清重放上下文；源退场按CMC／原生各自生命周期清理，残留Clone／SavedMove引用不构成当前准入。

校正时 `ClientHandleMoveResponse` 接受服务端语义／时间基线并Reset CurveMotion；`ClientUpdatePositionAfterServerUpdate` 在原生重演窗口置 `bReplayLocomotionFromAuthority`，使PrepMoveFor不再恢复旧普通预测基线，重演出口还检查原请求失败／后继请求关系并清上下文和标志。服务端自己选择Profile／推进时间；MoveData只传运动／Stop／TurnPhase／Sequence语义hint，不传Origin／Input／Prepared。RMS `NetSerialize` 保留原生wire字段与BaseYaw／Scale／策略，加载时清本地Origin／Prepared；外来Origin未重建、当前不支持导入。上述本地保护不证明原Prepared与新权威基线的完整协调，也不证明authority／proxy匹配、校正或网络动态验收。

Animation的 `NativeUpdateAnimation` 调 `Capture(OutState, OutDebug, Pawn)`，输出先Reset，只读取当前Pawn/CMC/ASC。StateFrame交付步态、输入、WalkRunBlendAlpha、Stop与转身等语义；CurveMotion的速度/方向/角度读取用于DebugFrame。ABP选择姿态与过渡，Animation无Profile播放时钟或胶囊位移权威。

## 8. Editor单Profile作者与保存边界

`UGGYGOLocomotionMotionProfileAuthorLibrary::CreateOrInspectProfile`接收Source、精确源对象路径、成功且有序的四曲线完整R3 Snapshot、目标对象路径、源Duration(double)及显式Loop。固定曲线顺序为Speed／DirX／DirY／Yaw；不猜角色、动作、MovementSet或正式PawnData。

1. 调R1重新读取完整`FFloatCurve`与binary64时长，和显式Snapshot逐字段比较；曲线Name／Flags、DefaultValue／前后外推、每键六float与三个模式均须一致。浮点比较保留原始位，包括负零和未启用权重字段。源时长须有限、正、在float范围内，转换后存入Profile的实际float Duration。
2. 先构造临时候选，四条`EditorCurveData = Source.FloatCurve`整曲线赋值，ExternalCurve置空；不SetKeys、AutoTangents或重新拟合。`ValidateProfile`与目标完整回读全部通过后，才查看正式目标。
3. 既有目标要求正确类型、精确路径、干净包及全部存储字段一致；只读返回`ExistingMatched`，差异明确Failed，不覆盖。磁盘包存在却目标不可读、已加载包缺目标，同样拒绝，不把失败当成“新建”。
4. 缺失目标以明确路径建新包；CreatePackage返回后复核原包身份、dirty状态、外来内容、源契约及目标名占用，再NewObject。对象建立及MarkPackageDirty返回后再次核对源、目标、包内容与完整回读；成功只返回`CreatedUnsaved`。
5. `Failed`不返回Profile或部分回读，Error含模块、源、目标和原因。清理只处理本调用创建的Profile；新包状态无法证明独占时保留并说明，回调rooted或含外来子对象的Profile也保留诊断，不清外部dirty或回滚外来对象。

`FGGYGOLocomotionProfileReadback`是真实目标字段，不伪造Profile没有的源Name／Flags；这两项进入来源指纹。`SourceFingerprint`为`locomotion-richcurve-v1:blake3-256:<64位小写十六进制>`：规范字节流依次写版本域、实际源路径、duration binary64位、四曲线数量；每曲线写Name、Flags、DefaultValue位、前／后外推、key数量及有序九字段。整数采用little-endian uint32／uint64，UTF-8采用uint32字节长度且无终止符；六float采用uint32位模式、三模式采用uint32。Loop另作明确配置比较，不纳入源内容指纹。该指纹不是整个uasset或磁盘全字节证明，也不是旧Python time/value摘要。
