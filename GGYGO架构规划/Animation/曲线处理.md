# 动画曲线：当前实现与目标边界

> 结构图：[[GGYGO_结构_动画曲线.canvas]] · 采样流程：[[GGYGO_流程_动画曲线处理.canvas]] · [[Animation/结构|返回 Animation 结构]]

## 曲线契约

ZZZ 移动动画是 in-place；离线烘焙的 `RootMotion_Speed` 直接给当前速度（cm/s），`RootMotion_PosX/PosY` 是从动画段起点累计的局部位移，`RootMotion_Dist` 是单调不减的累计路程，`RootMotion_Yaw` 是已解 ±180° 折叠的累计转角，`RootMotion_DirX/DirY` 是烘焙方向。`Cfg_ClipLength` 兼作“该动画有曲线”的标记，`Cfg_LoopTime` 表示循环。位置与方向使用 UE 的 X 前、Y 右轴序，且以动画段入口朝向为基准。

## 一帧如何处理

1. 当前代码在 `UGGYGOCharacterMovementComponent::TickComponent` 调 `SampleAnimCurves(dt)`，再调 `Super::TickComponent`，让本帧 CMC 物理使用本帧采样值。`UpdateCharacterStateBeforeMovement` 可能因 sub-stepping 在同帧多次执行，因此不能在那里更新持有跨帧基线的采样器。
2. `FGGYGOAnimCurveSampler::Sample` 通过 `UAnimInstance::GetCurveValue` 读取曲线，先把非有限值归零、速度/路程负值钳零。`Cfg_ClipLength` 或旧批次的速度、方向、路程信号可建立 `bHasCurveSource`，区分“曲线存在但速度为 0”和“无曲线”。
3. 没有基线、dt 无效，或 `RootMotion_Dist` 比上一帧回退（动画切段/循环回绕）时，只更新基线，不输出伪位移。正常帧对 PosX/PosY、Yaw 作差分；Speed 直接取曲线值。方向优先用烘焙的 DirX/DirY，缺失才由位移差分求出，避免低速方向抖动。
4. 输出 `FGGYGOAnimCurveMotion`：Speed、PositionDelta、Velocity、Direction、YawDeltaDegrees、YawTotalDegrees、ClipLength 和有效性标志。没有 AnimInstance 时，CMC 清当前值并重置基线，避免 Mesh 恢复后跳出大位移。

## 谁消费这些结果

- `GetMaxSpeed`：地面移动且配置 `bUseCurveDrivenSpeed`、有可用速度时取 `Speed * RootMotionScale`；否则取 MovementSet 的步态速度。非本地端拿不到曲线时放宽到 `MaxCurveDrivenSpeed` 上界，减少预测校正；这并不等于两端曲线状态相同。
- 转身期间 `PhysicsRotation` 用 `YawDeltaDegrees` 经 `MoveUpdatedComponent` 带扫掠转角；`FRootMotionSource_GGYGOCurve` 用进入该段时的 `BaseYaw` 把 Direction 和 Speed 变成世界速度，不能用每帧当前朝向，否则直线位移会扭成弧线。
- 刹停 Source 在速度归零时结束；转身 Source 在零速度帧仍留场输出零水平速度，生命周期由转身相位机控制。Source 离地退场时保留本帧动量、忽略 Z Override，避免重力被抹掉。`SavedMove` 保存曲线运动快照供重演。

## 目标拆环

当前 CMC 仍反向读取 AnimInstance 曲线，这依赖本地动画求值，在 Dedicated Server 和重演时难保证同一份输入。计划让普通走跑由 CMC/MovementSet 决定速度，动画跟随；转身/刹停的运动节奏烘焙成 C++ 可独立采样的 MotionProfile，CMC 保存 ProfileId、PlaybackTime 与入口变换。该目标尚未实现，不能把 MotionProfile 画成当前类。详见 [[计划_动画与表现层#7. 曲线与权威移动的新边界]]。
