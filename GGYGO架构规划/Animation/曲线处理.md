### 来源发布、不可用状态与退休

- GT 原 Initialize／Update 仅允许当前 Character 主 Mesh 的原 Producer 发布。ZZZ 解析五个单段 routes 与 `walkRun`；Loops 从实际 BS 样本解析，不要求 AnimSet 再存 WalkLoop／RunLoop 表项。
- Identity 为 Producer／Character／Mesh 弱身份＋LifecycleGeneration／ConfigurationGeneration。配置代次跨 reinitialize 单调推进；旧 producer 仅退休自己的配置代次。
- Source binding／既有 SavedMove／Origin／Input 有界保留强 Sequence／BS 引用；Owner、配置或 producer 退休后，旧引用不能授权后继动作。
- `PublishLocomotionSourceBinding(binding,error)` 的 bool 只确认合法原身份与代次 transport。Missing／Invalid 连同原 Error 可被接收，但不授曲线执行；Fixed／GA 不因无需 resolver 误报角色错误。
- CMC 需要曲线时，`GetLocomotionSourceBinding` 重验原身份并调 `ValidateBinding`，不可用／过期明确拒绝原请求；不保留旧健康来源兜底。解析半成品被清空，原 Error 含模块、Producer、AnimSet key／Motion／SampleIndex、asset 与原因，供必需曲线请求的失败诊断使用。
- `RetireLocomotionSourceBinding(originalProducer,originalConfigurationGeneration)` 只撤原 publication。Base 生命周期先退休再清表现；代次耗尽明确失败，不回绕或借后继身份。
- 配置不变只比较 refs／route／rates／length／sample 位置；变化才冻结新元数据。没有最终 Graph 输出缓存、任意整图历史或第二调度器。

## 2. 源动画数据与区间求值契约

生产四曲线为 `RootMotion_Speed`（cm/s）、`RootMotion_DirX/DirY`（局部 X 前、Y 右）、`RootMotion_Yaw`（累计角度）。Pos／Dist／Cfg 曲线不是当前移动求值的来源猜测或位移积分依据。

实际接口（归 Movement）：

```cpp
ValidateSource(Source, Error);
ValidateBinding(Binding, Error);
EvaluateSingleInterval(Source, t0, t1, Scale, Out, Error);
EvaluateWalkRunInterval(Binding, cycle0, acceptedDt, alpha, Scale, Out, Error);
```

这是函数摘要，参数完整类型以 [Evaluation.h](F:/ue_project/GGYGO/Source/GGYGO/Character/Data/GGYGOLocomotionEvaluation.h) 为准。

### 单源与数据验证

`ValidateSource` 要求有效原 Sequence／RouteKey、有限正 PlayLength／SequenceRateScale、与原元数据一致的真实资产时长和 rate，以及四条必需曲线存在。`ValidateBinding` 还检查 Available、五个非循环单段、looping BlendSpace1D／X轴[0,1]及实际样本表；sample 单帧／mirror 语义当前明确拒绝，不能假装按普通完整 clip 成功。

pure evaluator 调源 `EvaluateCurveData(Name,FAnimExtractContext(time,false),false)`，不读取当前 AnimInstance／Proxy。t0/t1 必须有限、非负且有序；Scale 有限非负。入口清 Out／旧 Error，先在局部 Candidate 求值，成功才交完整输出；失败保留完整 Reset 与原字段原因。

### 单段时间、端点速度与 Yaw

设源时长 L，真实 SequenceRateScale=r，move 区间为 [t0,t1]：

- 源坐标 `s0=t0*r, s1=t1*r`；非循环两端 clamp 到 [0,L]。
- 在源 s1 读取 Speed／Dir。方向先除最大绝对分量，再求长度归一，有限非零值不因 epsilon 被截成零；真正零方向才无方向。
- 原 Speed>0 必须有非零源方向，即使最终 Scale=0；原 Speed=0 可合法无方向。
- move 单位速度为 `Speed(s1)*r`，源速度向量为该速度乘归一化方向，之后才施 RootMotionScale。
- `YawDelta=Yaw(s1)-Yaw(s0)`；YawTotal 是区间末值。样本仍不积分 Pos：`bHasPositionDelta=false`。

循环源的 Yaw 在明确无界源坐标上解绕。若 q=floor(s/L)、p=fmod(s,L)，则 `Y(s)=Y(p)+q*(Y(L)-Y(0))`。不靠 Graph 的累计量跳变、上一帧 Pos 回退或 Cfg 猜测新段／回绕。

### WalkRun：实际样本与 native period

1. `GetSamplesFromBlendInput(FVector(alpha,0,0),...)` 获取实际 BS 对该 move alpha 的活跃样本／权重。
2. `P=GetAnimationLengthFromSampleData(samples)` 取得 native period，尊重资产自己的周期计算规则；不是固定对两个时长 Lerp。
3. `cycle1=cycle0+acceptedDt/P`。对每个源 i，`s0=cycle0*Li, s1=cycle1*Li`，速度时间换算率为 `Li/P`。
4. 各源先求 `Vi=normalized(Diri)*Speedi*(Li/P)`，再求 `V=sum(wi*Vi)`。MixedSpeed=|V|，MixedDir 从 V 求出；RootMotionScale 之后应用。
5. 区间 YawDelta／末 YawTotal 分别加权；不对改变权重后的“最终累计 Yaw／Pos”差分冒充真实区间。
6. 输出数学末相位；只在 CMC 全部成功提交时回绕、写入状态。任何必需依赖／结果失败不取单侧或固定资源替代。

相反方向源可以合法抵消，Mixed V=0 仍是成功来源。例：100·(+X) 与 300·(−X) 等权混合，V=−100X；分别混合 Speed 与 Dir 再相乘会变成0，不能替代向量混合。当前两个前向 Loop 不需要新增另一套 VelocityX/Y 曲线。

这里的权重来自 BS 对 move 输入的 native 样本查询，**不是 AnimGraph Player 的 filtered sample cache／Marker 时钟／最终整图曲线**。本轮保留 Player 与可见相位行为；例如物理权威相位 .70→.20 校正时，现有独立 Player 可仍在原足相位。没有把 source physics 与视觉完全同步作为已完成事实。

## 3. CMC移动模拟与WalkRun共相位

运行单位是原生一次 move／重演调用，不是渲染帧采当前 Graph。

1. Before 保留既有独立 Action／原生 RootMotion 权限与地面请求门禁；SimulatedProxy 走自身原生路径。
2. `TryUpdateLocomotion` 捕获原执行号及栈内候选，ResolveGait／alpha／Start／Stop／TurnBack 继续按原语义选择。
3. 普通单段在受理 dt 上调用源单段重载，普通 WalkRun 调实际 BS 重载；成功才提交候选，pure 不推进 clock。
4. `IsCurrentMotionFinished` 先验证源区间，单段按 `MotionTime*SequenceRateScale>=PlayLength` 判完成。Missing／Invalid 不是完成；明确 Fixed 模式与源时间线分开。
5. Stop／TurnBack 走 Stage：暂存原 Input／Origin 与 binding 后挂源，等待实际 native Prepare，不预支整帧区间。同 Completed Origin 只普通求值并提交剩余 clip 语义，不重新发行同一物理执行。
6. 普通成功 Commit；RMS 的真实准备区间成功后一次 Consume。失败 Reject 原非零请求并退自己的 Locomotion 资源；0号不补号，旧来源不失败后继。合法 mixed zero 不发行结束事件。

`Origin` 将原 source publication 与原 MovementSet、输入身份、执行号、片段／序列、入口 Yaw／Scale 关联。Source 引用不是身份猜测；每次使用重验原关系。

## 4. 速度、Yaw与原生RMS消费

RMS `PrepareRootMotion(sim,tick,...)` 请求原 CMC 的 `PrepareLocomotionCurveRootMotion`。CMC 验证原 Origin／Input／Source 与实际区间，调用纯源求值并返回 Prepared／Finished／Stale／Failed／UnsupportedOrigin。

RMS 只写返回的世界 OverrideVelocity 与 native EndTime；不读当前 CurveMotion，不自行选源／求值。固定 BaseYaw 旋转缩放端点速度，再乘 sim/tick；这是端点速度贡献，**不是精确平移积分**。胶囊运动和转身旋转仍由 CMC 原生物理／MoveUpdatedComponent 执行；挂载不保证当帧 Prepare，跳过准备不补造区间。

Stop 的原单段策略在实际 sim>0 且源 Speed 真正为0时自然结束；TurnBack 按既定 Turning／Braking／RunOut 语义退出，零速可留场。Mixed zero 不用于结束其它资源。离地、幂等清理和 Completed 剩余 clip 分支按真实生命周期处理，均不替换为另一业务动作。

成功来源包含合法0、极小值与0 Scale；GetMaxSpeed 曲线分支不因无资格回落 Fixed。`HasUsableSpeed` 的幅值判据不能代替 source 成功资格。末端 PhysicsRotation 仍有非有限 Yaw→0 的防御分支；上游源求值严格有限校验，不能把该分支当非法业务成功的验证证据。

## 5. 预测恢复与Animation只读Capture

- `SetMoveFor` 保存原 source binding 及普通起始语义／段时间／共相位／alpha／序列／转身基线；合并条件保留原 publication 身份。
- `PostUpdate` 保存本 move 的原 Input／Prepared 或 PendingInput；Prepared 是原区间派生结果，不是第二当前样本权威。
- `PrepMoveFor` 在 native Super 前安装原 replay binding／输入／Source group。普通 replay 沿原上下文消费已有或实际生成的区间；没有原准备结果时 Reset，不把整帧 dt 当成原实际区间。
- authority replay 接受新语义／时间基线，清旧派生 Prepared，保留原合法 binding 和记录的 native interval；必要时原 Source 在同一 sim/tick 重新 Prepare。重新求值的 Candidate／速度不能用旧预测结果替代。
- 旧 binding 已退休、Origin／group 不匹配、原请求 FAILED 时明确拒绝；不会因为保存了强资产引用就重开权限。Clear／EndReplay／EndPlay 各清自己的有界引用。
- 服务端用自己的合法来源和权威上下文求值。MoveData 保留语义 hint；RMS NetSerialize 加载清本地 Origin／Prepared，外来 Origin 尚不支持认证导入。代码契约不是完整 authority／proxy 或网络动态验收。

Animation Capture只读当前Pawn／CMC／ASC，原StateFrame给ABP输入、步态、混合、停止、转身、Tag，CurveMotion入Debug。Gate106在同一GT Capture只调用一次原CMC `GetLocomotionSteeringSnapshot`，核原身份后把完成区间native值复制到现有Frame；真实速度轨迹导数供ZZZ有限WalkRun倾身，不是源RootMotion_Yaw差分、LocalVelocityAngle或胶囊Yaw的替代。弱来源不在worker解析。源publication、CMC区间事实与表现标量分别有唯一归属，没有Graph曲线反馈或第二clock，也未给Player增加运动时间接线。接口见 [[Animation/结构#WalkRun倾身：原区间事实与普通分支|区间事实与普通分支]]，有限验收见 [[Animation/计划_动画与表现层#WalkRun运动偏移（2026-10-07，Gate106）|Gate106验收与边界]]；上方源曲线算法不变。

## 7. 历史Sampler与Editor读回边界

`FGGYGOAnimCurveSampler` 仍保留源码，当前 CMC 无调用；`FGGYGOAnimCurveMotion` 是样本的兼容别名。旧 Sampler 从 AnimInstance.GetCurveValue 读 Cfg／Speed／Pos／Dist／Yaw／Dir，以旧信号猜来源、持跨帧累计基线、差分并归零／钳零／生成方向；这些机制不是当前源求值契约，禁止作为运行兜底。

Editor `ReadFloatCurves` 读公开 DataModel；`ReadFloatCurveSnapshot` 交付调用者拥有的完整同步语义副本（Name／Flags／Default／外推／每键九字段及 double 时长），无源句柄、运行缓存或 move 时钟。2026-10-03 七源完整 Snapshot 和正式根的只读记录保留历史；不是当前运行时把 Editor DTO 复制为 DA。

生成器的有限非零方向／float32 校验修复已有独立专项；只对真正恒定序列压缩，不把小速度或非零位移钳为0。后续定向源修正只更新上述三个现有 DirX.Key.Value，其它约定 FloatCurve／源元信息保持。第一次 writer 在保存前身份读回失败并异常退出的原日志保留；后来精确保存与 cold read 成功不把原失败改判，raw 骨键／Channel 仍未验证。
