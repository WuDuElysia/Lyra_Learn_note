### 源配置如何进入 Movement

生产路由为 WalkStart→`WalkStart`、StartStop→`WalkStartEnd`、WalkStop→`WalkEnd`、RunStop→`RunEnd`、TurnBack→`TurnBack`；WalkRun→`walkRun` BlendSpace。这些是明确的既有 key 配置，可在 AnimSet 调整；缺 key／asset 时不选择替代资源。五个单段声明非循环，WalkRun 样本声明循环；单源 SequenceRateScale 和 BS SampleRateScale 分别读取真实资产属性。

Base 仅允许当前 Character 主 Mesh 的原 AnimInstance 发布。Identity 保存 Producer／Character／Mesh 弱身份、LifecycleGeneration 与 ConfigurationGeneration；配置代次跨 reinitialize 单调推进。Sequence／BS 强引用由当前 publication 与既有有界 SavedMove／Origin／Input 快照保留；保留引用不授予后继实例执行资格。

### 表现生命周期与现有 ABP

Reset 先退休本实例原 source publication，再清 CharacterOwner、StateFrame、DebugFrame，最后调派生 Hook。ZZZ 清 StateMemory、Snap、Events 借用上下文与公开派生字段，保留 AnimSet／Tuning。Owner 变化按“清旧 → 绑定当前 Owner → 发布当前来源 → 抓当前帧”执行；旧弱引用失效也能识别生命周期切换。

EnterMove／Stop／TurnBack 为单次播放，Idle／WalkRun 循环。WalkRun 的 X 输入仍消费旧序列化字段 `GaitBlendY`（显示 Walk Run Blend Alpha）；已读生产轴仍名 GaitBlendY、范围 0..1。本轮未改 Player／Evaluator／同步标记、滤波或网络相位，物理的 move 区间与表现播放器不承诺同 clock，也没有任意整图历史恢复器。

Gate82 的普通 FullBody Slot 是历史检查点。Gate100 保存后的主图为 `MainStateMachine → ActionPoseSlot → LocalToComponentSpace → ComponentToLocalSpace → Inertialization → Output Pose`，旧 FullBody Slot 与 Bip001 ModifyBone 均已删除。节点配置为 `SlotName=FullBody`、`AlwaysUpdateSourcePose=true`、`BodyBoneName=Bip001`、`TrajectoryBoneName=Root`、`ComponentAlignment=(0,0,50.801998138427734)`；CDO 声明必需 FullBody，原父类、AnimSet／Tuning、IgnoreRootMotion 与其余 24 张图保持。保存读回不是完整动态姿态验收。

PlayerCombo 现已按原 Main Section 的 source binding 调用 CMC `BeginMontageActionMotion`；Section／结束／失败时只释放自己的句柄，End 移动取消沿 `CancelMontageActionMotionForMovement`。CMC 按原 `RootMotion_PosX/Y/Z` 区间差提供胶囊 XYZ 位移，Body Z 由动画姿态链保留，两条链不交换最终姿态速度。三份 Montage 的 Main→End 和 Hit／Combo 窗口配置仍见 [[Animation/普攻动画实施]]，GA 原请求与资源归属见 [[计划_玩家普攻连段]]、[[Movement/动作曲线执行]]。

## 动作姿态节点与能力契约

`FGGYGOAnimNode_ActionPoseSlot` 保留原生 Slot 的 Initialize／CacheBones／Update／Evaluate、权重、Notify 与混合执行；没有第二播放器、源采样器或帧调度。`PostEvaluateSourcePose` 仅在同次 Evaluate 内借用原生真正求值且参与的 Source 标量，入口和退出都清临时量；`AlwaysUpdateSourcePose=true` 不授权读取被原生 Evaluate 省略的 Source。

在非 Additive、均匀混合和固定当前 Mesh 参考祖先的最低契约内，节点从原生 Slot 混合结果扣除实际 Source 与动作参考高度贡献，再加角色原组件对齐值。只写 Body 的 local translation；旋转／缩放、Root 分支及胶囊不由此节点改写。原 Mesh RequiredBones 必须实际保留 Body／Root，缺骨、非法祖先、原生 RootMotion 或 per-bone BlendProfile 明确失败，不以另一个 Skeleton 参考或固定高度代替成功。算法、原生有效系数与失败分支见 [[Animation/动作姿态修正]]、[[GGYGO_流程_动作姿态修正.canvas|子流程]]。

| 调用方 → 接口 | 输入、结果与生命周期 |
| --- | --- |
| 原 Guard `NativeUpdateAnimation` → 节点能力发布 | 在 GT 检查原 `MontageInstances` 中同 Slot、原生有效权重的真实输入及 active BlendProfile。只发布 bool／诊断、原 provider 弱身份与原生 UpdateCounter；worker 不读 MontageInstances 或受保护的 evaluation array。 |
| Task 启动 → Guard `AcquireActionPoseContract(OriginalMontage, OutTicket, OutDiagnostic) const` | 原 GT 并行完成屏障前后重验 provider／Owner／主 Mesh／模型／角色声明；按原编译 node properties 唯一定位 producer。返回 `ExplicitNotRequired/RequiredReady/Rejected/Unavailable`，失败清票据。RequiredReady 证明当前配置能力，不保证未来每次 pose 成功。 |
| Task 原生 `TickTask` → `PollActionPoseContract(OriginalTicket, OutDiagnostic) const` | Required-only，读原票据，不累积 DeltaTime、不驱动动画。原生命周期／Mesh／角色／配置替换为 Invalidated；新故障序号或当前能力失败为 Failed；原契约仍有效为 Valid。不刷新旧票据或为后继签权限。 |
| Task `FailActionPoseContract` → 历史 `OnFailed` → 原 GA | Task 精确处理原播放停止、scale lease、监听及 EndTask 后派发 typed failure；GA 按原 Activation／step／Task／资源验证，再 `RequestAbilityEnd(Original,true,true)`，由自身清理 CMC 句柄。普通用户 Cancel 策略不阻止必需依赖失败的强制 End。 |

`RequiredPoseCorrectionSlot=None` 是明确普通 Slot 模式；若 Montage 已使用 correction producer 却没有匹配声明，Acquire 必须 Rejected，不能悄悄降级为普通播放。RequiredReady 必须有 Ready 前的 OnFailed 消费者。Animation 不 include AbilitySystem、不持 GA 激活状态；能力契约扩展到 Guard 只读接口，原播放 Guard Scope／结果语义保持。

## Montage播放Guard的静态契约

`UGGYGOMontageGuardAnimInstance` 是 Base 的父类，管理原实例调用的 ScopeChain 借用登记与生命周期身份。Caller 栈拥有 `FGGYGOMontagePlayGuardScope`；Guard 不拥有 Scope 存储、GAS 播放状态或第二 Montage 执行器。

| 关键接口 | 契约 |
| --- | --- |
| `CanExecute`／`Complete(CallerReturn)`／`GetResult` | 准许原生入口、幂等封存结果；Result 为 Scope 内引用，析构前必须复制。完成证据不自动授 Task 资源权限。 |
| `TryGetCurrentMontagePlayGuardStage(CallerIdentity,OutNativeStage,bOutCompleted)` | GT 只看最内层原登记与原身份；不可用先 Reset。无祖先回查、外部谓词或生命周期刷新；外部回调后重新查询。 |
| NativeStage／Completed | Returned 只表示 Animation 原生调用返回；Completed 为 Scope 封存事实。均不等于 ASC 全部回写完成、Accepted 或新 GA 权限。 |
| 生命周期失效／Scope 析构 | 旧 Scope 只注销原登记，不停止新 Owner Montage，不清 ASC／Task 后继资源。 |

ASC 调用栈覆盖完整 Super 播放并复制结果；Task 通过 `TryPlayMontageWithOwnership` 消费单一 Result／原 Handle／Guard，管理自己的事件、委托与 RootMotionScale lease。姿态能力票据另行证明必需依赖，不替代 Playback Handle 或 Guard 的播放身份。精确 Clear、Completed、历史 OnFailed 与统一终止的资源边界见 [[AbilitySystem/结构]]。
