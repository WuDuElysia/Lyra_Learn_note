### 源配置如何进入 Movement

生产路由为 WalkStart→`WalkStart`、StartStop→`WalkStartEnd`、WalkStop→`WalkEnd`、RunStop→`RunEnd`、TurnBack→`TurnBack`；WalkRun→`walkRun` BlendSpace。这些是明确的既有 key 配置，可在 AnimSet 调整；缺 key／asset 时不选择替代资源。五个单段声明非循环，WalkRun 样本声明循环；单源 SequenceRateScale 和 BS SampleRateScale 分别读取真实资产属性。

Base 仅允许当前 Character 主 Mesh 的原 AnimInstance 发布。Identity 保存 Producer／Character／Mesh 弱身份、LifecycleGeneration 与 ConfigurationGeneration；配置代次跨 reinitialize 单调推进。Sequence／BS 强引用由当前 publication 与既有有界 SavedMove／Origin／Input 快照保留；保留引用不授予后继实例执行资格。

## 动画事实与曲线接口契约

| 调用方 → 接口 | 输入／前提 | 输出、状态归属与清理 |
| --- | --- | --- |
| UE → Base Initialize／Update | 原 Character／主 Mesh／Producer；现有 AnimSet routes | 配置／Owner 变化时解析并冻结 binding；正常帧只比较配置，复用 publication，不采 Graph 曲线。 |
| Base → `CMC.PublishLocomotionSourceBinding(binding,error)` | 原身份、非零生命周期／配置代次；Status 与定位 Error | bool 确认原身份与配置 publication 接收。Missing／Invalid 也保存为明确不可用状态；需要曲线执行时由 CMC 拒绝。合法 Fixed／GA 模式不因无需来源而报角色配置错。身份接收失败仍诊断。 |
| Base Uninitialize／Owner 或配置替换 → `RetireLocomotionSourceBinding(originalProducer,originalConfigurationGeneration)` | 原 consumer 与原 publication | 只撤原 producer／代次，释放自己的 handle；不能撤新 producer 的来源或让旧 binding 授权后继。 |
| Base → `StateCapture::Capture` | 当时 Pawn／CMC／ASC 的事实 | 输出先 Reset；StateFrame 只含语义，不新增 CMC MotionTime／CyclePhase 输入给 Player。 |
| ZZZ → Adapter／`MapMovementState`；AnimBP → 语义查询与查表 | 同帧 State／Debug；旧序列化字段 | 仅复制／映射。ABP 决定状态、素材、Time Remaining、混合和通知；无第二走跑插值或早停计时。 |
| CMC → `GetLocomotionSourceBinding`／`ValidateBinding` | 当前或原 replay binding 与真实执行请求 | 检查原身份、配置、路由、曲线及样本；Missing／Invalid／Stale 不成为成功或固定速度。 |
| CMC → 源 `EvaluateSingleInterval`／`EvaluateWalkRunInterval` | 单源 t0/t1 或实际 BS、共相位、受理 dt、alpha、Scale | 读取源 `EvaluateCurveData`，返回端点速度／区间 Yaw 与数学末相位；合法零混合保留。函数不提交 CMC 状态，算法见 [[Animation/曲线处理]]。 |
| CMC → Stage／Prepare／Consume | 原 Origin／Input、实际 native sim/tick、固定入口 Yaw／Scale | Stop／TurnBack 暂存输入，原生 Prepare 中求值，一次 Consume 才提交候选。RMS 只提供返回的世界速度贡献，胶囊仍归 CMC。 |
| SavedMove／权威 Response → 原 replay | 原 binding、输入、实际区间；新权威语义／时间基线 | 普通重演保留原上下文；权威重演清旧派生 Prepared，沿原合法 binding 和实际区间重新求值。旧结果不覆盖校正，不恢复 FAILED；导入 Origin 与网络动态边界仍开放。 |

### 表现生命周期与现有 ABP

Reset 先退休本实例原 source publication，再清 CharacterOwner、StateFrame、DebugFrame，最后调派生 Hook。ZZZ 清 StateMemory、Snap、Events 借用上下文与公开派生字段，保留 AnimSet／Tuning。Owner 变化按“清旧 → 绑定当前 Owner → 发布当前来源 → 抓当前帧”执行；旧弱引用失效也能识别生命周期切换。

EnterMove／Stop／TurnBack 为单次播放，Idle／WalkRun 循环。WalkRun 的 X 输入仍消费旧序列化字段 `GaitBlendY`（显示 Walk Run Blend Alpha）；已读生产轴仍名 GaitBlendY、范围 0..1。本轮未改 Player／Evaluator／同步标记、滤波或网络相位，物理的 move 区间与表现播放器不承诺同 clock，也没有任意整图历史恢复器。

Gate82 已精确保存 `ABP_Pyrios` 的 FullBody，位于原空间修正前，`AlwaysUpdateSourcePose=true`；其余已约定图及 AnimSet／Tuning 保持。三份普攻 Montage 的 Main→End 和独立 Hit／Combo 窗口仍见 [[Animation/普攻动画实施]]、[[计划_玩家普攻连段]]。PlayerCombo 尚无动作位移接管；Slot 已接不等于胶囊位移或攻击整链通过。

## Montage播放Guard的静态契约

`UGGYGOMontageGuardAnimInstance` 是 Base 的父类，管理原实例调用的 ScopeChain 借用登记与生命周期身份。Caller 栈拥有 `FGGYGOMontagePlayGuardScope`；Guard 不拥有 Scope 存储、GAS 播放状态或第二 Montage 执行器。

| 关键接口 | 契约 |
| --- | --- |
| `CanExecute`／`Complete(CallerReturn)`／`GetResult` | 准许原生入口、幂等封存结果；Result 为 Scope 内引用，析构前必须复制。完成证据不自动授 Task 资源权限。 |
| `TryGetCurrentMontagePlayGuardStage(CallerIdentity,OutNativeStage,bOutCompleted)` | GT 只看最内层原登记与原身份；不可用先 Reset。无祖先回查、外部谓词或生命周期刷新；外部回调后重新查询。 |
| NativeStage／Completed | Returned 只表示 Animation 原生调用返回；Completed 为 Scope 封存事实。均不等于 ASC 全部回写完成、Accepted 或新 GA 权限。 |
| 生命周期失效／Scope 析构 | 旧 Scope 只注销原登记，不停止新 Owner Montage，不清 ASC／Task 后继资源。 |

ASC 调用栈覆盖完整 Super 播放并复制结果；Task 当前通过 `TryPlayMontageWithOwnership` 消费单一 Result／原 Handle／Guard，管理自己的事件、委托与 RootMotionScale lease。精确 Clear、Completed 与统一终止的资源边界见 [[AbilitySystem/结构]]；本次 source 迁移没有扩大 Guard 或 Task 权限。

## Editor曲线只读接缝

`ReadFloatCurves` 唯一读公开 DataModel，`ReadFloatCurveSnapshot` 每次调用它一次，交付完整同步值副本；工具没有运行时 source binding 或曲线时钟。生成器保留有限非零速度／方向，源定向修改只改批准的三个 Key.Value，保存与冷读由资产调用者负责。
