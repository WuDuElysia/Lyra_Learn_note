`ABP_Pyrios` 的 `EnterMove`、`Stop`、`TurnBack` 播放器均为单次播放；`NotMoving` 与 WalkRun 循环。`EnterMove → Moving` 使用剩余动画比例 ≤ 0.03：起步开启循环会让末尾条件可能被回绕跳过。WalkRun 仍使用同一个 BlendSpace1D，X 输入消费 `StateMemory.GaitBlendY`（蓝图显示 `Walk Run Blend Alpha`，旧成员名保留兼容拆分引脚）；轴规范名为 `WalkRunBlendAlpha`，当前生产资产需在 UE 窗口回读并保存修正。

`UGGYGOAnimInstanceBase` 从 [[Movement/结构|CMC]] 和 [[AbilitySystem/结构|ASC]] 捕获事实，AnimBP 只读这些事实选择表现。Movement 已负责推进 `WalkRunBlendAlpha` 和选择 `StopMotionType`；ZZZ 兼容层只做无状态映射：前者复制到旧序列化字段 `GaitBlendY`，后者映射为 `StopValue`（StartStop=0、WalkStop=1、RunStop=2）。它不再维护 0.3 秒早停计时或走跑插值。

AnimInstance 的初始化、反初始化和运行时 Owner 变化共用一个幂等复位入口。入口先清 `CharacterOwner`、`AnimationState` 与 `AnimationDebug`，再调用派生 Hook；ZZZ Hook 清 `StateMemory`、`Snap`、`LocomotionEvents` 的无所有权上下文和全部公开派生表现字段，但保留 `AnimSet`、`Tuning` 配置。Owner 变化帧按“清旧状态 → 绑定新 Owner → 抓取新帧”的顺序执行，因此 `A → nullptr → B` 的首帧不会继承 A 的 Tag、步态、速度或 TurnBack。`FGGYGOAnimationStateCapture` 当前无跨帧缓存。

## Montage播放Guard的静态契约

`UGGYGOMontageGuardAnimInstance` 属于Animation Runtime。项目Base已继承它，Base的Initialize/Uninitialize/Update调用Super进入Guard生命周期；StateFrame抓取链与Guard的借用调用登记分别保留职责。Guard唯一持有原AnimInstance的ScopeChain非拥有指针登记与生命周期generation/call ID，不持有GAS类型、第二Montage执行器或Task资源权威。Scope存储属于Caller栈，Request/Result属于该Scope，不把借用登记写成存储所有权。

| 接口 / 输入输出 | 当前静态契约 |
| --- | --- |
| `TryGetCurrentMontagePlayGuardStage(const UObject* CallerIdentity, EGGYGOMontagePlayGuardNativeStage& OutNativeStage, bool& bOutCompleted) const` | GameThread只读调用，接收原协调者的不透明CallerIdentity；在原Guard实例上只检查最内层 `ScopeChain.Last()` 的登记、原Guard、Caller及生命周期身份。 |
| 可用true | 即时复制NativeStage和 `bSealed` 到两个输出；不要求Montage实例存在或仍活跃，不证明Outcome=Accepted或ASC/GA/Task权限。 |
| 不可用false | 输出先Reset为NotEntered/false；空Caller/无Scope或内层身份无效等均不可用，不回查匹配祖先，也不以祖先Executing作为替代。false不是准许新播放或清理资源的依据。 |
| 查询边界 | 无外部谓词调用、生命周期刷新、祖先回查或新状态；副本只代表查询瞬间，任何外部调用/回调后须重新查询。Readonly身份观察不能检测未被观测的Owner A→B→A，不扩写成完整调用方所有权证明。 |
| NativeStage / Completed | NativeStage为NotEntered/Executing/Returned；Returned仅表示原生Animation Super返回，ASC整个Super与回写可能仍在进行。bOutCompleted来自Scope封存标志，不是第四个NativeStage，不等于来源发布或成功结果。两者均不授Task播放、停止、lease或委托资源权限。 |

Scope的Request保存原AnimInstance、RequestedMontage、不透明CallerIdentity和原有纯 `IsCallerContextCurrent` 谓词。该谓词由既有Guard入场/完成校验消费，与上述查询“不调用外部谓词”分开。`CanExecute` 只准许原生入口；`Complete(CallerReturn)` 幂等封存证据，`GetResult` 返回Scope内引用，调用方须在Scope析构前复制Identity/Outcome/NativeStage/返回值，不能把结果引用留到析构后。

Initialize/Uninitialize及观测到的Owner变化使Guard身份失效；不清空借用链或释放仍在Caller栈的旧Scope。Scope析构按原实例自身登记注销，即使生命周期已失效仍清理自身；不会停止新Owner的Montage或修改ASC/Task状态。引擎实例、GAS Local/Rep/GA/预测状态及Task事件/委托/RootMotionScale lease保持既有归属。

ASC受控播放在调用栈创建Scope，CallerIdentity为原ASC，覆盖整个 `Super::PlayMontage` 并复制完成结果。Task::Activate已消费 `TryPlayMontageWithOwnership` 单一Result／ASC签发原Handle／Guard，绑定携原Guard的精确实例委托；无第二尝试表／扫描，事件与缩放资源只归Task。混出请求ASC精确Clear；Completed是原实例Ended事实，不借Clear后已退休的当前证明、不授后继GA终止权。ASC/Task及T2统一终止核心已实施并随Gate65/66编译，受控激活政策已确认；旧夹具、派生原生命周期与生产入口尚未迁完，新Completed动态未验。接口／清理见[[AbilitySystem/结构#Task原实例与资源消费（已编译，专项与迁移边界保留）|Task消费者]]。阶段查询仍只读原生阶段，不因Result消费成为播放权威；生产AnimClass、严格P1来源／权限链及网络继续开放。
