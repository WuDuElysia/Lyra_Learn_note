# Animation：结构与接口

> 结构图：[[GGYGO_结构_动画与表现.canvas]] · 动画流程：[[GGYGO_流程_动画表现.canvas]] · 曲线子图：[[GGYGO_流程_动画曲线处理.canvas]]

> 曲线的类关系和采样算法另见 [[GGYGO_结构_动画曲线.canvas|曲线结构图]]、[[曲线处理]]。

| 类 / 资产 | 关键接口或数据 | 当前责任 |
| --- | --- | --- |
| `FGGYGOAnimationStateCapture` | `Capture` | 游戏线程上从 Pawn、CMC、ASC 收集一帧语义事实。 |
| `FGGYGOAnimationStateFrame` | `bHasMoveInput`、步态、转身等字段 | C++ 向 AnimBP 发布的只读帧；不包含状态机拓扑。 |
| `UGGYGOAnimInstanceBase` | `NativeUpdateAnimation`、`HasAnimationStateTag`、`IsAnimationRunGait`、`IsTurnBackCurveDriven` | 抓帧并提供通用语义查询。 |
| `UZZZAnimInstance` / `FZZZAnimSnapshot` | 兼容快照、表现记忆 | 现有 `ABP_Pyrios` 的迁移层。 |
| `ABP_Pyrios` | 状态机、资产选择与过渡图 | 决定 EnterMove、Moving、Stop、TurnBack 等表现拓扑。 |
| `FZZZAnimSet` / `FZZZAnimTuning` | 动画查表与混合配置 | 保留当前 ZZZ 资产接线。 |

`UGGYGOAnimInstanceBase` 从 [[Movement/结构|CMC]] 和 [[AbilitySystem/结构|ASC]] 捕获事实，AnimBP 只读这些事实选择表现。当前 `StateMemory.StopValue`、`GaitBlendY` 仍由 ZZZ 兼容层推进；MotionProfile、Linked Anim Layer 与清理兼容层属于后续阶段，见 [[计划_动画与表现层]]。曲线的资产准备、采样和消费链另见 [[GGYGO_流程_动画曲线处理.canvas|动画曲线子图]]。

## 动画事实与曲线接口契约

| 调用方 → 接口 | 输入 / 前提 | 作用与输出 / 副作用 |
| --- | --- | --- |
| UE → `AnimInstanceBase::NativeUpdateAnimation(dt)` | Pawn/CMC/ASC 已可查询 | 调 `StateCapture::Capture(OutState, OutDebug, Pawn)`，形成一帧只读 AnimationStateFrame。 |
| StateCapture → CMC / ASC / Pawn 查询 | 步态、移动输入、转身、状态 Tag 与位置朝向 | 只读取玩法事实；ABP 负责状态选择和资产表现，不从 C++ 接收预定 ABP 状态名。 |
| AnimBP → `HasAnimationStateTag/IsAnimationRunGait/IsTurnBackCurveDriven` | 已捕获 StateFrame | 过渡图读语义；`GetSeqByKey/GetBlendSpaceByKey` 从动画资源表选素材。 |
| `ZZZAnimInstance::NativeUpdateAnimation` → LegacySnapshotAdapter | 同帧 StateFrame/DebugFrame | 当前兼容旧 Snapshot 和 StopValue/GaitBlendY 记忆；迁移完成前不可写成已移除。 |
| CMC → `AnimCurveSampler::Sample(AnimInstance, dt, OutMotion)` | 当前播放动画上的 RootMotion_* 曲线 | 当前实现是移动层反读动画数据，计算 CurveMotion 供 CMC/RMS；MotionProfile 只是拟议的拆环数据源。 |

曲线基线、差分、方向优先级与预测重演见 [[曲线处理]] 和 [[GGYGO_结构_动画曲线.canvas|曲线结构子图]]。
