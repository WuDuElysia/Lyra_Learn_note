### 源配置如何进入 Movement

生产路由为 WalkStart→`WalkStart`、StartStop→`WalkStartEnd`、WalkStop→`WalkEnd`、RunStop→`RunEnd`、TurnBack→`TurnBack`；WalkRun→`walkRun` BlendSpace。这些是明确的既有 key 配置，可在 AnimSet 调整；缺 key／asset 时不选择替代资源。五个单段声明非循环，WalkRun 样本声明循环；单源 SequenceRateScale 和 BS SampleRateScale 分别读取真实资产属性。

Base 仅允许当前 Character 主 Mesh 的原 AnimInstance 发布。Identity 保存 Producer／Character／Mesh 弱身份、LifecycleGeneration 与 ConfigurationGeneration；配置代次跨 reinitialize 单调推进。Sequence／BS 强引用由当前 publication 与既有有界 SavedMove／Origin／Input 快照保留；保留引用不授予后继实例执行资格。

### 表现生命周期与现有 ABP

Reset 先退休本实例原 source publication，再清 CharacterOwner、StateFrame、DebugFrame，最后调派生 Hook。ZZZ 清 StateMemory、Snap、Events 借用上下文与公开派生字段与WalkRun倾身Angle／Valid／Failure、原弱CMC／SourceEpoch，保留AnimSet／Tuning。Owner 变化按“清旧 → 绑定当前 Owner → 发布当前来源 → 抓当前帧”执行；旧弱引用失效也能识别生命周期切换。

EnterMove／Stop／TurnBack 为单次播放，Idle／WalkRun 循环。WalkRun 的 X 输入仍消费旧序列化字段 `GaitBlendY`（显示 Walk Run Blend Alpha）；已读生产轴仍名 GaitBlendY、范围 0..1。未改Player／Evaluator／同步标记、BlendSpace节点滤波或网络相位，物理的 move 区间与表现播放器不承诺同 clock，也没有任意整图历史恢复器。

Gate82普通FullBody Slot是历史检查点。Gate100保存的主图为 `MainStateMachine → ActionPoseSlot → LocalToComponentSpace → ComponentToLocalSpace → Inertialization → Output Pose`；原普通Slot和顶层 `ModifyBone(Bip001)` 全轴Translation Replace已删除。ActionPoseSlot配置仍为 `FullBody/AlwaysUpdateSourcePose=true/Bip001/Root/ComponentAlignment=(0,0,50.801998138427734)`，CDO必需FullBody。Gate106仅新增普通WalkRun的单Spine旋转支路和 `Tuning.WalkRunLean`；主图、父类、AnimSet、其余旧Tuning、IgnoreRootMotion及另外24张图保持。保存读回与动态证据各按有限范围记录。

PlayerCombo 用 `BuildSourceBindingRange(原Montage,Slot,Main,End,OutBinding,OutError)` 保存有序原Sections，按原snapshot `BeginMontageActionMotion`；Main→End共用原句柄、入口朝向与CMC／RMS时钟。作者单点经过后，GA同时接受原Scope的合格移动和一次真实新攻击；新段重新关门，Section变化只记录段落。移动经 `CancelMontageActionMotionForMovement` 中止原句柄并结束原GA，后续攻击从01重新开始；攻击按显式NextStepIndex换段，03接01由GA新请求实现。无请求继续完整End；原非中断BlendOut经 `NotifyMontageActionNaturalBlendOut` 认证，CMC末贡献沿 `ObserveMontageActionMotionCompletion` 发布一次，GA等原Task与原位移两事实再自然结束。失败／替换／Owner失效清本人资源，不借后继完成。配置见 [[Animation/普攻动画实施]]，资源见 [[计划_玩家普攻连段]]、[[Movement/动作曲线执行]]。

## 动作姿态节点与能力契约

`FGGYGOAnimNode_ActionPoseSlot` 保留原生 Slot 的 Initialize／CacheBones／Update／Evaluate、权重、Notify 与混合执行；没有第二播放器、源采样器或帧调度。`PostEvaluateSourcePose` 仅在同次 Evaluate 内借用原生真正求值且参与的 Source XYZ 向量，入口和退出都清临时量；`AlwaysUpdateSourcePose=true` 不授权读取被原生 Evaluate 省略的 Source。

在非 Additive、均匀混合和固定当前 Mesh 参考祖先的最低契约内，节点从原生 Slot 混合结果扣除实际 Source 与动作参考的 XYZ 贡献，再加角色原组件对齐值。只写 Body 的 local translation；旋转／缩放、Root 分支及胶囊不由此节点改写。原 Mesh RequiredBones 必须实际保留 Body／Root，缺骨、非法祖先、原生 RootMotion 或 per-bone BlendProfile 明确失败，不以另一个 Skeleton 参考或固定高度代替成功。算法、原生有效系数与失败分支见 [[Animation/动作姿态修正]]、[[GGYGO_流程_动作姿态修正.canvas|子流程]]。

| 调用方 → 接口 | 输入、结果与生命周期 |
| --- | --- |
| 原 Guard `NativeUpdateAnimation` → 节点能力发布 | 在 GT 检查原 `MontageInstances` 中同 Slot、原生有效权重的真实输入及 active BlendProfile。只发布 bool／诊断、原 provider 弱身份与原生 UpdateCounter；worker 不读 MontageInstances 或受保护的 evaluation array。 |
| Task 启动 → Guard `AcquireActionPoseContract(OriginalMontage, OutTicket, OutDiagnostic) const` | 原 GT 并行完成屏障前后重验 provider／Owner／主 Mesh／模型／角色声明；按原编译 node properties 唯一定位 producer。返回 `ExplicitNotRequired/RequiredReady/Rejected/Unavailable`，失败清票据。RequiredReady 证明当前配置能力，不保证未来每次 pose 成功。 |
| Task 原生 `TickTask` → `PollActionPoseContract(OriginalTicket, OutDiagnostic) const` | Required-only，读原票据，不累积 DeltaTime、不驱动动画。原生命周期／Mesh／角色／配置替换为 Invalidated；新故障序号或当前能力失败为 Failed；原契约仍有效为 Valid。不刷新旧票据或为后继签权限。 |

`RequiredPoseCorrectionSlot=None` 是明确普通 Slot 模式；若 Montage 已使用 correction producer 却没有匹配声明，Acquire 必须 Rejected，不能悄悄降级为普通播放。RequiredReady 必须有 Ready 前的 OnFailed 消费者。Animation 不 include AbilitySystem、不持 GA 激活状态；能力契约扩展到 Guard 只读接口，原播放 Guard Scope／结果语义保持。

## Montage播放Guard的静态契约

`UGGYGOMontageGuardAnimInstance` 是 Base 的父类，管理原实例调用的 ScopeChain 借用登记与生命周期身份。Caller 栈拥有 `FGGYGOMontagePlayGuardScope`；Guard 不拥有 Scope 存储、GAS 播放状态或第二 Montage 执行器。

| 关键接口 | 契约 |
| --- | --- |
| `CanExecute`／`Complete(CallerReturn)`／`GetResult` | 准许原生入口、幂等封存结果；Result 为 Scope 内引用，析构前必须复制。完成证据不自动授 Task 资源权限。 |
| `TryGetCurrentMontagePlayGuardStage(CallerIdentity,OutNativeStage,bOutCompleted)` | GT 只看最内层原登记与原身份；不可用先 Reset。无祖先回查、外部谓词或生命周期刷新；外部回调后重新查询。 |
| NativeStage／Completed | Returned 只表示 Animation 原生调用返回；Completed 为 Scope 封存事实。均不等于 ASC 全部回写完成、Accepted 或新 GA 权限。 |
