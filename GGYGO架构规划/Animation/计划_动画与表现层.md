## 0. 这次重构解决什么

旧 CMC 从当前 AnimInstance 的 `GetCurveValue` 决定速度／转身，再由 Animation 读回 CMC 选择姿态，移动因而依赖 Graph 评估时序与当前播放状态。旧 Decisions 又逐条镜像 ABP 过渡线，使表现拓扑变更牵动通用 C++。

已实现的替换将这两项责任拆开：CMC 接收源引用与配置身份，按 move 的区间独立读源曲线；ABP 读语义组织姿态。曾采用的七份 Locomotion Profile 曲线副本已退出生产，避免动画和 DA 成为两个可编辑事实来源。历史类／作者工具／旧失败证据保留，不继续作为生产路线。

## 1. 冻结的职责边界

### 1.1 C++：稳定机制、唯一状态与生命周期

- Animation Runtime 管理原 Producer／Character／Mesh 生命周期、源解析／发布／退休和语义抓帧。
- 原生 ActionPoseSlot 只修正 Mesh Body translation，Guard 提供只读能力票据；原生 Slot 唯一执行姿态混合，Task／GA 各自处理必需依赖失败。
- Movement 管理动作段、接受 dt、MotionTime、CyclePhase、WalkRun alpha、输入请求失败、预测及权威恢复。
- `GGYGOLocomotionEvaluation` 只在显式 source 与区间上求值；没有 clock、Graph 缓存或执行请求。
- GA 管动作资源与能力生命周期；RMS 提供速度贡献；CMC 唯一移动胶囊。
- 通用层不固定角色路径或招式；角色差异通过现有配置／蓝图／源动画提供。

### 1.2 AnimBP / Linked Anim Layer：表现拓扑

状态机、素材选择、Time Remaining、Slot、BlendSpace、Marker、惯性化、IK 与表现层次属于 ABP。蓝图消费稳定语义，不写 CMC／ASC 内部状态，不复制移动计时器。Linked Layer 仍为未来可整体替换的表现域目标，未在本次 source 迁移中实施。

### 1.3 配置与唯一编辑来源

`FZZZAnimSet` 保留 Sequences／BlendSpaces 表，六个 SourceKey 明确映射五个单段和 WalkRun BS。Loop 来自实际 BS 样本；没有另一个 Loop 资源表。默认 key 匹配既有接线，缺 key／asset 明确 Missing，不选择替代资产。

源 `RootMotion_Speed/DirX/DirY/Yaw` 是唯一运行曲线编辑位置。MovementSet 保存明确曲线／Fixed 模式及数值参数；七个废弃 Locomotion 引用已置 null，曲线模式不再要求七 DA。动作 `ActionMotionProfile` 仍归独立动作接口，本次退役范围只含七个 Locomotion DA。

### 1.4 Montage Notify 与 GA

窗口由 Montage／Notify 配置，GameplayEvent 报告 Hit／Combo／Cancel 等语义；GA 校验原播放身份后接受事件，Combat 查询去重、伤害走 GAS。Notify 不直接改 CMC 或施伤，也不创建第二能力状态机。PlayerCombo 的 Main 已接 CMC 原动作句柄；Required 姿态依赖失败经历史 OnFailed 强制结束原 GA，与正常用户 Cancel 政策分开。

## 2. 目标依赖方向

### 2.1 当前两条数据流

```text
AnimSet／实际 Sequence＋BlendSpace
  → Animation 原生命周期解析与冻结 source binding
  → CMC.PublishLocomotionSourceBinding
  → CMC move 区间／相位／alpha
  → Movement 纯源曲线求值
  → CMC／原 CurveRMS／原 SavedMove

CMC／ASC／Pawn 事实
  → StateCapture → StateFrame
  → ZZZ 兼容映射／ABP 状态机
  → Locomotion／原生 ActionPoseSlot／原空间转换／惯性化
```

source DTO 只依赖 Engine 与公共 motion 类型；CMC 不 include Base／窥读 AnimSet／反查当前 Proxy。Animation→Movement 的配置入口与 Movement→Animation 的只读语义分别有明确契约，不把 Graph 的输出速度再送回 CMC。

### 2.2 已消除的旧运行时环

生产移动不调用 `GetAnimInstance()->GetCurveValue()`。服务器和客户端从各自合法 source publication 与 move 上下文独立求值，不需要等 Mesh 最终曲线。但当前 publication 仍依赖原 AnimInstance／主 Mesh 生命周期和资产可用，不能把“不依赖 Graph 求值”写成“完全无需 AnimInstance”。

## 3. C++ 对动画只发布语义帧

StateFrame 当前包含世界速度／加速度、水平速度／方向、本地方向、WalkRunBlendAlpha、StopMotionType、Gait、MovementMode、TurnBackPhase、输入／接地／阻止／RunOut 和状态 Tag。CurveMotion 只读入 DebugFrame。

七条旧 Transition UFUNCTION、Decisions、GaitValue、MovingSubState 已删除。ABP 直接组合输入、Run 语义与 TurnBack 查询；旧 `GaitBlendY`／`StopValue` 只保留序列化兼容映射。Frame 不含 ABP 状态名、Select 索引或曲线来源引用；本轮也未新增 Player 时间／相位字段。

## 4. AnimInstance 的当前形态

Base 继承 MontageGuard，集中进行：

1. 原 native Initialize／Update 识别原主 Mesh／Owner／Producer与配置变化。
2. ZZZ 解析 source 元数据；Base 向 CMC 发布 immutable binding。
3. StateCapture 在 GT 抓当前语义；ZZZ 只映射兼容字段。
4. Uninitialize／Owner 或配置替换先退休原 source 代次，再清自身帧与派生表现资源。

Identity 的生命周期／配置代次是来源身份，不是运动时间。配置不变只比较源引用／rate／length／sample 位置，不反复建立 holder；变化才发布新代次。强资产引用随当前 binding 与既有有界 move 记录释放；弱 Producer／Character／Mesh 和原代次失效后不授后继执行资格。

Missing／Invalid 也能作为合法身份的 publication 被接收；原 Error 保留。只有需要曲线移动时，CMC 的 source gate 明确拒绝。Fixed／GA 的正常配置不因无需 source resolver 被诊断为整角色 Error。身份 transport 拒绝仍由 Animation 诊断一次；无静默业务替代。

起步早停选择和 WalkRun alpha 继续由 CMC 管理。调试字段、旧 key 表与 StopValue 兼容字段的进一步清理仍需真实资产消费审计，不能在本批顺手删除。

## 5. 动画资产与 Linked Anim Layer

现有 `ABP_Pyrios` 保留 WalkRun1D／TurnBack 外层拓扑和单段播放器。Gate82 普通 FullBody Slot 为历史；Gate100 已替换为 `GGYGO Action Pose Slot`，并删除原 Slot／Bip001 ModifyBone。当前主图为状态机→ActionPoseSlot→原 LocalToComponentSpace→原 ComponentToLocalSpace→原 Inertialization→Root；AlwaysUpdateSourcePose=true，Bip001／Root／完整原组件对齐值由 ABP 配置，角色声明 RequiredPoseCorrectionSlot=FullBody。其余24图、AnimSet／Tuning、父类及 IgnoreRootMotion 保持。未迁 Locomotion Player／Evaluator，也未接 CMC normalized phase。实际保存读回、BodyZ 观察和边界见 [[Animation/普攻动画实施]]、[[Animation/动作姿态修正]]。

未来可按可整体替换的 Locomotion／武器／Reaction 域拆 Linked Layer；Idle／Start／Loop／Stop 可以留在同一域。此目标尚未实施，不因源读取完成标为通用主图或多 Boss Form 已验收。

## 6. 强类型 AnimProfile

当前已实现强类型 motion 语义到现有 key 的明确 routes 和 typed source binding，既有表本身仍为 FName 映射。未来是否迁表现 Profile 或由 Linked Layer 持有资源，需以真实角色消费审计决定，避免复制同一资源表。

表现 Profile 若采用，只保存资源引用／调参与必需项校验，不复制运动曲线或保存 Damage／Cooldown／权限。本次 source binding 是运行时只读引用快照，不是新的可编辑 DA。

## 7. 曲线与权威移动的新边界

### 7.1 普通 Locomotion

- 明确 Fixed 模式使用 MovementSet 的固定数值；曲线模式读取源动画。
- 单段：move 秒乘真实 SequenceRateScale，源端点 Speed／Dir 求速度，区间两端求 Yaw。
- WalkRun：用实际 BS 的 `GetSamplesFromBlendInput` 和 `GetAnimationLengthFromSampleData` 得权重／native period；共相位映射每个源的时间，先求源速度向量，再加权混合。
- CMC 成功才提交时间／相位；pure evaluator 不写 clock。缺失、非法或 stale 来源不进入 Fixed，也不取单侧资源替代。
- 合法零速、极小有限非零方向及零 Scale 保留；混合向量抵消为零不结束 GA／TurnBack，不假造默认前向。

这是 CMC move 的源混合上下文，未复制 AnimGraph 节点的滤波／Marker 缓存；表现 clock 按当前 Player 行为保留，不能声称最终整图曲线或物理／表现完全同相位。

### 7.2 动画形状必须决定移动的动作

Stop／TurnBack 暂存原 Origin／Input，在原 RMS 的实际 Prepare 区间内由 CMC 调纯源求值并一次 Consume。单段完成、Stop 自然退出和 TurnBack 分相位保留既定语义；不根据最终混合零向量推断窗口结束。

普通 replay 用原 binding／输入／实际区间；authority replay 保留原合法绑定与 native interval，清旧派生 Prepared，在权威基线上重新求值。导入 Origin、完整 authority／proxy 匹配和联机动态仍未关闭。

动作攻击位移见 [[Movement/动作曲线执行]]、[[Movement/计划_移动与动作位移|动作职责与验收]]。PlayerCombo 显式解析原 Montage／Slot／Main 的 action source binding，按原播放 snapshot 调 `BeginMontageActionMotion`；GA持句柄，Section／完成／失败时精确释放，End受理移动取消经 `CancelMontageActionMotionForMovement`。CMC 在原模拟区间读取 PosXYZ 差并执行胶囊，不从最终 Slot pose 或 Body Z 自动推导目标。GA_Dodge 仍是占位。

### 7.3 原生动作姿态与必需依赖

组件对齐不能再把整个 Body Z 固定。当前 `FGGYGOAnimNode_ActionPoseSlot` 在原生 Slot 输出上，借用同次实际参与 Source 的残差，扣原当前 Mesh 参考贡献并加原组件对齐；只写 Body translation，保留动作相对 Trajectory 的 Z。最低能力为非 Additive／均匀混合、固定当前 Mesh 参考祖先和真实 CompactPose 必需骨，不扩展为任意混合模式。

Guard GT 检查真实原生 Montage 输入，发布原 provider／native UpdateCounter 与能力诊断；worker 只消费该发布和本轮原生权重。Task 在 Ready 前 Acquire 并注册失败消费者，Required-only native Tick Poll；失败先清原 Task 资源再历史 OnFailed，由 GA认证原 Activation／step／Task／资源并强制 End。RequiredReady不保证未来pose成功，None也不能绕过已经使用的correction producer。精确算法、epoch／故障基线、失效与清理见 [[Animation/动作姿态修正]]、[[GGYGO_流程_动作姿态修正.canvas|动作姿态子流程]]。

## 8. 线程与时序

source 解析／发布／撤销、StateCapture及Guard输入能力发布在原游戏线程生命周期进行；pure evaluator在CMC原模拟调用中读显式源数据。动画worker沿原Slot评估同次pose、校验原native traversal并清借用Source标量，不读取CMC／ASC、GT MontageInstances或受保护的montage evaluation array。

不新增 Tick 管理器、全图历史、最终曲线 publisher 或动画侧第二 motion clock。是否更改 Player 时间／Marker／notify 行为属于后续可见选择，本次保持现状。

## 11. 必测场景

## 12. 非目标

本轮不扩大到 Linked Layer、Motion Matching、Warping、完整 Graph rollback 或 GA_Dodge；不以 Asset 保存、源码 push 或普通烟通过替代完整姿态、其他攻击或网络验收。普攻资产与播放窗口见 [[Animation/普攻动画实施]]，当前必要测试及失败边界见 [[Animation/动作姿态修正#7. 实际证据与未验证边界|证据入口]]，跨模块规则见 [[计划_玩家普攻连段]]。
