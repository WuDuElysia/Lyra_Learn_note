## 撤销与失败边界

UE5.8 重应用 `ApplyToAnimationSequence` 有包围旧 Revert 和新 Apply 的事务；`LogAnimation` 冲突错误使重应用回滚并保留旧 applied snapshot。

显式 `RevertFromAnimationSequence` 会先移除 applied 实例，回调后回收，**没有同样的失败回滚**。检测到人工修改时资产内容被保留，但自动撤销快照随引擎流程丢失，须从原来源/备份恢复或人工处理。低层恢复 API 失败也不能承诺显式撤销跨字段原子性。旧破坏性应用没有快照，拒绝伪造恢复；旧 verify-only 撤销无操作。

生成器只保存本次新建对象。部分保存失败会保留已保存的部分产物及可能的脏内存对象；报告失败，先明确处理再重试，不能用 SaveAll 掩盖。Python 检查返回值及磁盘存在性，不等于已完成真实 UE 重载验收。
