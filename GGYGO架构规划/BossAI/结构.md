# BossAI：结构与接口

> 结构图：[[GGYGO_结构_BossAI.canvas]] · 战斗流程：[[GGYGO_流程_BossAI.canvas]] · 子图：[[GGYGO_流程_Boss选招.canvas]]、[[GGYGO_流程_Boss换形态.canvas]]

| 类 / 数据 | 跨模块关键接口 | 当前状态 |
| --- | --- | --- |
| `AGGYGOBossEncounter` | `SpawnBoss`、`GetBossState`、`GetBossAvatar`、`GetBossController` | 已实现：一处创建宿主、Pawn 与 AIController。 |
| `AGGYGOBossState : AGGYGOCombatantState` | `InitializeFromDefinition`、`GetCurrentFormTag`、`GetCurrentPhaseTag` | 已实现持久 ASC 与复制标签；阶段/形态的完整切换事务仍待实现。 |
| `UGGYGOBossDefinition` / `UGGYGOBossActionSet` | 形态/阶段配置、候选动作表 | 定义可授予能力与语义动作候选。 |
| `AGGYGOBossCharacter` | PawnExtension、MeleeTrace | 当前形态的 Avatar；可在后续换形态时被替换。 |
| `AGGYGOBossAIController` | `InitializeDecisionStream`、`GetActionWeight`、`DrawActionWeight`、`RecordActionSelection` | 已实现确定性选招基础，不持有 ASC。 |
| `UBTTask_GGYGOChooseBossAction` / `UBTTask_GGYGOActivateAbility` | ActionTag 选择 / GAS 激活与结束等待 | 已实现 BT 到 GAS 的语义桥。 |
| `UGGYGOBossMeleeAbility` | Montage Event、MeleeTrace、伤害 GE | 已实现近战竖切。 |

当前装配是 `BossEncounter → BossState(Owner/ASC) + BossCharacter(Avatar) + BossAIController(Brain)`。决策层只输出 `ActionTag`；[[AbilitySystem/结构|ASC]] 负责激活和伤害，[[Movement/结构|CMC]] 负责移动。目标/仇恨、转阶段、替换 Pawn 的完整事务是 [[计划_BOSSAI]] 的后续阶段，相关子图明确标记为目标设计。
