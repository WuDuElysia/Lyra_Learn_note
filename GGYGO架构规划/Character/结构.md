# Character：结构与接口

> 结构图：[[GGYGO_结构_角色与组件.canvas]] · 初始化流程：[[GGYGO_流程_角色初始化.canvas]] · [[GGYGO_流程_Pyrios渲染.canvas|Pyrios 渲染流程]] · [[渲染实现]] · 文字计划：[[计划_角色与组件]]

| 类 / 组件 | 对外关键接口 | 关系 |
| --- | --- | --- |
| `AGGYGOCharacterBase` / `AGGYGOHeroCharacter` | Pawn、ASC 查询、组件入口 | 基础 Avatar 与玩家派生；战斗状态的宿主可在 Pawn 外。 |
| `UGGYGOPawnExtensionComponent` | `SetPawnData`、`InitializeAbilitySystem`、`UninitializeAbilitySystem`、ASC 初始化/卸载委托 | PawnData 与外部 ASC 的装配边界；实现 InitState，不决定宿主必须是哪一种 Actor。 |
| `UGGYGOHealthComponent` | `InitializeWithAbilitySystem`、`GetHealth`、`GetPoise`、`StartDeath`、`FinishDeath` | 订阅 HealthSet 变化并发布生命、韧性和死亡事件。 |
| `UGGYGOHeroComponent` | `InitializePlayerInput`、`DetermineCameraMode`、`SetAbilityCameraMode`、`ClearAbilityCameraMode` | 玩家专属输入绑定、能力重试缓冲与相机模式所有权。 |
| `UGGYGOCharacterMovementComponent` | `SetMovementSet`、`HasMoveInput`、`GetHorizontalSpeed` 等 | CMC 权威的移动状态；细节见 [[Movement/结构|Movement]]。 |
| `UGGYGOPyriosRenderComponent` | `BeginPlay`、`RefreshMaterials()`、`TickComponent`、`EndPlay` | `AGGYGOHeroCharacter` 的默认子组件；按 Pyrois Mesh 槽位生成 MID，向 Toon 材质传主光方向、颜色、受限强度和角色级遮挡，并管理随骨骼姿态的描边 Mesh。其他 Mesh 无匹配时不替换材质。 |
| `UGGYGOPawnData` | ASC/能力/输入/相机/移动配置 | 装配数据，`DefaultCameraMode` 由 HeroComponent 读取。 |

玩家路径是 [[Teams/结构|CharacterSlot]] 持有 ASC，Boss 路径是 [[BossAI/结构|BossState]] 持有 ASC；两者都调用 PawnExtension 的 `InitializeAbilitySystem(InASC, InOwnerActor)` 把当前 Pawn 设为 Avatar。`UGGYGOHealthComponent` 通过这条初始化链拿到属性集。HeroComponent 只在玩家角色上负责输入与相机，不是 Boss 必需组件。

相机组件与模式栈关系见 [[Camera/结构|Camera 结构]]，能力状态接口见 [[AbilitySystem/结构|AbilitySystem 结构]]。结构图只列跨组件协作的接口，InitState 的执行顺序留在流程图。

## Pyrios 渲染组件

`AGGYGOHeroCharacter` 构造时创建 `StylizedRenderComponent`，所以 `BP_PC_Pyrios` 继承该组件。它在 `BeginPlay` 取得角色 Mesh，`RefreshMaterials()` 按槽位将 Body 1、Body 2、Weapon 的材质替换为生成的 MI 对应的 MID。显式 `MaterialSlots` 可覆盖自动选择；换 Mesh 后需调用 `RefreshMaterials()`。FX01 槽位仍用原材质。

`UpdateLighting()` 从可指定或场景首个 `ADirectionalLight` 读取主光方向/颜色/强度，将光强按可配置参考值、响应和上限映射到 `SceneLightStrength`，结合一次角色级可见性射线写入 MID；默认每 0.1 秒更新。`UpdateOutline()` 创建跟随原 Mesh Pose 的反面扩张描边 Mesh。材质采用 Unlit/Emissive 的卡通光照，场景仍可使用 UE 光照；Lumen/Skylight/点光不会直接驱动该角色材质。该组件不参与 PawnExtension 的 ASC InitState，也不写 CMC/ASC。材质资产、限制与验证见 [[渲染实现]]。

Pyrois 骨骼模型的 Body 1、Body 2、Weapon 默认槽位已直接绑定三个 Toon MI；`BP_PC_Pyrios` 没有 Mesh 材质覆盖，因此编辑器打开模型或角色蓝图时就能预览表面材质。`BeginPlay` 再为运行时主光参数创建 MID，并创建描边壳；静态编辑器视口使用 MI 中的基准光强，不生成描边壳。
