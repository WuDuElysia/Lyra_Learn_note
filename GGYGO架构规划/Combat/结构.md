# Combat：近战判定结构与接口

> Combat 管查询、原窗口身份、采样、去重与命中订阅；GA 管自身 Activation 和资源生命周期，GAS 管 GE／Execution／AttributeSet 结算。

> [[GGYGO_结构_Combat.canvas|结构图]] · [[GGYGO_流程_Combat.canvas|判定流程]] · [[AbilitySystem/GGYGO_流程_伤害结算.canvas|后续伤害流程]] · [[AbilitySystem/计划_玩家普攻连段|玩家连段配置]] · [[计划_实施状态|任务与验收记录]]

`UGGYGOMeleeTraceComponent` 位于 `Combat/HitDetection/`，Legacy 与 Owned 共用一份活动窗口、采样、去重和 Tick。Legacy 的 `BeginTraceWindow(StartSocket, EndSocket, Radius)`／`EndTraceWindow()`／`OnMeleeHit(HitActor, HitResult)` 保留蓝图签名；活动 Owned 窗口存在时，Legacy 开关明确拒绝。Owned 以 `FGGYGOMeleeTraceWindowHandle` 校验原窗口，只分发携原窗口身份的原生命中回调，不广播全局 `OnMeleeHit`。组件报告碰撞候选，不决定伤害数值、不直接修改目标属性。

## 查询形状与逐帧采样

`FGGYGOMeleeTraceShape` 的 `RootTip` 必须一链两点；`SocketChains` 至少一链、每链至少两点。各链的有序 `Socket/Bone` 均来自角色原主 Mesh，相邻点构成查询段；`WorldRadiusCm` 是固定世界厘米，不随骨骼或组件 Scale 改变。RootTip 参数入口转换成同一 Shape，空配置或非法模式明确拒绝，不借旧字段或另一模式补齐。TraceChannel 决定碰撞响应，默认 `ECC_Pawn`；查询忽略 Owner。

`PerformTrace` 的单帧流程如下：

1. 核原窗口 serial、Owner／World／Mesh／MeshAsset 身份，再由 `ReadTraceShapeFrame` 读完所有链的控制点、坐标与动画缓存，检查基线拓扑及整个窗口预算。任一链无效时先拒绝整帧，不能让前一链先产生命中；缺 Socket／骨骼／缓存不退回原点。
2. 每段按 `N=max(1,ceil(max(上帧段长,本帧段长)/WorldRadiusCm))` 分段，含两端共 `N+1` 个采样点。所有链／段共享 `MaxTraceSegments+1` 次 Sweep 预算，重复端点也计入；默认 `MaxTraceSegments=64`，合法范围1..512。超预算或非有限值先诊断并关闭原窗，不先执行部分 Sweep。
3. 首帧共同保存全链 `PreviousPoints` 基线，不生成命中。后续帧对每段各采样点执行上帧→本帧的 `SweepMultiByChannel` 球扫，显式请求 PhysicalMaterial，同一 `FHitResult` 供后续伤害衰减与表面 Cue 使用。
4. 所有链共用 `HitActorsThisWindow` 弱引用 Actor 去重；同窗同 Actor 只分发一次，新窗可再次命中。Legacy 广播 `OnMeleeHit`，Owned 分发原窗口订阅。每次外调后复核原窗口和借用资源，失效立即停止旧分发／扫掠／基线回写；原窗仍有效才更新 `PreviousPoints`。

帧间运动按直线近似，大角度旋转不还原武器真实弧线。组件不判断 GA Activation 或目标业务资格；[[BossAI/结构|BossMeleeAbility]] 与 [[AbilitySystem/结构|PlayerCombo／共享载荷]] 消费命中，材质标签归 [[Physics/结构]]。

## 原窗口身份与清理

唯一 `uint64 WindowSerial` 每次成功开窗递增，关闭不递增、不重置；耗尽返回 `SerialExhausted`，禁止回绕复用。`bIsTracing` 与 serial 共同校验原窗；`ActiveShape` 保存原窗配置，`WindowMesh`／`WindowMeshAsset`／`WindowWorld` 以弱身份借用原资源。身份或资源变化时退出旧业务，不把后继窗口当作原窗口。

私有 `CloseCurrentTraceWindow` 统一清理：先使原窗失效并脱离其订阅，清除 Shape、借用资源、`PreviousPoints`、baseline 与本窗去重并停 Tick，最后释放原回调持有资源。`EndTraceWindow` 只清 Legacy；`CloseOwnedTraceWindow` 只清匹配的 Owned 原窗。内部判定失败及 `Deactivate`／`OnUnregister`／`EndPlay` 复用私有入口；生命周期清理栈内拒绝重入开窗，重复关闭幂等，重新注册不继承旧状态。Trace 使用 Combat 自有日志，不依赖 GAS，也不拥有伤害、位移或能力终止机制。

### 原窗口公开接口

原生接口在 GameThread 调用，不新增第二窗口状态。句柄只由组件签发，保存签发组件弱身份与 serial，可复制、比较；`HasWindow()` 仅表示曾签发，当前资格须查询。没有“取得当前窗口句柄”接口或历史结束原因缓存。

| 接口 | 输入 → 作用 → 结果 |
| --- | --- |
| `ValidateTraceShapeDefinition(Shape, OutError)` | 纯配置拓扑／点名／半径 → 静态校验 → bool／具体原因；不依赖 Actor／World，不记录日志或改窗口。 |
| `ValidateTraceShapeOnCurrentMesh(Shape, ExpectedMainMesh, OutError)` | Shape 与 Owner 当前原主 Mesh → 只读核全部点、坐标与整窗预算 → bool／原因；不签句柄、不 Sweep、不建基线。 |
| `TryOpenOwnedTraceWindow(Shape, ExpectedMainMesh, ExpectedWindow, OutWindow)` | 空 Expected 只取空闲窗口，非空只替换本组件仍活动的同一 Owned 窗口。先快照配置／原资源／Expected 再清 Out，允许 Expected／Out 别名。成功返回 `Opened` 与新句柄；旧身份／窗口冲突返回 `WindowConflict`，非法／异组件预期返回 `InvalidExpectedHandle`，不改当前窗口。获准替换后配置／可用性失败结束原窗并返回 `InvalidConfiguration`／`Unavailable`；身份耗尽为 `SerialExhausted`。失败 Out 为空，不接管 Legacy。 |
| `TryOpenOwnedTraceWindow(StartSocket, EndSocket, Radius, ExpectedWindow, OutWindow)` | RootTip 参数 → 转换 Shape 并取当前主 Mesh → 进入同一 Owned 开窗规则，不另建执行器。 |
| `CloseOwnedTraceWindow(Window)` | 确切原窗 → 匹配才清理并返回 `Closed`；结束／替换后为 `AlreadyInactive`，空句柄／异组件为 `InvalidHandle`／`WrongComponent`。不触碰后继，不回落无身份 End。 |
| `QueryOwnedTraceWindow(Window)` | 原句柄 → 核签发组件、serial 与 Owned 来源 → `Active`／`Inactive`／`InvalidHandle`／`WrongComponent`；Inactive 包含已结束或被替换，不猜 Activation。 |
| `SubscribeWindowHit(Window, Callback, OutSubscription)` | 确切活动 Owned 窗口与已绑定回调 → 注册独立 `FDelegateHandle` → `Subscribed`；其余返回 `InvalidHandle`／`WrongComponent`／`WindowInactive`／`InvalidCallback`，输出为空。`FGGYGOMeleeTraceWindowHitDelegate` 携 `(OriginalWindow, HitActor, HitResult)`，开窗／订阅不同步命中。 |
| `UnsubscribeWindowHit(Subscription)` | 确切 token → 先从成员容器移除、再释放回调资源 → 成功 true，不存在／已清理 false。窗结束自动退订；旧 token 不移除后继订阅，不按对象全量解绑。 |

Owned 分发快照原窗口与订阅集合，逐项检查原窗仍活动、资源有效、token 仍在，再外调并复核。已退订成员跳过；新增订阅从后续命中开始。若 B 回调关 B、开并订阅 C，立即中止 B 后续分发／扫掠／回写，C 首次 Tick 自建基线。消费者核注册时的原 Activation、原资源来源与回传窗口，不用回调时可变的“当前 Activation”补认领。Legacy 无调用者窗口身份；Combo／Boss 使用 Owned，不复播旧全局事件。

### GA 消费与原资源归还

窗口身份、查询、baseline、去重和 Tick 唯一归 Combat；GA 保存的窗口／token 是原 Activation 所持资源，不是另一份窗口权威。Activation、结束／取消与完成发布归 [[AbilitySystem/结构|GAS共同生命周期]]；Montage／输入／位移／FX 资源由各自所属机制管理，Trace 不新增 GA 状态、计时器或第二执行链。

| 消费者 | 开窗／命中／清理契约 |
| --- | --- |
| `UGGYGOPlayerComboAbility` | 认证 Montage Hit 窗口事实 → `OpenTraceWindow(Resource, Declaration)`：先 `ReleaseTraceWindow(Original)` 归还原段资源，再以 `Step.TraceShape`／原 Mesh 取得 Owned 窗并订阅。回调捕原 Activation、step token、原 Task／Trace 与 OpenedWindow，核段／来源、回传窗与 `QueryOwnedTraceWindow==Active` 后进入 `HandleMeleeHit`。End 事实须匹配原 `Declaration`；换段也只释放原窗。`CleanupAbilityResourcesForTermination(Context)` 匹配原资源 Activation 后先快照并脱开成员，再精确退订／关窗并归还自身其他资源。 |
| `UGGYGOBossMeleeAbility` | 认证 Montage Hit 窗口事实核原 Task／资源批次；原窗 Active 时重复 Begin 保留去重，Inactive 才归还并重开。RootTip 使用 `TraceStartSocket`／`TraceEndSocket`／`TraceRadius`；`FOriginalMeleeResources` 持 Original、原 Trace、Window／WindowHits 与声明来源。弱回调在 `HandleOriginalMeleeHit` 核原批次／Activation／Trace、回传窗及权威。`CloseOriginalTraceWindow(Resources)` 先脱批次窗口／token，再精确退订／关窗；共同 Cleanup 匹配 Context 后脱开整个原批次，归还自己持有的资源。 |

开窗／订阅失败明确诊断，由消费者按原生命周期拒绝或终止；不借 Legacy、别的窗口或别的能力继续。命中由消费者核原 Activation／来源与权限；终止清理按原 Context 资源归属执行，不用 GA 的可变当前状态重新认领。

### GA → Builder／GE／Cue

有效原命中 → GA 将同次 `HitResult`、目标 ASC、所选 GE 与**命中回调时原 Avatar 当前位置**送入 `BuildHitEffectPayload` → Builder 统一构造 Context／可选 Spec／Cue，并追加 Owner／物材 Tags。`AddHitResult(reset=true)` 后再写显式来源快照，Context 的距离为 Origin→ImpactPoint。Builder 不提交伤害；Caller 按配置校验并填入 SetByCaller，再由 GAS 的 GE／Execution／AttributeSet 链结算。

显式无 GE 是 Combo 的正常 Cue 模式；Boss 要求 ResolvedGE 与有效必需 Spec。Combo 必需 GE、Builder 或返回 Spec 的业务输入失效时，诊断后以 `RequestAbilityEnd(Original, true, true)` 结束原动作；即使用户取消被禁用，也不继续错误业务。Boss 伤害类／Builder／必需 Spec 失败只拒绝本次 hit。有效载荷的 GE 免疫／应用拒绝保持既定碰撞 Cue 政策。数值、配置模式与这些响应归 GA／GAS；Trace 只报告同一 `HitResult`。
