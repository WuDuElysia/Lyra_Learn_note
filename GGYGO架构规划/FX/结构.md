# FX：发布、复制与远端表现

## 职责与状态归属

| 类／数据 | 所有权与接口 |
| --- | --- |
| `UGGYGOMontageFXReplicationComponent` | CombatantState 的默认组件；持有复制的 `State` 和本机 `PublicationOwner`，认证发布来源，接收 `OnRep_State` 与可靠 `MulticastTerminal`。 |
| `UGGYGOMontageFXPublicationOwner` | 持有当前发布键、本地资源事实与远端 generation；只按原 lease 关闭，隔离旧资源和同键后继。 |
| `FGGYGOMontageFXRecord`／`State`／`Terminal` | Record 含 Occurrence、BeginServerTime、原 Avatar／Mesh／System、变换、停止策略与 seek 预算；State 复制当前 ActiveRecords；Terminal 含 Occurrence、CloseRevision、Normal／Abort。 |
| `FGGYGOMontageActionResources`／`UGGYGOLocomotionFXComponent` | 分别持有能力窗口和普通移动产生的 lease，在自身资源结束时关闭；不转交 ASC 扫描。 |
| `UGGYGORemoteMontageFXComponent` | 持有原实例的 Niagara Controller、服务器起点和原渲染／时间配置；同一原生 Tick 负责远端进度与可见性。 |

## 单元附着配置

`FGGYGONiagaraEffectUnit` 的 `bOverrideAttachment` 默认为 false，此时继承动作窗的 Socket／Transform；启用后使用单元自己的 `SocketName`／`LocalTransform`，替换整组默认值。空 Socket 表示原 Mesh 根。具体角色挂点由 GA 资产配置，C++ 不决定招式挂在哪根骨骼。

`ResolveAttachment(DefaultSocket, DefaultTransform, OutSocket, OutTransform)` 是纯配置解析。本地 `PlayNiagaraEffects` 与 `MontageActionResources` 发布记录使用同一解析结果。`ValidateFXSocketsOnMesh(Config, Mesh, OutError)` 由动作入场和窗口消费共用：Attached 只核对解析后的实际挂点，全部单元覆盖时不要求未使用的默认挂点存在；有继承单元时仍核默认挂点。World 保留动作起点校验，独立挂点仍由配置准入拒绝；无效变换明确失败。正常结束与打断继续使用原单元停止策略和资源关闭链。

配置回归及单机 D3D12 武器随动、自然结束和取消已验证；本次独立挂点的真实联机与 Cook 尚未验证。材质准备仍由 [[Character/结构|角色原资源准备入口]] 管理。

## 发布与关闭接口

`FindForASC(ASC)` 从 ASC 的 Owner 找复制组件。`PublishMontageFX(Ability, Activation, Task, BeginFact, Request, OutLease, Error)` 认证原权威 GA／Task 的同步窗口事实；`PublishLocomotionFX(Movement, CompletedInterval, Request, OutLease, Error)` 认证 CMC 完成区间。成功只表示发布并取得 lease，不表示 Niagara 已就绪或已经显示。

持有者以 `PrepareClose(Lease, Reason, OutObligation)` 改写原发布状态，再在安全出口 `DispatchClose` 派发。组件注销调用 `Shutdown`：尚未归还的 lease 按 Abort 关闭并诊断。客户端 `ReceiveState` 调和活动记录，`ReceiveTerminal` 只终止对应键；闭窗后首次相关性没有活动记录可重建。

## 远端年龄与资源生命周期

远端目标年龄来自 `GameState.GetServerWorldTimeSeconds() - BeginServerTime`。活动期间保持 Solo 和 DesiredAge，用记录中的原生步长及 CPU 预算追赶；实际 Controller Age、执行状态、材质与原 Mesh 均满足条件后恢复渲染。曾经 reached 不代表当前年龄已经追上；预算不足时再次隐藏。渲染状态同时提交给原 Niagara 场景代理，不增加模拟 Tick。

正常闭窗按资产配置的 StopMode 交接。有效活尾恢复原时间模式、清除 seek 标记并恢复原渲染值，继续由同一 Solo Tick 推进至自然完成。未 reached 的实例立即销毁；Abort 使用独立配置的停止策略。Actor 退役、组件销毁与同键重获以 generation 隔离，旧资源归还不触及新实例。

`CanRestore(Occurrence, Generation)` 认证当前远端资源，`RemoteDestroyed` 只归还对应代次。Editor 观察窗口和 `UGGYGOPlayerActionObservation` 只读取发布、复制、年龄、通道与生命周期事实，不授予播放或关闭权限。
