# GameFeature / Experience：结构与接口

> 结构图：[[GGYGO_结构_GameFeature.canvas]] · 启动流程：[[GGYGO_流程_GameFeature.canvas]] · 文字计划：[[计划_GameFeature]]

| 类 / 数据 | 关键接口 | 责任 |
| --- | --- | --- |
| `UGGYGOExperienceDefinition` | GameFeature 列表、默认编队 | 一局的装配数据，不是角色运行状态。 |
| `AGGYGOGameMode` | `InitGame`、`ActivateGameFeatures`、`HandleStartingNewPlayer`、`SpawnSquadForPlayer` | 服务器装配入口；等待异步插件激活结束后再生成玩家队伍。 |
| `UGGYGOPawnData` | PawnClass、AbilitySet、输入/相机/移动配置 | 每个角色的装配描述。 |
| `UGGYGOAssetManager` | 共享资产获取 | 项目级资产入口，约束见 [[模块参考]]。 |

GameMode 按 Experience 加载 GameFeature，再按 [[Teams/结构|Teams]] 的 `Roster`、存档预设或默认编队选择成员；创建 Slot 和 Pawn 时分别接入 [[AbilitySystem/结构|ASC/AbilitySet]] 与 [[Character/结构|PawnExtension]]。`PendingGameFeatureCount` 非零时玩家生成延后；失败回调也会结清等待计数。插件中的组件注入属于 UE GameFeature 生命周期，不能在结构图中画成 GameMode 的成员类。
