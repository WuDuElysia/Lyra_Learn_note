## Hero本地ASC身份订阅与原H清理

Hero 的 H 关联与 native Session 是两个生命周期。H Ready 只使既有输入可向原 ASC Receive；原组件／绑定／IMC 仍由自身 Session 管理，ASC 请求与 Spec held／许可／等待仍归 ASC。

| --- | --- |
| `PrepareLocalAbilitySystemSubscription(Extension, OutError)` | 原 Pawn／Extension；先持原订阅记录再注册 typed Notice，同步回放及晚返回 token 始终归该记录。成功仅订阅，不保证 Ready。 |
| `GetReadyLocalAbilitySystemComponent()`／`GetInputSessionAbilitySystem()` | 前者只读已接收原 opaque H 的真实 Ready／PublishedContext；后者还核对既有 native Session 的精确 H 关联。相同 ASC/Pawn 指针不能替代后继 H。 |

| 记录 | 持有的来源与资源 | 失效／清理责任 |
| --- | --- | --- |
| `FPlayerInputSession` | 原 Component／Subsystem／PlayerInput／ForceWalk CMC 弱身份、native generation、绑定句柄、自身 IMC 注册、Action 绑定与观察 | 自身 Release 先摘并退休记录，再精确归还原绑定、注册及所属请求。 |

**Closing** 是原 H 失去本地输入资格的事实：Extension EndPlay 先关准入、Host 释放之前发布；普通 Withdraw 先摘原槽并标记未安装，再发布。每个 H 只发布一次，Context 为空，不证明 native Cancel／Clear 成功。Hero 匹配原订阅／H 后先退休 association／observations，再 exact End 原 SourceASC 的 ID；独立 native Session、绑定、IMC 与活动 Action 首观察锁存保留。Closing 不推断相机／CMC／物理 Source 资源所有权，也不制造 Released 或成功结果。

**Released** 仍是独立的本地撤回通知。匹配原 H 后捕获原 Session／Pawn／Camera 及输入、镜头代次，撤 H 与弱归还来源；确实拥有原 native Session 才 `ReleasePlayerInput`，仅有原 H 关联则只精确 End。汇合后复核原记录仍当前、H 槽空、预期 native Session／代次及镜头代次未变，再清原 overrides 并只 Reset 捕获的原 Camera。无 Controller／InputComponent 不阻止原镜头撤回；后继 H、输入或镜头请求使旧尾部停止。

H Closing／Released 均不等于能力 Action Released 或物理移动 Released。Hero 自身 EndPlay 独立归还全部自持资源；[[Character/结构#Host原生请求接口（已定义，生产迁移中）|Host／Extension]]拥有本地 H 与原生编排，[[AbilitySystem/结构|ASC]]拥有 ActorInfo／publication 及输入请求权威。

### 原绝对期限与 ASC 唯一等待

首次真实 Action 观察固定 `OriginalDeadline = WorldTime + InputBufferWindow`，同 Action 的重复 Triggered、拒绝、Ready／重绑或重试都不续期。正常 Action End 的 `Released` 不受 deadline 门禁；期限只控制有限重试，不能伪造 held 释放。OnInputTriggered 的短按在首期限内可有限重试；WhileInputActive 有限重试还须真实 held，普通 held Process 不借有限重试许可。

ASC 只由冻结的真实 Try／Can Queued 失败给原请求／Spec 授许可；许可在 `Super::NotifyAbilityFailed` 外调前提交，外部观察通知保留在 Super 返回后并重验。真实 GroupFreed 先快照并消费整个原有序等待集合，active／blocked／expired／拒绝候选也消费；只有新的实际 Queued 失败才再次入尾。等待次序不是请求身份或时钟，不按 GroupTag 猜配、不增加 Tick／Timer／每帧等待扫描。下一次既有 Process 花掉旧许可后再 Try，同 Spec 在该 Process 最多一次；新的真实失败才续授许可。Hero 的旧缓冲及生产 Retryable／GroupFreed 订阅已退役，公用 delegate 仍可供只读诊断观察。
