## 职责与接口契约

- GA决定动作选段、作者信号后的打断权限、接续政策和所持资源；原Task管理Montage实例、原Point事实／播放快照与必需Pose资源，Animation发布原资产绑定并修正身体姿态，CMC唯一执行胶囊，不持攻击门或Main／End阶段。纯求值层没有状态／时钟，RMS只持原资源与native时间。不读取BossAction／BT，不以最终AnimGraph混合曲线取得移动权限。
- 同一CMC仅一个动作执行槽；原Handle／原Montage实例／Owner／Source身份必须匹配，旧释放／失败不能清后继。必需源／PosXYZ曲线／Pose声明缺失或失效时明确失败，中止自身动作，不选默认Profile、Slot或另一能力。
- 两种明确配置模式：当前普攻 `OriginalMontage` 模式执行XYZ；兼容业务 `Profile` 模式只在服务器地面执行XY。模式由明确请求决定，不能因原Montage失败自动切换。

### 当前普攻：原 Montage 来源与 CMC 接口

Animation `BuildSourceBindingRange(Montage, Slot, Main, End, OutSource, Error)` 建立 `FGGYGOActionMotionSourceBinding`：原Montage／Slot、有序 `Sections`、分段Sequence、裁剪／loop／rate和完整请求范围。首段名仍由原 `SectionName` 表达，单段 `BuildSourceBinding` 保留明确单段语义。PlayerCombo 当前要求相邻 Main／End 两段并固定原 Task 路由；End 中校正启动可使用同一范围绑定的当前位置，剩余时长读取实际资产。

Task的原实例快照提供当前Section／Position／有效PlayRate；绑定不是另一份播放进度。`GGYGOActionMotionEvaluation::EvaluateInterval` 将 native 实际Montage区间映射到原Sequence分片，读取必需累计 `RootMotion_PosX／RootMotion_PosY／RootMotion_PosZ`，逐源／逐loop累加 `P(t1)-P(t0)`；跨段累计曲线归零不作为同一源的大跳变。失败Reset输出并保定位原因。

原始 `Segment.MontageEndSeconds` 仍精确保存 `GetEndPos()`；仅真正最后段且请求结束于整个Montage终点时，Animation私有映射可认证原生末端量化：差异至多两float ULP，保存的CommonTarget帧域Round必须逐位命中 `GetPlayLength()`；Editor未Cook还核原DataModel帧域。Build／Expected验证／Map共用该规则，最终源坐标仍是完整原 `AnimEndTime`。内段gap／overlap、较大尾差、非法速率或无法表示的loop仍拒绝；Movement与网络字段不改成另一套终点状态。

| 接口／调用者 | 关键输入 → 输出、作用与清理 |
| --- | --- |
| GA → `BeginMontageActionMotion(Source, InstanceId, Position, EffectiveRate, TranslationScale, OutHandle, OutError)` | 活authority或原本地autonomous、原实例仍播放绑定范围内当前Section、位置／固定速率有效，且Walking／NavWalking／Falling；验证native动画RootMotion互斥。冻结入口Actor旋转及Mesh组件Scale×业务Scale，安装同一ActionCurveRMS的OriginalMontage模式，返回精确Handle／明确失败。 |
| RMS → `PrepareRootMotion(SimulationTime, MovementTickTime, Character, CMC)` | native时间映射到原Montage区间，纯求值PosXYZ；`WorldDelta = EntryActorRotation.RotateVector(Delta * capturedScale)`，再除MovementTickTime输出Override XYZ。Mesh旋转不再次参与，缩放只乘一次；零位移继续持资源，尾帧clamp保留。 |
| GA → `ObserveMontageActionMotionFailure(OriginalHandle, Callback, Error)` | 注册原动作唯一失败接收者；运行期源／原实例／速率失效只通知该原资源。Release先撤原失败接收者，再外部清理，不能清后继。 |
| GA → `ObserveMontageActionMotionCompletion(OriginalHandle, Callback, Error)` | 注册原资源唯一完成接收者，回传精确原Handle。只有最后Prepared区间已被原生移动消费且AfterMovement结束才发布；原完成事实可一次迟到Replay，第二接收者拒绝。取消／替换／Owner退役精确清原回调，历史回放不重新发布。 |
| 原 Task 非 Interrupted BlendOut → `NotifyMontageActionNaturalBlendOut(OriginalHandle, OriginalInstanceId, Error)` | 认证原Handle／实例及配置末段auto-blend窗口，准许同一native时钟继续有限尾区间；不是位移完成。未消费完成时要求原native实例仍可查；已消费完成的原资源可接受迟到通知且不给新执行权。 |
| 原 Task Completed／GA清理 → `ReleaseMontageActionMotion(OriginalHandle, Reason, Error)` | Completed只接受已认证原Task完成后的有界Drain，返回成功不表示轨迹已完成；保原RMS及完成接收者直至最后区间消费。实际完成后的清理幂等，完成身份有界保留到后继／Owner退役。其他理由中和自己的贡献并撤原接收者；普通Release不恢复旧速度／不清后继Velocity。 |
| 作者信号授权后的 GA → `QueryQualifiedMovementIntent`／`SubscribeQualifiedMovementIntent`／`UnsubscribeQualifiedMovementIntent` | 以原Scope查询／订阅只读合格输入意图；物理资格仍来自Input原Session／Binding／Request，Ready／零轴不能伪造Press。过点时已有Held与门后新Press均可消费；订阅先写出原Observer再同步重放，句柄归原GA资源精确清理。接口不检查Main／End。 |
| 作者信号授权后的 GA → `CancelMontageActionMotionForMovement(OriginalHandle, OriginalIntent, Error)` | 重查仍合格且全字段相等的原Intent，按精确Handle取消原动作；未换Owner或安装后继时才清原水平余速、失效对应原生结果记录，空气Z保留。适用于原轨迹中途，不要求进入End。旧Handle／旧意图不能停止新动作；GA结束并重置连段，普通移动沿原Input和CMC Walk→Run，不硬设Run。 |

OriginalMontage模式取消 `IgnoreZAccumulate`，启用native敏感离地；Walking／NavWalking／Falling、碰撞、重力和落地均由原生CMC执行，未另建PhysFalling／落地判定或Actor逐帧位移。固定速率／原实例／Section／元信息每次使用都验证；未经明确兼容契约的跳段／中途变速不以猜测时间修复。

### Main、End 与身体姿态

PlayerCombo持活原动作资源时，CMC Before跳过普通Locomotion／自动旋转；Main→End保持同一动作Handle／RMS／native时间，End入口不释放轨迹，也不隐式开门。每段以 `InterruptionNotifyName` 配置唯一原生 `UAnimNotify_PlayMontageNotify` 单点，当前名称为 `Event.Montage.CancelPoint`；原Task的 `ConfigureOriginalMontageNotify`／原Notify事实及快照认证精确Mesh、Montage、实例和作者点，普通Hit／Combo Window不授门。

GA仅在该次播放过点后调用 `EnableStepInterruption`，持续允许移动和新攻击至原播放结束；新播放重新关门。早到信号只保原实例事实，原Scope／Handle就绪并重验后才安装观察；非零启动／校正是否已过点只读原Task播放快照，不按End名称推定。过点时已有合格Held或门后新Press经原Scope查询、重验同Intent、精确Cancel清水平余速并保空气Z，再结束原GA／重置连段，沿原输入恢复Walk／Run。新攻击按GA的 `NextStepIndex` 接续，当前三段目标1／2／0，无新请求不自动循环。CMC不持门、攻击段或接续政策；无合法打断请求时完整Main→End继续执行，Pose／来源等必需依赖失败仍中止自身动作。

自然路径有两个独立来源事实：RMS实际区间映射到完整绑定终点；`ApplyRootMotionToVelocity` 经原生应用标记贡献消费，`UpdateCharacterStateAfterMovement` 再发布原Handle完成。原Task Completed则认证该Task播放结束并申请有限Drain。GA先分别保存两个事实，均完成才 `RequestAbilityEnd`；Task先结束、或Motion先结束都使用同一原资源，不借后继实例补认领。native碰撞／落地结果仍由CMC负责，消费完成不承诺绕过碰撞达到未受阻的资产终点，也不另开追补链。

三份 `AM_Pyrios_Attack_Normal_01/02/03` 已恢复完整原End裁剪；原AnimSequence、Main及Hit／Combo窗口保持。自然混出触发点由实际目标源采样率／倍率换算最后一帧，在Montage中配置；混出时长独立配置，当前为0.25秒／HermiteCubic，C++不写死帧长或混合时长。GA沿原watchdog包含实际native混出预算。停播／BlendOut／`GetCurrentActiveMontage()==None` 均不直接代表最后贡献消费完成；其他可瞬时销毁实例的混出模式／极短配置兼容仍需独立验证。

### 显式业务 Profile 兼容模式

`UGGYGOActionMotionProfile` 保留业务累计TranslationCurve（秒、cm、Mesh Component空间、首帧0）／Duration／TranslationScale。GA明确选择后调用Blueprint `BeginActionMotion(Profile, PlayRate)`，仅authority且接地接受，返回Handle或INDEX_NONE；固定入口Mesh旋转／缩放，差分只输出世界XY，`EndActionMotion(Handle)`／自然到期／离地清该资源。Profile不是原动画曲线副本，未参与七旧Locomotion DA退役；当前普攻使用上述原Montage入口。

AI路径暂停仍归调用方，Movement不操作AI攻击流程。Trace／Montage／动作源按各自窗口与原资源清理，不能把某个BlendOut回调等同于所有资源已结束。

## 生产工具操作与证据

1. 离线执行 `AAADocs/Scripts/audit_kevin_action_motion.py`，生成 `Saved/Codex/kevin_motion_source.json`（含源文件 SHA256 和每帧 FBX 位置/四元数）。
2. 完整构建后运行 `GGYGO.BuildKevinMotionAssets audit`。默认只读，报告 `Saved/Codex/kevin_motion_build_report.json` 包含单位/轴/起点、相对旋转、原地残差和原姿态重建误差。
3. 核验通过后运行 `GGYGO.BuildKevinMotionAssets build`。只写带自身归属标记的输出；重复运行由原 AS 重新派生，不对已剥除轨迹重复扣除。已有 Profile 的手调缩放保留。
4. Animation 的 Montage builder 引用派生序列；Combat 的 GA 资产引用 Profile。两者时长/速率需一致，原始序列保持未启用原生 RootMotion。

上述Profile工具模式采用 `P(clamp(t+dt)×rate)-P(clamp(t)×rate)`，转换为世界水平位移后除以movement tick时间。当前OriginalMontage按固定原分片映射并差分XYZ；两种模式都交同一native RMS速度通道，碰撞后不另建追补位移链，native时间是唯一执行时钟。
