## 职责与接口契约

- C++ 提供 `UGGYGOActionMotionProfile` 数据类型、CMC 的 `BeginActionMotion(Profile, PlayRate)` / `EndActionMotion(Handle)` / `HasActiveActionMotion()`，以及独立的 `FRootMotionSource_GGYGOActionCurve`。不读取 BossAction、GA 状态或行为树，不决定攻击招式。
- GA 蓝图/资产决定具体动作是否使用曲线、引用哪个 Profile、播放速率和缩放；GA 保存返回的 Handle，与 Montage 同时开始，并在完成/取消出口清理。GA 不再维护另一份位移时间或速度。
- `BeginActionMotion` 仅服务器权威且接地时接受，失败返回 `INDEX_NONE`；同一 CMC 同时仅持有一个动作源，旧 Handle 无权结束新动作。
- Profile 存储累计位移 `TranslationCurve`（秒、厘米、导入后 Mesh Component 坐标）、`Duration` 与 `TranslationScale`。运行时冻结入口 Mesh 的旋转/缩放，把曲线差分交给 CMC；不消费最终 AnimBP 的混合曲线。
- 首版仅水平地面位移。高度仍由 CMC 地面/重力负责，骨盆高度与 RootQ 旋转保持为动画姿态。暂不支持空中动作、追踪转向、Montage 跳段/中途变速。
- 动作在场暂停本角色的旧 locomotion 曲线采样、Brake/TurnBack 源与 CMC 自动朝向；普通玩家 locomotion 与动作策略保持现有实现。
- 正常 BlendOut 关闭 Trace，位移继续到曲线末尾；Montage Completed 再清理。中断/取消立即清理。零速帧不提前结束；自然超时/离地也必须同步释放 CMC 门控，不能遗留锁。
- AI 路径请求的暂停属于调用方；Movement 不操作 BT/AI 攻击流程。原生动画 RootMotion 与此曲线模式不能同时驱动同一动作。

## 生产工具操作与证据

1. 离线执行 `AAADocs/Scripts/audit_kevin_action_motion.py`，生成 `Saved/Codex/kevin_motion_source.json`（含源文件 SHA256 和每帧 FBX 位置/四元数）。
2. 完整构建后运行 `GGYGO.BuildKevinMotionAssets audit`。默认只读，报告 `Saved/Codex/kevin_motion_build_report.json` 包含单位/轴/起点、相对旋转、原地残差和原姿态重建误差。
3. 核验通过后运行 `GGYGO.BuildKevinMotionAssets build`。只写带自身归属标记的输出；重复运行由原 AS 重新派生，不对已剥除轨迹重复扣除。已有 Profile 的手调缩放保留。
4. Animation 的 Montage builder 引用派生序列；Combat 的 GA 资产引用 Profile。两者时长/速率需一致，原始序列保持未启用原生 RootMotion。

累计采样采用 `P(clamp(t+dt)×rate)-P(clamp(t)×rate)`，转换为世界水平位移后除以 movement tick 时间，交给 RMS 的速度通道。碰撞阻挡后不追补被阻挡的位移。自然结束的门控根据 RMS 状态释放，没有第二份 GA 运动计时。
