## 职责与接口契约

- GA决定动作、Main／End规则和所持资源；原Task管理Montage实例、播放快照与必需Pose资源，Animation发布原资产绑定并修正身体姿态，CMC唯一执行胶囊。纯求值层没有状态／时钟，RMS只持原资源与native时间。不读取BossAction／BT，不以最终AnimGraph混合曲线取得移动权限。
- 同一CMC仅一个动作执行槽；原Handle／原Montage实例／Owner／Source身份必须匹配，旧释放／失败不能清后继。必需源／PosXYZ曲线／Pose声明缺失或失效时明确失败，中止自身动作，不选默认Profile、Slot或另一能力。
- 两种明确配置模式：当前普攻 `OriginalMontage` 模式执行XYZ；兼容业务 `Profile` 模式只在服务器地面执行XY。模式由明确请求决定，不能因原Montage失败自动切换。

### 当前普攻：原 Montage 来源与 CMC 接口

Animation `FGGYGOActionMotionSourceBinding` 固定原Montage、Slot、Section、分段Sequence、裁剪／loop／rate与时间范围。Task的原实例快照提供当前Section／Position／有效PlayRate；绑定不是另一份播放进度。`GGYGOActionMotionEvaluation::EvaluateInterval` 将实际Montage区间映射到原Sequence分片，读取必需累计 `RootMotion_PosX／RootMotion_PosY／RootMotion_PosZ`，累加 `P(t1)-P(t0)`，失败Reset输出并保定位原因。

| 接口／调用者 | 关键输入 → 输出、作用与清理 |
| --- | --- |
| GA → `BeginMontageActionMotion(Source, InstanceId, Position, EffectiveRate, TranslationScale, OutHandle, OutError)` | 活authority或原本地autonomous、原实例仍播放配置Main、源／位置／固定速率有效，且Walking／NavWalking／Falling；验证native动画RootMotion互斥。冻结入口Actor旋转及Mesh组件Scale×业务Scale，安装同一ActionCurveRMS的OriginalMontage模式，返回精确Handle／明确失败。 |
| RMS → `PrepareRootMotion(SimulationTime, MovementTickTime, Character, CMC)` | native时间映射到原Montage区间，纯求值PosXYZ；`WorldDelta = EntryActorRotation.RotateVector(Delta * capturedScale)`，再除MovementTickTime输出Override XYZ。Mesh旋转不再次参与，缩放只乘一次；零位移继续持资源，尾帧clamp保留。 |
| GA → `ObserveMontageActionMotionFailure(OriginalHandle, Callback, Error)` | 注册原动作唯一失败接收者；运行期源／原实例／速率失效只通知该原资源。Release先撤原失败接收者，再外部清理，不能清后继。 |
| GA → `ReleaseMontageActionMotion(OriginalHandle, Reason, Error)` | Completed释放原Main门控，保留尚未消费的最后Prepared贡献及有界完成身份；其他结束理由中和自己的贡献。普通Release不写旧速度／不清后继Velocity。自然结束与Owner退役清自身资源。 |
| GA End → `QueryQualifiedMovementIntent`／`SubscribeQualifiedMovementIntent`／`UnsubscribeQualifiedMovementIntent` | 以原Scope查询／订阅只读合格输入意图；物理资格仍来自Input原Session／Binding／Request，Ready／零轴不能伪造Press。已有Held可在End入口消费，新Press可在End内消费；订阅句柄归原GA资源清理。 |
| GA End → `CancelMontageActionMotionForMovement(OriginalHandle, OriginalIntent, Error)` | 精确原动作／意图仍匹配且无后继时，释放原动作并仅清水平余速、失效对应原生结果记录；空气Z保留。旧Handle／旧意图不能停止新动作。普通移动随后仍沿原Input和CMC Walk→Run，不硬设Run。 |

OriginalMontage模式取消 `IgnoreZAccumulate`，启用native敏感离地；Walking／NavWalking／Falling、碰撞、重力和落地均由原生CMC执行，未另建PhysFalling／落地判定或Actor逐帧位移。固定速率／原实例／Section／元信息每次使用都验证；未经明确兼容契约的跳段／中途变速不以猜测时间修复。

### Main、End 与身体姿态

PlayerCombo Main持原动作资源时，CMC Before跳过普通Locomotion／自动旋转。Task发布原End事实后，GA调用Release(Completed)，进入原End并查询／订阅QualifiedMovementIntent；合格已有Held或新Press经精确Cancel清水平余速，再沿普通移动解算恢复Walk／Run。无合格意图时保留End实际生命周期；Pose／来源等必需依赖失败通过原能力中止入口处理，即使用户Cancel不可用也不继续错误动作。

已保存的 `/Game/BP/Anim/ABP_Pyrios` 为 `MainStateMachine → GGYGOActionPoseSlot(FullBody) → LocalToComponent → ComponentToLocal → Inertialization → Output`，RequiredPoseCorrectionSlot=FullBody、RootMotionMode=IgnoreRootMotion；该次保存其他24图保持。姿态node/provider只管Body／轨迹骨的表现，Task的Acquire／Poll核原Owner／Mesh／provider／声明生命周期；均不写Velocity、不生成Movement请求。身体位移与胶囊XYZ是不同职责，详细表现机制见 [[Animation/动作姿态修正|网格姿态与胶囊边界]]、[[Animation/结构|动画姿态职责]]。

### 显式业务 Profile 兼容模式

`UGGYGOActionMotionProfile` 保留业务累计TranslationCurve（秒、cm、Mesh Component空间、首帧0）／Duration／TranslationScale。GA明确选择后调用Blueprint `BeginActionMotion(Profile, PlayRate)`，仅authority且接地接受，返回Handle或INDEX_NONE；固定入口Mesh旋转／缩放，差分只输出世界XY，`EndActionMotion(Handle)`／自然到期／离地清该资源。Profile不是原动画曲线副本，未参与七旧Locomotion DA退役；当前普攻使用上述原Montage入口。

AI路径暂停仍归调用方，Movement不操作AI攻击流程。Trace／Montage／动作源按各自窗口与原资源清理，不能把某个BlendOut回调等同于所有资源已结束。

## 生产工具操作与证据

1. 离线执行 `AAADocs/Scripts/audit_kevin_action_motion.py`，生成 `Saved/Codex/kevin_motion_source.json`（含源文件 SHA256 和每帧 FBX 位置/四元数）。
2. 完整构建后运行 `GGYGO.BuildKevinMotionAssets audit`。默认只读，报告 `Saved/Codex/kevin_motion_build_report.json` 包含单位/轴/起点、相对旋转、原地残差和原姿态重建误差。
3. 核验通过后运行 `GGYGO.BuildKevinMotionAssets build`。只写带自身归属标记的输出；重复运行由原 AS 重新派生，不对已剥除轨迹重复扣除。已有 Profile 的手调缩放保留。
4. Animation 的 Montage builder 引用派生序列；Combat 的 GA 资产引用 Profile。两者时长/速率需一致，原始序列保持未启用原生 RootMotion。

上述Profile工具模式采用 `P(clamp(t+dt)×rate)-P(clamp(t)×rate)`，转换为世界水平位移后除以movement tick时间。当前OriginalMontage按固定原分片映射并差分XYZ；两种模式都交同一native RMS速度通道，碰撞后不另建追补位移链，native时间是唯一执行时钟。
