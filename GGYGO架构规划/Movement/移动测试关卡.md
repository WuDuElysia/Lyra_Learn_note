# 移动测试关卡

打开 `/Game/Map/L_Movement_Test` 后按 Play，使用项目现有移动输入测试 Pyrios。主场景 `/Game/Map/Untitled` 和默认启动地图配置保持原样。

## 当前资产与接线

| 项目 | 配置 |
| --- | --- |
| 地面 | `Movement_Floor_1000m`，引擎 Cube，1000 × 1000 米，厚 1 米，顶面 Z=0 |
| 碰撞 | Static，`BlockAll`，`WorldStatic`，QueryAndPhysics，Pawn 为 Block；Cube 简单盒碰撞 |
| 地表 | `/Game/Map/Materials/M_MovementGrid`，世界坐标 5 米棋盘与网格，粗糙度 0.85，无贴图依赖 |
| 出生点 | 唯一 `PlayerStart_Movement`，位置 (0,0,150) cm，Yaw=0 |
| 光照 | Movable DirectionalLight（10）、SkyAtmosphere、实时 SkyLight（1） |
| World Settings | GameMode Override = `/Game/BP/GamePlay/BP_GameMode` |
| Experience | 复用 `/Game/System/Experiences/DA_Experience_Default` |
| PawnData | 复用 `/Game/Characters/Player/Pyrios/DA/DA_Pawn_Pyrios` |
| 玩家 | `/Game/BP/Character/Player/BP_PC_Pyrios`，原 InputConfig、MovementSet、相机与 ABP |
| 关卡形式 | 独立普通地图，5 个场景 Actor；无 World Partition、导航网格或 AI 测试接线 |

```text
Open L_Movement_Test → Play
BP_GameMode.InitGame → Experience
HandleStartingNewPlayer → SpawnSquadForPlayer
  空 Roster 且无存档编队 → Experience.SquadMembers
  PlayerStart(0,0,150) → Slot + BP_PC_Pyrios → Possess
IA_Move → HeroComponent.Input_Move → AddMovementInput
  CMC → Cube 简单碰撞 → 地面顶面 Z=0
```

普通地图集中保存五个 Actor，避免移动测试依赖主场景流送和外部 Actor 包。GameMode 必须保留有效 Experience；丢失装配引用会导致没有可控角色。保存过的玩家编队仍按 GameMode 原有优先级覆盖默认编队。

## 2026-09-29 PIE 证据

UE 5.8.1 的真实 InViewPort PIE 正常生成并附身 `BP_PC_Pyrios_C_0`。通过 `EnhancedInputLocalPlayerSubsystem.inject_input_vector_for_action(IA_Move)` 注入轴值，经过原输入回调和 CMC；没有传送角色或写入速度/步态来伪造移动。

- 总采样 38.0018 秒、4513 帧：1 秒静置、31 秒向前、3 秒反向、3 秒松开。
- 全部采样 `grounded=true`、`MOVE_WALKING`；胶囊中心 Z 始终约 90.15 cm，没有持续下坠。
- Walk 首次出现于 1.0123 秒，Run 于 2.5183 秒，两者相差 1.506 秒。
- 32 秒反向输入后依次记录 Turning（32.0113）、Braking（32.3363）、RunOut（33.053）；最终 Yaw=180°。
- 最远 X=325.96 米；稳定曲线跑速约 10.50 米/秒，峰值 15.43 米/秒。从中心到边缘按稳定速度估算约 47.6 秒。
- 最终网格材质和灯光修正后重新启动 PIE，确认地面、角色与天空可见且玩家正常落地；材质 D3D_SM6 编译成功，不再使用失败后的默认材质。

证据：工程 `AAADocs/Movement_Test_Verification.json`、`AAADocs/References/Movement_Test_PIE.png`。完整逐帧采样在本机 `Saved/LevelDesign/movement_runtime.json`（忽略的运行产物）。创建与验证脚本分别为 `AAADocs/Scripts/create_movement_test_level.py`、`AAADocs/Scripts/verify_movement_test_level.py`；通过 UE Python 控制台执行，验证脚本须在本关卡 PIE 中运行，完成后恢复后台节流设置。

当前结论限于本机单人 PIE 和 InputAction 注入。物理键盘操作、联机预测、边缘跌落、导航和流送未在本轮验收；TurnBack 的动作美术质量由 Movement/Animation 后续专项评估。
