### CMC 私有职责与原生生命周期

`GGYGOMovementPrediction.h/.cpp` 提供原 Owner 同步值、SourceCheckpoint、SavedMove／MoveData／Response；Scope 的发行、nonce／generation、就绪与输入准入仍归 CMC。SavedMove 只保存原 move，wire 版本及 ForceWalk 的 `FLAG_Custom_3` 保持，文件迁移没有新增协议权威。

`FGGYGOActionMotionExecution` 是 CMC 的按值私有成员 `ActionMotionExecution{*this}`，由两个原生构造入口绑定同一 CMC；仅内部动作操作持有原资源与观察者，外部沿 CMC 既有入口请求。`RetireCompletedResource／Close` 将已脱离的委托捕获保留到原外层操作返回时才析构，真实外调后的弱对象／原资源重验继续保留。Profile／Montage 共享一个动作槽，native RMS 唯一持时间，CMC 原生移动入口唯一执行胶囊；拆分不是第二执行器。

| StartStop | `WalkStartEnd` | 原 Sequence，非循环 |
| WalkStop | `WalkEnd` | 原 Sequence，非循环 |

`FGGYGOLocomotionSourceBindingPtr` 是共享 const 快照。弱引用标识原 Producer／Character／Mesh；强资产引用只随 publisher／当前绑定及既有有界 SavedMove／Origin／Input 生命周期保留。代际表示身份与配置变化，不是播放时间。状态 `Available／Missing／Invalid／Stale` 与定位原因明确分开。

| --- | --- |

`NativeInitializeAnimation／NativeUpdateAnimation` 沿原入口观察 owner、mesh、主 AnimInstance 和配置变化；反初始化／生命周期重置退休原发布。消费者不通过当前动画对象为 SavedMove 临时重解析或收养后继。

## 正式 MovementSet 分发与只读查询

[[System/结构|System]] 在同 GI 原生 Manager 登记既有 InitState 顺序；[[Character/结构|PawnExtension]] 到 DataInitialized 后沿唯一 `ApplyPawnDataToConsumers → CMC.SetMovementSet(PawnData.MovementSet)` 分发。GameplayReady 是组件初始化结果，不发行移动输入资格。

| 接口 | 输入、输出与边界 |
| --- | --- |
| `SetMovementSet(InMovementSet, OutError)` | 校验并接受原配置，恢复基线／重置自身 Locomotion。非法非空数值明确拒绝；nullptr 是合法解绑，返回 false 且错误为空。不结束独立 ActionMotion。任何实际 setter 提交会关闭未提交配置的初始化暂态；拒绝／解绑的明确事实保留给 steering 查询，Reset 不重新打开等待。 |
| `GetMovementSet() const` | BlueprintPure 只读返回实际 accepted 配置／nullptr；请求的 DA 不等于已接受结果。 |
| `ValidateMovementSet(OutError)` | 校验原 16 项非废弃标量，并调用 `GGYGOLocomotionSteeringEvaluation::ValidateConfiguration` 校验显式启用的 steering。成功不要求七个旧 Profile；编辑器校验复用同一规则。 |
| `GetSpeedForGait`／`GetSanitizedWalkToRunHoldSeconds` | 读取原数值；后者保留旧名称但不再偷偷钳制、替换或修复配置。 |

仅显式 `bUseCurveDrivenSpeed=false` 使用 WalkSpeed／RunSpeed。曲线模式需要独立合格来源，缺失或求值失败不改成固定模式。七个废弃 UPROPERTY 及 `GetProfileForMotion` 保留兼容；旧 `UGGYGOLocomotionMotionProfile` 纯求值和 `FGGYGOAnimCurveSampler` 仅供历史工具／测试，不在当前 CMC 生产链。

## 纯求值与普通移动提交

`UpdateCharacterStateBeforeMovement → TryUpdateLocomotion` 使用同一原生 move 的输入／接地／配置／禁止标记和原请求，捕获 Candidate → ResolveGait → UpdateWalkRunBlend → 选择段。普通段成功才 Commit；失败不推进候选语义、时间或周期。连续保持达到配置阈值后由 Walk 升 Run；ForceWalk、释放、离地、禁止与配置重置按既有规则清保持计时。

| 纯接口 | 输入 → 输出／约束 |
| --- | --- |
| `ValidateSource(Source, Error)` | 原 Sequence 身份、路由、正有限 RateScale／PlayLength、当前元信息和四个运行曲线 `RootMotion_Speed／RootMotion_DirX／RootMotion_DirY／RootMotion_Yaw`；`HasCurveData` 明确检查缺曲线。 |
| `ValidateBinding(Binding, Error)` | Available、五个非循环单段、循环 BlendSpace1D、0..1 X 轴及实际样本／速率／长度一致；当前拒绝 single-frame／mirror 样本，旧 Profile 引用不能使来源合格。 |
| `EvaluateSingleInterval(Source, t0, t1, Scale, Out, Error)` | move 秒 × SequenceRateScale 映射 clip 秒，`EvaluateCurveData` 读取 t1 Speed／Dir、区间累计 Yaw；速度换算为真实时间速率。Scale 仅缩放速度，不缩放 Yaw。 |
| `EvaluateWalkRunInterval(Binding, StartCycle, ActualDt, Alpha, Scale, Out, Error)` | 原 `GetSamplesFromBlendInput(FVector(Alpha,0,0))` 得权重，`GetAnimationLengthFromSampleData` 得原生周期；末周期为 start＋dt／period，各原样本按 cycle×length 求值并作长度／周期速率换算。先求各源，再混合速度向量和区间 Yaw，输出混合幅值／方向及末周期。 |

同次求值中，公开 SingleInterval 独立验证原 Source；WalkRun 的 CMC 查询先核 publication／生命周期，紧接公开 EvaluateWalkRunInterval 完整验证 Binding 一次，再由私有 `SampleValidatedInterval` 读取已经验证的样本。Action 区间沿 Animation 既有 MapMontageInterval 完整验证来源，再检查 Movement 必需执行曲线。没有跨帧 Valid 缓存或公开跳过校验入口，原生执行边界仍实时认证。

输出与错误在入口 Reset，全部成功才写局部结果。合法零速、微小正值、Scale=0 及相反向量抵消为零都保留；负速、非有限、正速缺有效方向明确失败。方向以最大分量缩放归一化，不按小值容差清零。

WalkStart／WalkRun 经原生 `GetMaxSpeed／CalcVelocity／PhysicsRotation／MoveAlongFloor` 执行。BlendSpace 查询是在 CMC 的 move 上下文中做原生纯计算，未读取最终 AnimGraph 的滤波缓存、marker 历史或姿态；混合累计 Yaw 不是平移积分。

## WalkRun 普通转向与只读完成区间

本机制属于普通接地移动，接在既有 CMC 执行入口。原合格请求、输入、Set 和动画来源仍决定能否执行；Turning／Braking、Stop 的 CurveRMS、Action／最后贡献 drain、独立或未知根运动、混合区间、代理及无输入区间不发行普通 steering 表现资格。RunOut 只有在原区间实际交回普通执行后才适用，Camera／Animation 不重判相位。

当前 Pyrios 专用 Set 的 `SteeringAngleResponse` 为 Linear 六键 `(0,0)、(15,0.07)、(45,0.22)、(90,0.7)、(135,1)、(180,1)`，`SteeringMinYawRate=0`、`SteeringMaxYawRate=1440°/s`、`SteeringRunAngularRateScale=0.75`；Walk 增益仍为1。仅这四项角色配置变化，其余28项序列化属性保持，C++ 默认值和共享默认 Set 沿用原配置。旧 min90 的末级限幅使 Run 小角度落在同一90°/s平台，旧 max720×Run0.5又限制大角度预算。修正后15°／120°的 Run 预算为75.6／972°/s；这是上限计算，实际响应仍受原生摩擦／加速度与碰撞影响，量化事实见上面的当前验收入口。

两次执行分别取真实误差：`CalcVelocity` 用前一水平速度 heading→已准入 Acceleration heading；`PhysicsRotation` 用当前胶囊 heading→完成 Velocity heading。两者复用同一配置求预算，不共用镜头偏角；Camera 与 Animation 仍只消费实际速度轨迹导数。

| 实际接口 | 输入 → 作用、输出与清理 |
| --- | --- |
| `ValidateConfiguration(Set, Error)` | 显式 disabled 为正常模式；enabled 须朝向移动、有限角速度上下界／正增益及覆盖 0..180° 的必需响应曲线，至少两键、Y∈[0,1]。非法配置返回原 Set 路径和原因，不创建默认曲线。 |
| `EvaluateAngularBudget(Set, SignedErrorDegrees, WalkRunBlendAlpha, NativeDeltaSeconds, OutBudgetDegrees, Error)` | 绝对角误差查响应；上下界插值×原 Alpha 连续增益，再限到 authored 界限、乘实际 dt，预算至多180°。实时求值也拒绝 cubic 超界／非有限；详见 [[计划_移动与动作位移#14.1 无状态角预算与真实执行|公式与参数含义]]。 |
| CMC `CalcVelocity` → `ConstrainPlanarHeading(PreviousVelocity, NativeVelocity, StartingYawDegrees, BudgetDegrees)` | 先保同一子区间原 Velocity，再调用 Super；以原速度方向追赶原生新方向，首个无速度端用真实胶囊朝向。只约束方向，保持 Super 的水平幅值和 Z；摩擦、制动、碰撞仍走原生。错误恢复同一子区间原动量并拒绝原请求。 |
| CMC `PhysicsRotation` → `ComputeOrientToMovementRotation` | 原动作／曲线旋转分支先执行；普通资格下以真实 Velocity 为朝向目标，用胶囊→速度误差计算同类角预算，临时交 Super 原旋转入口，返回后清预算。不另加 Actor transform 写入者。 |
| `BeginLocomotionSteeringInterval` → `OnMovementUpdated(dt, OldLocation, OldVelocity)` | Before 捕获原 entry yaw／实际控制归属；native 旋转完成后发布 serial、frame、dt 和两端实际导数。整区间有接管／混合就正常不适用；历史 replay 不发布新的 live 样本。 |
| GT `GetLocomotionSteeringSnapshot() const` | 返回四状态的值快照；重验原 Character／CMC／UpdatedComponent、accepted Set／原 Source、epoch及结果。仅当前或上一引擎帧可消费；native correction／replay 或实际速度／Yaw 被替换后正常不适用，身份／依赖失效明确 Invalid。frame 只界定观测有效期。 |

`ActualSignedYawRate` 是胶囊 ΔYaw／native dt；`ActualSignedVelocityYawRate` 是 `OldVelocity → completed Velocity` 的水平 heading ΔYaw／dt，UE 右为正。胶囊追转和轨迹转弯可以反号：胶囊60→40°、速度30→40°。Camera 外侧与 Animation 倾身消费后者；两个速度端需有限且非零才有 `bHasVelocityYawRate=true`，零速初始端不伪造“零转向观测”。`DesiredDirectionError` 是已准入输入 heading 相对完成胶囊的误差，现有 `LocalVelocityAngle` 仍表达真实速度相对 Actor 的偏角。

| `EGGYGOLocomotionSteeringStatus` | 含义与消费 |
| --- | --- |
| Initial | 合法原配置初始化尚在途，或 accepted 依赖尚无完成区间；保持初始构图／中性姿态，没有有效导数或移动准入。 |
| Valid | 整个完成区间属于原普通 steering；有合法速度两端时消费实际轨迹导数，否则只正常回收表现。 |
| NotApplicable | 显式关闭、接管／混合／无输入、正常过期或 native 校正替换结果；各消费者平滑回收自身表现量。 |
| Invalid | 原生命周期、必需配置／源或数值契约失败；带定位诊断。Animation 清展示并暴露失败；Camera typed failure 传播到原发布门禁，不能自动重启。 |

### 原配置初始化的窄边界

Anim 注册可能早于 Extension 注册，Hero 的 DataInitialized／输入装配也会在 Extension 原同步推进中先调用 Camera Ready。未提交 Set 且从未执行 native 区间、原对象有效、Extension 尚未 DataInitialized 时，构造／BeginPlay 前允许 Initial；BeginPlay 后只在 Character 的 `IsPawnDataInitializationInProgress() const` 为真时允许。该接口由原 `CheckDefaultInitialization`／`ApplyPawnDataToConsumers` 调用栈 scope 提供，验证原 Extension／Pawn／World，返回／EndPlay 立即关闭，不持第二 Ready、timer 或状态顺序。

任何 Set 提交（包括拒绝或明确解绑）、实际 native 区间、初始化调用返回或 DataInitialized 完成均关闭未绑定等待。仅停在 Spawned／DataAvailable 标签不能无限 Initial；有错不能假装初始化中。合法同步暂态不推进相机 Ready 等待移动输入，也不绕过 CMC accepted 配置准入。R2 冷启动根因与严格复跑见 [[计划_移动与动作位移#14.5 整链验收与剩余边界|本次验收]]。

Stop、UpdatedComponent／Owner 生命周期退役、输入失效、Set／Locomotion Reset、原来源发布／退休及 EndPlay 清原观测和旋转 scratch，提升 source epoch；消费者在源 epoch／模式／动画生命周期变化时清自己的展示滤波。未新增调度器、运动时钟、复制速度权威或 Action／TurnBack 执行链。

## 原请求失败与 Input 消费

### 显式Cold／Rearm消费（C38）

`BindMovementInputSession／ConsumeMovementInputFact／InvalidateMovementInputSession` 仅接受原 Binding、完整 Kind／Mode／Proof 和事件布局，输出 Recorded／Duplicate／Stale／Rejected。Cold 一次首 Started 窗口在配置／执行失败前耗尽；异常恢复须真实 Released→Neutral→新 Press。同 Event 全 payload 相同才 Duplicate；旧 Request 搭高 Event 仍 Stale，不污染水位。零 Acceleration、Reset、换配置、ASC Ready 或重复 Started 不清 FAILED、不自动重试。

### 原执行失败与退休

普通求值失败 → `RejectLocomotionEvaluation(originalSerial, Error)`；native Prepare 失败 → `ReportLocomotionCurveRootMotionFailure(Origin, Reason)` → 既有 `FailLocomotionRequest`。原号精确失败，0 号不补执行请求；旧来源只退休自身，不失败／清后继。诊断带模块、对象、配置／资产和原因，沿原请求节流，不每帧重复报错。重力、资源释放和独立 Action 生命周期保持。

### 新请求准入与原生动量

没有合格来源、配置或活执行请求时，`GetMaxSpeed()` 仍返回 0，新 Acceleration、RequestedVelocity、无归属 RMS 不能驱动地面移动。已经由原生物理产生的速度可以继续原生摩擦／制动；它不等于新输入请求、曲线成功样本或固定速度模式。

| 原生入口／记录 | 输入、作用与清理 |
| --- | --- |

| `UpdateVelocityBeforeMovement` | UE `PerformMovement` 已直接应用 Override，尚未 `StartNewPhysics`。拒绝的 Override 用本区间的物理前快照撤销全部 XYZ 贡献；只有已有动量资格才保留地面速度。快照消费即清，不能从旧帧缓存恢复速度。此处不要求尚未置位的 `bMovementInProgress`。 |
