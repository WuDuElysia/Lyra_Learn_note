## 原生移动Owner同步（M2：已编译，M3／Hero1待接）

### 接口、原订阅与清理

CMC唯一拥有原生Owner范围及server generation；Input唯一发行真实Press／Held／Release／Session。Scope／Observer／Notice是同一CMC的同步与订阅资源，不是第二执行器或输入状态机。Pawn／PC／Connection／NetDriver、原CMC寿命／范围／nonce须匹配；原生生命周期负责发行及退休，配置／回放／输入值不签代际。

| 接口与输入 | 作用、输出与生命周期 |
| --- | --- |
| `GetMovementOwnerSyncScope(OutScope, OutError) const` | bool；取当前活原Scope或明确定位失败。获得Scope不是Ready，更不是运动许可。 |
| `SubscribeMovementOwnerSync(OriginalScope, Observer, OutObserver, OutError)` | bool；验证原Scope，先安装原记录并写出OutObserver，再同步回放当前Notice。回调收到原ObserverId＋Notice；回放后不改写输出。true只表示曾安装，回调可能已退休原范围，调用方须重验原身份。 |
| `UnsubscribeMovementOwnerSync(OriginalObserver, Reason, OutError)` | bool；仅关闭／注销原记录并释放其回调。在途Invalidated派发仍能精确取消尚未调用的原订阅；嵌套派发不借后继范围清理，没有历史订阅库。 |
| `TryAdmitInitialMovementInputRequest(OriginalObserver, OriginalBinding, OriginalSourceRequest, OriginalReadyNotice, OutError)` | **M3仅声明，尚未实现。** 后续一次准入仍须原Observer／Binding／Source请求／当前ReadyScope、nonce及Notice精确匹配；AlreadyAdmitted不再执行，ExecutionFailed保留原Failed。Hero1先用Source查询真实仍Held，不能因Ready补Press。 |

范围退休先从当前槽移除，再发布Invalidated；派发资源在所有退出路径封闭尚未调用记录。EndPlay先封闭在途terminal回调／原生入口，清自身执行及订阅资源后退休原Scope；迟到通知不得借当前后继对象清理。

### Owner v2：原move到Ready

1. `FSavedMove_GGYGO::SetMoveFor`捕获原Scope／nonce／客户端当时已知generation；Clear清自身。PostUpdate、PrepMoveFor及响应不把新Ready代号补到旧move。
2. `ClientFillNetworkMoveData`复制该原捕获；MoveData的OwnerSyncWireVersion为2。M1 SourceCheckpoint仍为独立v1事实运输，字段不等于服务端输入准入。
3. 实际packed容器的原`ServerMove_PerformMovement`调用进入`MoveAutonomous`，原生已接受timestamp／正delta及PC就绪后，CMC核对原数据指针、Pawn／PC／连接及原nonce，取得M2唯一server owner generation的原receipt；回放指针或序列化值本身不签证明。
4. `ServerFillResponseData`只把匹配原PendingAdjustment timestamp的receipt写入v2 Response，覆盖ACK及correction；没有新RPC／第二帧调度器。
5. `ClientHandleMoveResponse`核对原Scope／PC／端点／nonce／代际，完成native ACK／correction全部处理并返回后，才发布Ready。陈旧响应不升级原Scope；真正owner更替退休旧范围，不能取得首次Cold资格。

**Ready仅表示Owner同步就绪。** 当前Started仍走既有Admitted路径，唯一Waiting／TryAdmit与认证checkpoint／回放消费属于未实施M3；Hero1的原Observer持有、真实Held查询和一次TryAdmit待接。正常首次同步等待原Held请求、Failed／重绑／真实owner更替仍真Release→Press的已确认政策保持。真实输入资格不由CMC、Ready或速度反推。

| 私有`ConsumeLocalAbilitySystemNotice(ExpectedSubscription, Notice)` | Ready核对原opaque／Owner、Extension真实Ready和ASC当前PublishedContext；新opaque才替换既有ASC派生缓存并调用原ResetLocomotionState。同opaque重复Ready、Refreshed不Reset，Refreshed须已消费同资源。Released仅匹配原opaque，不要求已撤出的资源Ready或ASC仍活，晚R不清S。 |

## Profile 纯求值与当前消费边界

`EvaluateInterval` 输入 CMC 选定的起止时间，返回 `bool` 并输出样本；第四参数为可选 `FString* OutError = nullptr`，现有三参数调用仍可使用。入口清空 `OutSample` 和可选错误，全部校验成功后才提交局部候选；失败返回字段/曲线及原因，输出保持 Reset，不写运行时日志。

合法零速度成功并保留 0；负速度、非有限数据/求值/派生结果、正速度无有效方向明确失败，不替换为零或前向。Speed/Direction 在 EndTime 采样，Yaw 返回累计角和区间差；合法单键常量、非循环时间钳制和循环浮点边界修正保留。

每次 `EvaluateInterval` 都全量调用同一个 `ValidateProfile`：检查 Duration、键时间/数值/切线、启用权重、合法枚举和区间覆盖。Profile 无跨帧缓存、播放时钟或失败生命周期；绑定时验证与热路径成本尚待后续独立评估。

C37 已编译并将纯数学接入生产。单段／双 Loop 失败不推进候选时间、相位或转身，不取单侧样本、固定速度或将缺依赖视为完成。Gate44 无执行来源失败、Gate45 抽象身份对象 ensure 失败均保留；之后 Gate46 原 `AuthorityAndMapping` Success／0 诊断只证明当时合成来源消费者。后继本地RMS实际区间／原move回放于2026-10-03交回编码／有限静态接受；当前已随Gate69R1／Gate70编译，七份生产Profile资产已保存、默认引用已接并经冷回读校验。原生区间／回放专项、MoveData服务端输入认证／完整网络接续及当前Run／ABP动态仍未验，M3／Hero1待实施。

### 原生区间如何映射与提交

Before 的 `TryUpdateLocomotion` 对 Stop／TurnBack 调 Stage，先保存原候选并挂源，不按整个 DeltaSeconds 提前求值该 RMS。引擎调用 RMS `PrepareRootMotion(SimulationTime,MovementTickTime,...)`，RMS 再请求**原** CMC 的 Prepare：

```text
t0 = MotionTimeOrigin + (Source.GetTime() - SourceTimeOrigin)
t1 = t0 + SimulationTime
EvaluateSingleInterval(原 Set 的原段 Profile, t0, t1, 原 Scale, ...)
OverrideVelocity = Rotate(原 BaseYaw, 缩放终点速度／方向)
                   * (SimulationTime / MovementTickTime)
```

有限正 tick、合法零 SimulationTime、原 group／Input／配置／标量都须核对；partial／zero／catchup 按实际区间进入接口，不制造整帧预算。Speed／Direction 保留 t1 端点采样，Yaw 保留累计角与区间差，TurnBack 按实际 SimulationTime 推进；**这不是精确平移积分**。实时 Prepare 成功由 CMC Consume 一次提交，RMS 仅把原结果速度放入 RootMotionParams、设置原生结束时间／标志；胶囊碰撞仍由原生 CMC 执行。

`HasUsableSpeed` 仍判断正常 Brake／RMS 的速度幅值，不用于证明成功来源。合法低速结束或离地返回当前动量与 Finished；不能将配置／求值失败当作正常结束。原生 Prepare 遍历期间只标记退场，不结构性移除数组；旧贡献用 Additive identity 退自己的资源，独立 Action／动画 Root Motion 优先级保持。自然结束记录 Completed Origin，剩余 clip 语义走普通 CMC 路径，不重新挂同一物理源。

### SavedMove 回放、失败与网络边界

`SetMoveFor` 保存起始语义；`PostUpdate` 保存本 move 的原 Input／Prepared 并限制合并。`PrepMoveFor` 先调用 `BeginLocomotionCurveReplay` 安装原输入／结果与借用的 SavedRootMotion group，再调用 native `Super::PrepMoveFor`；之后清准备期 group 借用。原生 Prepare 重算或保留的原 Prepared 在 Before 经 Consume 一次提交；原 move 没有准备区间时不由整帧 dt 制造一次模拟。普通非 RMS 重演仍沿语义基线求值，权威校正时间沿原 Response 契约。

失败只在核对原当前 Origin 后进入既有 `FailLocomotionRequest`；当前 FAILED 不被历史 Candidate 重开，旧原资源不失败或清后继。`RetireLocomotionCurveRootMotion` 精确处理同一 Origin 的 Current／Pending；Reset、EndPlay 及 `EndLocomotionCurveReplay` 释放原引用／回放上下文，独立 Action 清理权不变。

Clone 保留原共享引用；Matches／UpdateStateFrom 拒绝本地 Origin 不匹配。NetSerialize 沿原基类与 BaseYaw／SpeedScale／bEndOnZeroSpeed wire 字段，**加载时清本地 Origin／Prepared 与诊断节流**。当前只认证本地签发来源；导入身份无法证明时明确拒绝，不能把 wire 未扩展写成 authority／proxy 匹配、服务器校正或完整网络兼容已关闭。

## WalkRun 与停止分支接线

Boss 显式动作曲线接口独立见 [[Movement/动作曲线执行]] 与 [[GGYGO_流程_动作曲线执行.canvas|执行子图]]。Locomotion 的 Profile、时间与 RMS 只处理普通移动段；切换/置空 MovementSet 只清理 Locomotion 自有 RootMotionSource，不结束 ActionMotion 持有的资源。

```text
EnterMove：WalkStart（不循环）
  RemainingRatio <= 0.03 → Moving.WalkRun
WalkRun：X = WalkRunBlendAlpha（0 = Walk，1 = Run）
  当前 ABP 仍经 StateMemory.GaitBlendY 兼容字段传入
Stop：StartStop / WalkStop / RunStop → StopValue 0 / 1 / 2
```

公开命名统一为 `WalkRunBlendAlpha`。`GaitBlendY` 只因现有 AnimBP 已序列化该成员而保留，蓝图显示名为 `Walk Run Blend Alpha`；不得用于新 API、Profile 或 BlendSpace 轴命名。实际输入仍接 X。单次动画必须关闭播放器循环，否则剩余时间条件可能在回绕时被跳过。

`GA_Dodge` 当前仅占位；`RequestRunOnNextMove()` 是 CMC 预留接口，尚无调用方。闪避正常结束、取消和无输入的处理留到统一 GAS 实施时接入，当前不能写成已具备“闪避后直接跑”。
