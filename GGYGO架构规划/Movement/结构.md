实际来源为 `/Game/BP/Anim/ABP_Pyrios` 的原 `FZZZAnimSet`。语义路由指向既有字典键；Walk／Run Loop 从实际 BlendSpace 样本取得，不另建 Loop 资产表。

| StartStop | `WalkStartEnd` | 原 Sequence，非循环 |
| WalkStop | `WalkEnd` | 原 Sequence，非循环 |
| RunStop | `RunEnd` | 原 Sequence，非循环 |

| WalkRun | `walkRun` | 原 `BS_Pyrios_WalkRun`，循环；样本携带 SequenceRateScale 和独立 SampleRateScale |

`FGGYGOLocomotionSourceBindingPtr` 是共享 const 快照。弱引用标识原 Producer／Character／Mesh；强资产引用只随 publisher／当前绑定及既有有界 SavedMove／Origin／Input 生命周期保留。代际表示身份与配置变化，不是播放时间。状态 `Available／Missing／Invalid／Stale` 与定位原因明确分开。

| --- | --- |

| CMC 来源查询／`ValidateBinding` | 曲线执行需要 Available、当前身份及合法原资产；失败进入原请求诊断。显式固定模式没有来源 resolver 是正常可选能力缺席，不无条件报错。 |

`NativeInitializeAnimation／NativeUpdateAnimation` 沿原入口观察 owner、mesh、主 AnimInstance 和配置变化；反初始化／生命周期重置退休原发布。消费者不通过当前动画对象为 SavedMove 临时重解析或收养后继。

## 正式 MovementSet 分发与只读查询

[[System/结构|System]] 在同 GI 原生 Manager 登记既有 InitState 顺序；[[Character/结构|PawnExtension]] 到 DataInitialized 后沿唯一 `ApplyPawnDataToConsumers → CMC.SetMovementSet(PawnData.MovementSet)` 分发。GameplayReady 是组件初始化结果，不发行移动输入资格。

| 接口 | 输入、输出与边界 |
| --- | --- |
| `SetMovementSet(InMovementSet, OutError)` | 校验并接受原配置，恢复基线／重置自身 Locomotion。非法非空数值明确拒绝；nullptr 是合法解绑，返回 false 且错误为空。不结束独立 ActionMotion。 |
| `GetMovementSet() const` | BlueprintPure 只读返回实际 accepted 配置／nullptr；请求的 DA 不等于已接受结果。 |
| `ValidateMovementSet(OutError)` | 校验 16 项非废弃标量的有限性、非负与范围；成功不要求七个旧 Profile。编辑器校验复用此规则。 |
| `GetSpeedForGait`／`GetSanitizedWalkToRunHoldSeconds` | 读取原数值；后者保留旧名称但不再偷偷钳制、替换或修复配置。 |

仅显式 `bUseCurveDrivenSpeed=false` 使用 WalkSpeed／RunSpeed。曲线模式需要独立合格来源，缺失或求值失败不改成固定模式。七个废弃 UPROPERTY 及 `GetProfileForMotion` 保留兼容；旧 `UGGYGOLocomotionMotionProfile` 纯求值和 `FGGYGOAnimCurveSampler` 仅供历史工具／测试，不在当前 CMC 生产链。

## 纯求值与普通移动提交

`UpdateCharacterStateBeforeMovement → TryUpdateLocomotion` 使用同一原生 move 的输入／接地／配置／禁止标记和原请求，捕获 Candidate → ResolveGait → UpdateWalkRunBlend → 选择段。普通段成功才 Commit；失败不推进候选语义、时间或周期。连续保持达到配置阈值后由 Walk 升 Run；ForceWalk、释放、离地、禁止与配置重置按既有规则清保持计时。

| 纯接口 | 输入 → 输出／约束 |
| --- | --- |
| `ValidateSource(Source, Error)` | 原 Sequence 身份、路由、正有限 RateScale／PlayLength、当前元信息和四个运行曲线 `RootMotion_Speed／RootMotion_DirX／RootMotion_DirY／RootMotion_Yaw`；`HasCurveData` 明确检查缺曲线。 |
| `ValidateBinding(Binding, Error)` | Available、五个非循环单段、循环 BlendSpace1D、0..1 X 轴及实际样本／速率／长度一致；当前拒绝 single-frame／mirror 样本，旧 Profile 引用不能使来源合格。 |
| `EvaluateSingleInterval(Source, t0, t1, Scale, Out, Error)` | move 秒 × SequenceRateScale 映射 clip 秒，`EvaluateCurveData` 读取 t1 Speed／Dir、区间累计 Yaw；速度换算为真实时间速率。Scale 仅缩放速度，不缩放 Yaw。 |
| `EvaluateWalkRunInterval(Binding, StartCycle, ActualDt, Alpha, Scale, Out, Error)` | 原 `GetSamplesFromBlendInput(FVector(Alpha,0,0))` 得权重，`GetAnimationLengthFromSampleData` 得原生周期；末周期为 start＋dt／period，各原样本按 cycle×length 求值并作长度／周期速率换算。先求各源，再混合速度向量和区间 Yaw，输出混合幅值／方向及末周期。 |

输出与错误在入口 Reset，全部成功才写局部结果。合法零速、微小正值、Scale=0 及相反向量抵消为零都保留；负速、非有限、正速缺有效方向明确失败。方向以最大分量缩放归一化，不按小值容差清零。

WalkStart／WalkRun 经原生 `GetMaxSpeed／CalcVelocity／PhysicsRotation／MoveAlongFloor` 执行。BlendSpace 查询是在 CMC 的 move 上下文中做原生纯计算，未读取最终 AnimGraph 的滤波缓存、marker 历史或姿态；混合累计 Yaw 不是平移积分。

## 本地 CurveRMS 原资源与实际区间

| 原资源／接口 | 输入 → 产物／唯一提交 |
| --- | --- |
| `StageLocomotionCurveRootMotion(tick, Candidate, Error)` | Stop／TurnBack 捕获原 Origin＋move Input，挂既有唯一 CurveRMS；不提前按整帧 dt 求值或提交 RMS 时间。 |
| `FGGYGOCurveRootMotionOrigin` | 原 CMC、Set、输入 Binding／InputRequest／执行号、段序列、不可变 SourceBinding、时间锚点、入口 yaw／scale。共享存活不等于仍有效，使用时重验原关系。 |
| `FGGYGOCurveRootMotionMoveInput` | 原 Origin、StartCandidate、Acceleration、tick 与接地／禁止／ForceWalk 等事实；一次原 move 的派生快照。 |
| `PrepareLocomotionCurveRootMotion(Source, sim, tick, OutPrepared, Error)` | native RMS 用原 Source 时间及实际 SimulationTime 请求原 CMC；核对原 group／Input／绑定／请求，求值原 Sequence 区间并生成完整 Candidate、Sample、OverrideVelocity 和结果。 |
| `ConsumeLocomotionCurvePrepared(Prepared)` | 验证同一原结果，去重一次 Commit；Prepared 不是另一份权威状态、时钟、准入或 FAILED。 |
| `FRootMotionSource_GGYGOCurve::PrepareRootMotion` | 调原 CMC Prepare 后仅安装返回的 Override 速度、native 时间／状态；碰撞、移动模式和胶囊位移仍由 CMC 原生物理执行。 |

实时区间：`t0 = MotionTimeOrigin + (SourceTime − SourceTimeOrigin)`，`t1 = t0 + SimulationTime`。终点速度向量旋转到世界基准后乘 `SimulationTime／MovementTickTime`；TurnBack 按实际区间推进并使用扫掠朝向。合法零模拟区间保留，partial／catchup 不伪造整帧预算；此算法不是精确平移积分。

Stop 自然结束要求正模拟区间且**原求值 Sample.Speed 恰为 0（施加 RootMotionScale 前）**；正的小幅 Sample.Speed 或 Scale=0 不触发此结束条件。TurnBack 另按真实阶段结束。正常离地／已结束返回原动量，完成资源不重新挂载。Prepare 遍历期间只标记退场，不结构性修改源数组；旧源只退出自身贡献，Action／其他根运动权限沿原仲裁。

### SavedMove 原绑定与权威校正

1. `SetMoveFor` 捕获原输入检查点、Owner Scope／nonce／generation、语义基线和不可变 SourceBinding；`PostUpdate` 保存原 Input／Prepared。来源变化或相关 RMS move 限制合并，`PostUpdate_Replay` 不覆盖原记录。
2. `PrepMoveFor` 在 native Super 前 `BeginLocomotionCurveReplay` 安装原记录及借用的 SavedRootMotion group；结束回放、Clear、Reset／EndPlay 清各自引用。原 Prepared 存在却缺匹配原 native source 时明确拒绝，不能改查当前 group。
3. **权威校正按 authority Candidate.MotionTime 基线重新求值实际 native 区间**；旧 Prepared 只供原区间元信息，旧 Candidate／速度不能作为校正结果。`bReplayPreparedFromAuthority` 确保只消费重算结果，沿同一 Prepare／Consume 提交。
4. Clone 保留原共享引用；Matches／UpdateStateFrom 拒绝本地 Origin 不匹配。NetSerialize 现有 wire 保持，加载清本地 Origin／Prepared；**网络导入 Origin 尚未认证**，完整 owner／server／proxy 仍未验。

Gate91 Stop 校正的 `0.4 → 0.416`、speed `292`、原 Prepared 时间 `0.016`／引用不可变断言均通过。该夹具在原记录边界捕获实际 native group，模型仍是本地未 possessed authority；不能推导正式自主客户端或完整网络通过。

## 原请求失败与 Input 消费

### 显式Cold／Rearm消费（C38）

`BindMovementInputSession／ConsumeMovementInputFact／InvalidateMovementInputSession` 仅接受原 Binding、完整 Kind／Mode／Proof 和事件布局，输出 Recorded／Duplicate／Stale／Rejected。Cold 一次首 Started 窗口在配置／执行失败前耗尽；异常恢复须真实 Released→Neutral→新 Press。同 Event 全 payload 相同才 Duplicate；旧 Request 搭高 Event 仍 Stale，不污染水位。零 Acceleration、Reset、换配置、ASC Ready 或重复 Started 不清 FAILED、不自动重试。

### 原执行失败与退休

普通求值失败 → `RejectLocomotionEvaluation(originalSerial, Error)`；native Prepare 失败 → `ReportLocomotionCurveRootMotionFailure(Origin, Reason)` → 既有 `FailLocomotionRequest`。原号精确失败，0 号不补执行请求；旧来源只退休自身，不失败／清后继。诊断带模块、对象、配置／资产和原因，沿原请求节流，不每帧重复报错。重力、资源释放和独立 Action 生命周期保持。

### 新请求准入与原生动量

没有合格来源、配置或活执行请求时，`GetMaxSpeed()` 仍返回 0，新 Acceleration、RequestedVelocity、无归属 RMS 不能驱动地面移动。已经由原生物理产生的速度可以继续原生摩擦／制动；它不等于新输入请求、曲线成功样本或固定速度模式。

| 原生入口／记录 | 输入、作用与清理 |
| --- | --- |
| `UpdateCharacterStateBeforeMovement`／`BeginNativeMovementVelocityInterval` | 以同 Character／UpdatedComponent、有限且与上次实际结果相符的地面速度开启当前区间；Before 退出时保存当前实际速度，供本 move 的物理前准入使用。 |
| `UpdateVelocityBeforeMovement` | UE `PerformMovement` 已直接应用 Override，尚未 `StartNewPhysics`。拒绝的 Override 用本区间的物理前快照撤销全部 XYZ 贡献；只有已有动量资格才保留地面速度。快照消费即清，不能从旧帧缓存恢复速度。此处不要求尚未置位的 `bMovementInProgress`。 |
| `CalcVelocity`／`ApplyRootMotionToVelocity` | 拒绝新驱动并保留生产诊断；有实际动量时暂时屏蔽 Acceleration、RequestedMove、ForceMaxAccel／RVO，让 Super 执行原生制动，再还原请求字段。Walking／NavWalking 因 Override 跳过 Calc 时，在拒绝 Apply 处补执行一次原本跳过的制动，不应用该 RMS。 |
| `UpdateCharacterStateAfterMovement`／实际已接受的 native correction | 在外部 movement-update 委托前记录真正物理结果；校正只观察已由原生接受的实际速度，不采用待接受 payload。owner／component 或原区间失效不能认证后继。 |
| Stop／取消／组件更换／EndPlay | 显式 Stop、精确动作清水平余速、实际 UpdatedComponent 更换及 EndPlay 使对应派生记录失效；Before／After 界定有界生命周期。外部重写同一个数值不能借已停止结果重新获得资格。 |

未知 RMS 的资源仍归原执行者；Movement 拒绝其贡献，不移除他人的源。合法独立 Action／实际动画 RootMotion 保持原仲裁。该机制沿原 CMC 的帧调度和请求失败状态工作，未新增缓存速度执行链、Tag 步态权威或网络协议。

## 本地 ASC 身份订阅

CMC 私有记录仅持弱 Extension、原 DelegateHandle 和已消费 opaque Resource，作为派生缓存；[[Character/结构|PawnExtension／ASC]] 保持资源与发布权威。

BeginPlay 原 `CacheAbilitySystemComponent → PrepareLocalAbilitySystemSubscription` 一次注册 `RegisterLocalAbilitySystemNoticeAndCall`；同步回放前持原记录，晚返回只接收或归还原 Handle。Ready 核对原 Owner／真实 Ready／PublishedContext，新 opaque 才 Reset；同资源重复 Ready／Refreshed 不 Reset，晚 Released 只清匹配原 opaque。移动禁止查询沿 `GetReadyLocalAbilitySystemComponent() const` 读取 CantMove；无 Ready 是原合法暂态，不发行输入或替代速度。

EndPlay 先封闭原 native／Owner 在途入口、退休自身 CurveRMS／回放引用，再精确 Release ASC 原订阅、失效 Input 和原 Scope，最后 Super。清理不撤后继或独立 GA 句柄；订阅不是曲线时钟或请求资格。生产接线已编译，独立动态专项仍未验。

## WalkRun、AnimBP 与独立 Action

`ABP_Pyrios` 的 Walk／Run 在同一 BlendSpace1D，X=0 Walk／1 Run；CMC 的 `WalkRunBlendAlpha` 经 Animation 兼容映射到旧序列化 `StateMemory.GaitBlendY`。StopMotionType 映射 StopValue 0／1／2，既有 EnterMove／WalkRun／Stop／TurnBack 拓扑保留。Moving 内层 Entry→WalkRun 的只读事实不代表整个 ABP 绕过 EnterMove。

公共接口规范名为 `WalkRunBlendAlpha`；`GaitBlendY` 与 `walkRun` 仅因原资产兼容保留。轴显示名保存仍未获得本轮证据。**本轮未迁移 Player／Evaluator 播放相位，不承诺表现与 CMC 同时钟或无脚滑。** Gadge／GA_Dodge／Gadget 保持占位；`RequestRunOnNextMove` 无调用方，后续统一 GAS 时由用户明确动作结束语义。

当前 PlayerCombo：原 Task 播放快照＋Animation 原 Main SourceBinding → `BeginMontageActionMotion` → 同一 ActionCurveRMS 的 OriginalMontage 模式 → 原生 Walking／NavWalking／Falling 执行 XYZ。Main 在场抑制普通 Locomotion／自动旋转；End 以 `ReleaseMontageActionMotion(..., Completed)` 结束原 Main，保留尚未消费的最后 Prepared 贡献。GA 查询／订阅 `QualifiedMovementIntent`；End 入场时已有 Held 或 End 内新合格 Press 都可经 `CancelMontageActionMotionForMovement` 精确打断，并由原输入／CMC 恢复 Walk→Run。步态验收读 `GetResolvedGait()`／`GetWalkRunBlendAlpha()`，不以 WalkLoop／RunLoop Tag 代替 CMC 权威。

坐标和清理契约详见 [[Movement/动作曲线执行]] 与 [[Movement/GGYGO_流程_动作曲线执行.canvas|动作子图]]。旧 `BeginActionMotion(Profile, PlayRate)`／`EndActionMotion(Handle)` 仍是明确的服务器地面业务 Profile 模式；未将它作为原 Montage 缺依赖时的替代。MovementSet 变化不结束独立 Action。Animation 的 `GGYGOActionPoseSlot`／必需 Pose 契约只管身体姿态，GA／Task 管其生命周期与失败，均不写胶囊。
