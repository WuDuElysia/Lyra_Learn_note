## 10. 移动层（D3）：现行方案

### 10.1 根因与决定

旧方案把原动画曲线复制到七份 Locomotion Profile，再以独立 Walk／Run 表混合，形成两个可编辑来源；MovementSet 的数值规则与动画来源资格也混在同一校验。用户已选择直接使用原动画源，混合曲线可接受；本轮取消七份副本作为生产来源并实际退役。

现行链路：

```text
Animation 原 AnimSet／Sequence／BlendSpace
  → 原生命周期发布不可变 SourceBinding
  → CMC 验证原身份、来源与请求
     普通 WalkStart／WalkRun：纯求值 → Commit → native Physics
     Stop／TurnBack：Stage 原资源 → native Prepare 实际区间
                     → 原 CMC 求值／Consume → RMS 安装速度 → native Physics
  → 提交后的只读 AnimationStateFrame → 既有 AnimBP 表现
```

源解析不持移动时间，CMC 不读取当前 AnimGraph 曲线／姿态缓存。MovementSet 持有移动规则与普通转向响应配置，原动画仍是运行速度曲线唯一来源；ActionMotionProfile 是独立业务动作资产。没有新增状态机、Tick 或备用曲线执行链。完整接口输入／输出与清理见 [[Movement/结构#动画唯一来源与发布生命周期|来源发布]]、[[Movement/结构#本地 CurveRMS 原资源与实际区间|原资源执行]]。

### 10.2.1 原生 Owner 同步与首次准入分层（M2／M3／Hero1）

M2／M3／Hero1 已接入并编译，动态网络未验。CMC 唯一发行原 Scope／nonce／server generation；Input 唯一发行物理事实。Subscribe 先安装原 Observer 再同步 Replay，Unsubscribe 精确注销；SetMoveFor 捕获原代际，packed move 经 native 验证后产生 receipt，ACK／correction 全部返回后 Ready。

Ready 只表示同步就绪。Hero 查询原 Source 仍 Held 后，以原 Observer／Binding／Request／ReadyNotice 调 TryAdmit 一次；AlreadyAdmitted 不重执行，ExecutionFailed 保留失败。正常首次等待原 Held；失败、重绑与真实 owner 更替仍须真实 Release→Press，不补 Press／Neutral。接口和清理见 [[Movement/结构#原生移动 Owner 同步|Owner 同步契约]] 与 [[Input/结构|Input 来源]]。

### 10.3 原 Sequence 与原生 BlendSpace 求值

单段来源为原 `WalkStart／WalkStartEnd／WalkEnd／RunEnd／TurnBack` Sequence；WalkRun 路由保留原 `walkRun`，Loop 来源为 `BS_Pyrios_WalkRun` 的实际样本。必须核对原资产身份、长度、SequenceRateScale、独立 SampleRateScale、循环语义和 `RootMotion_Speed／RootMotion_DirX／RootMotion_DirY／RootMotion_Yaw` 四运行曲线；当前 single-frame／mirror 样本明确拒绝，不读取副本或给缺失来源选默认动作。

单段按 move 秒 × SequenceRateScale 映射 clip 秒。t1 读取 Speed／Dir，Yaw 计算区间累计角，速度换算实际播放速率；Scale 只缩放速度。非循环末端按原 clip 范围，循环跨周期累加 Yaw。输出原子提交，合法0／微小正值保留，正速缺方向与负／非有限结果明确失败。

WalkRun 算法：

1. 原 BlendSpace `GetSamplesFromBlendInput(FVector(Alpha,0,0))` 查询实际权重；`GetAnimationLengthFromSampleData` 取得含 authored rate 的原生周期。
2. CMC 传 start cycle 与实际 dt，数学层算 end cycle＝start＋dt／period；每个实际源映射 cycle×PlayLength，速度按 length／period 换算。
3. 先分别求各源，再按原生权重混合速度向量，最后求混合幅值／方向；区间 Yaw 按源累加后混合。向量抵消为0是合法结果，不是动作结束。
4. CMC 成功后提交周期与样本；错误不提交候选、不借单侧源替代、不回落固定速度。

这使用原生 BS 的纯采样／周期接口，不承诺与 AnimGraph 最终滤波状态、marker 同步或 Player 相位相同。算法细节见 [[Movement/结构#纯求值与普通移动提交|纯求值契约]]、[[Animation/曲线处理|源资产与表现边界]]。

#### 10.3.1 Stop／TurnBack：原资源、实际区间与权威重算

Stage 记录原 SourceBinding、Set、请求／执行号、段序列、入口 yaw／scale、时间锚点和原 move Input；只挂既有 CurveRMS，不提前提交整帧时间。native Prepare 在原 group 中认证原资源，实时映射 `t0=OriginMotion+(SourceTime−OriginSource)`、`t1=t0+sim`，原 CMC 纯求值、推进 TurnBack 并唯一 Consume。

OverrideVelocity 为世界端点速度 × sim／tick；不是精确平移积分。Stop 自然结束要求正 sim 且原求值 Sample.Speed 恰为0（RootMotionScale 前），正的小幅 Sample.Speed 或 Scale=0 不使其提前完成；TurnBack 按既有阶段结束。零模拟区间不制造预算，正常离地／完成保留动量；Prepare 遍历时只标记退场，不结构性移除数组。

SavedMove 保留原绑定／Input／Prepared，PostUpdate_Replay 不覆盖原件。BeginReplay 在 native Super 前安装原记录；原 Prepared 存在却缺原 native source 时拒绝，不改查当前组。**authority replay 根据 authority Candidate.MotionTime 和原 actual interval 重算**，旧 Prepared 只提供区间元信息，不能直接提交旧速度／Candidate。Gate91 原0.416／292／Prepared不可变断言通过。

Clone 保留本地原引用，NetSerialize 既有 wire 不扩展、加载清本地引用。网络导入 Origin 未认证；本地 authority 夹具不证明正式 owner／server／proxy。Clear／EndReplay／Reset／EndPlay 精确释放自己的资源，不解除 FAILED，不清后继／Action。

### 10.4 唯一状态、失败与 ASC 生命周期

CMC 持有 Gait、hold timer、WalkRunBlendAlpha、motion time／cycle、TurnBack phase、执行号和 FAILED；横向速度／接地等派生事实来自 CMC。ASC 持有动作 Tag／能力状态。Animation 只消费只读事实，不另设 Idle／Moving 权威状态。

Input Consume 校验原 Binding 与完整 Mode／Proof／Event：首 Cold 窗口一次耗尽，精确重复不重执行，陈旧请求不提升水位。Released／Neutral 不清失败，合格新 Press 才发行新执行请求。纯求值错误与 native Prepare 错误均精确失败原请求并退自己的贡献；配置重置、零加速度或同请求重放不自动恢复。

原生已有动量不发行新请求。无合格来源／配置时 GetMaxSpeed 仍0，Acceleration／RequestedMove／未知RMS显式拒绝；同角色／胶囊的实际已完成结果可继续 Super 制动。UE直接 Override 发生在物理前，因此当前 move 的 Before快照在 `UpdateVelocityBeforeMovement` 消费，不能要求仅 `StartNewPhysics` 内才置位的 bMovementInProgress；物理内资格仍要求该标志。Stop／实际组件更换／原动作清水平余速／EndPlay使派生记录失效，不删除他人RMS。接口与实际根因见 [[Movement/结构#新请求准入与原生动量|动量边界]]。

ASC 身份消费沿原 BeginPlay 一次 Prepare 订阅 → 原 Ready opaque 派生缓存 → const Getter 查询 CantMove；同 opaque 重复 Ready／Refreshed 不 Reset，晚 Released 不清后继。EndPlay 封闭原执行／在途入口，再退 CurveRMS／回放、释放原订阅／输入／Owner Scope。订阅资源不是曲线时钟或移动准入。见 [[Movement/结构#本地 ASC 身份订阅|ASC 资源]]。

### 10.5 蓝图接线、名称与占位

现有 Walk／Run 是一张 BlendSpace1D：X=0 Walk／1 Run。CMC 持续推进 WalkRunBlendAlpha；Animation 将其映射到原 StateMemory.GaitBlendY，StopMotionType 映射 StopValue 0／1／2。EnterMove、Moving 内 WalkRun、Stop、TurnBack 的现有拓扑保留，不为 Walk 和 Run 再建独立状态。

公开字段／新接口采用 `WalkRunBlendAlpha`；旧 `GaitBlendY` 与字典键 `walkRun` 因资产兼容保留。BlendSpace 轴显示名保留旧名，本轮未迁移。播放器／Evaluator 相位未迁移，本轮不能写成“与 CMC 同钟”或“脚滑已解决”。

Gadge／GA_Dodge／Gadget 按用户要求只占位；RequestRunOnNextMove 尚无调用方。闪避结束、取消、无输入及下一次移动语义留待用户统一 GAS 实施时讲解；本轮不推定闪避后直接跑已接入。

## 13. 独立动作位移：现行接口与后续方案

### 13.1 现行 GA → CMC 契约

Locomotion 原动画曲线、当前普攻原 Montage Position曲线与显式业务 ActionMotionProfile各有用途。GA管原动作及Handle，Task管原播放／必需Pose资源，Animation管源绑定、身体姿态与窗口，Movement执行胶囊；不由混合表现曲线反向取得执行权。

`UGGYGOActionMotionProfile` 定义累计位移（cm、秒、Mesh Component 空间、首帧0）、Duration／TranslationScale。GA 选资产／Montage／PlayRate → `BeginActionMotion(Profile, PlayRate)` 校验并返回精确 Handle → ActionCurveRMS 差分累计轨迹、冻结入口 Mesh 基准 → CMC 物理执行。`EndActionMotion(Handle)`、自然结束／离地只清该资源。活跃 Action 暂停 Locomotion／自动旋转，配置解绑不结束 Action。

上述 Profile仍是服务器地面XY模式，未作为原动画失败后的替代。当前PlayerCombo通过 `BuildSourceBindingRange` 绑定完整Main→End，使用原Task实例／当前段位置／固定速率调用 `BeginMontageActionMotion`；原累计PosXYZ逐源／loop差分，经固定入口Actor旋转、捕获MeshScale和业务Scale一次，交同一RMS的OriginalMontage模式。进入End不换Handle／时钟／基准；取消IgnoreZ并沿原生敏感离地、Walking／NavWalking／Falling碰撞／重力／落地执行。

原Task认证作者单点信号，GA在原Scope／Handle就绪后调用 `EnableStepInterruption`，才查询／订阅QualifiedMovementIntent；过点时已有Held／门后新Press均须合格物理证明。门持续到本次播放结束，新播放重新关门；Main／End不自动授权，CMC不持攻击门、阶段或连段政策。`CancelMontageActionMotionForMovement` 只清匹配原资源的水平余速、保空气Z／后继；原输入继续交CMC普通Walk→Run。原Task非Interrupted BlendOut调用 `NotifyMontageActionNaturalBlendOut` 认证原末段混出窗口；`ObserveMontageActionMotionCompletion` 只在最后原Prepared贡献经native移动和AfterMovement消费后通知原Handle。原Task Completed经 `ReleaseMontageActionMotion(..., Completed)` 接受有界Drain，成功返回不是消费完成；GA等两原事实闭合后自然结束。必需Pose缺失／失效明确中止原动作，不以其他Slot／Profile替代。详细参数、触发、清理与已保存ABP接线见 [[Movement/动作曲线执行]]／[[Movement/GGYGO_流程_动作曲线执行.canvas|动作流程]]；七DA退役不取消独立业务Profile。

### 14.1 无状态角预算与真实执行

新增 `Character/Data/GGYGOLocomotionSteeringEvaluation.h/.cpp` 为纯数学，`GGYGOLocomotionSteeringTypes.h` 定义 native 只读 DTO；CMC 持原区间 scratch 与有限完成样本，不新增方向状态机、Tick、timer 或第二执行器。

`EvaluateAngularBudget(Set, SignedErrorDegrees, Alpha, NativeDt, OutBudget, Error)`：

```text
response = SteeringAngleResponse(abs(error))                 // X角度，Y归一化响应
scale = lerp(WalkAngularRateScale, RunAngularRateScale, Alpha)
rate = clamp(lerp(MinYawRate, MaxYawRate, response) * scale,
             MinYawRate, MaxYawRate)                         // 度／秒
budget = min(rate * NativeDt, 180°)
```

| 配置／接口 | 作用、输入与输出 |
| --- | --- |
| `bEnableLocomotionSteering` | 显式选择普通转向模式，默认 disabled；enabled 配置必须朝向移动，缺配置不回退默认曲线。 |
| `SteeringAngleResponse` | `FRuntimeFloatCurve` 覆盖0..180°，至少两键、Y∈[0,1]；配置校验有限 keys／tangents／weights／插值类型、严格升序和端点。实时求值仍检查 cubic 超界。 |
| `SteeringMinYawRate／SteeringMaxYawRate` | 有限 0≤min≤max、max>0；原 dt 必须正有限，Alpha∈[0,1]，角误差∈[-180,180]，非法／溢出返回定位错误。 |
| `SteeringWalkAngularRateScale／SteeringRunAngularRateScale` | 有限正值，越大越快追上输入、曲率越弱；当前 Pyrios Walk=1、Run=0.75，C++ 默认仍为1／0.5。末 rate 仍受原上下界限制，不能把该增益误读成表现幅度。 |
| `ConstrainPlanarHeading(PreviousVelocity, NativeVelocity, StartingYaw, Budget)` | 同一 native 子区间原方向向 Super 新方向追赶，夹角受预算限制；保持 Super 水平幅值与 Z，无初速时使用实际胶囊朝向。 |
| `CalculateVelocityYawRate(OldVelocity, NewVelocity, NativeDt, OutRate)` | 仅有限、非零水平两端与正 dt 得实际 heading 导数；无观测返回 false，不伪造零转向事实。 |

CMC 原 `CalcVelocity` 保存该子区间旧速度后调用 Super，在原普通准入仍成立时应用角预算；原 Acceleration、曲线速度上限、摩擦／制动、扫掠／碰撞保持。失败恢复该子区间原动量并精确拒绝原请求。原 `PhysicsRotation` 先保 Action／TurnBack 分支，普通执行以完成的真实 Velocity 为胶囊目标，按胶囊→速度误差重求预算；`ComputeOrientToMovementRotation` 把目标与临时 Yaw 预算交给 Super，调用后清 scratch。两者共同产生真实弧线。

### 14.2 原区间发布、四状态与初始化契约

本机 native 顺序为 AfterMovement→PhysicsRotation→native RootMotion rotation→OnMovementUpdated。CMC 在 `UpdateCharacterStateBeforeMovement` 开原观测区间、保存 entry yaw及执行归属；只在 `OnMovementUpdated(dt, OldLocation, OldVelocity)` 发布真实完成结果。不能拿 AfterMovement 尚未旋转的 yaw 或原曲线整段 ΔYaw 当普通转向。

| 状态 | 真实边界与消费者行为 |

### 14.4 世界轨迹外侧投影（用户已选择／已实现）
