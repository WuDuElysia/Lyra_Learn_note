# System：结构与接口

> [[GGYGO_结构_System.canvas|结构图]] · [[计划蓝图|返回导航]]。本目录对应 `Source/GGYGO/System/`，提供公共语义键、共享资产启动快照和无状态 GE 类选择。

## 当前职责与所有权

| 类 / 数据 | 输入与职责 | 输出与边界 |
| --- | --- | --- |
| `GGYGOGameplayTags` | `UE_DEFINE_GAMEPLAY_TAG` 在模块加载时向 `UGameplayTagsManager` 注册原生键 | [[Input/结构|Input]]、[[AbilitySystem/结构|AbilitySystem]]、AI 与消息使用统一语义；不由项目 AssetManager 调用注册。 |
| `UGGYGOAssetManager` | 引擎实际持有的项目 Manager；读取 `GGYGOGameDataPath` 及 GameData 三项 GE 软配置 | 一次启动预载结果；独占本共享预载路径的四份 `UPROPERTY(Transient)` 强引用与逐项状态，不保存角色状态。 |
| `UGGYGOGameData` | 共享软配置：`DamageGameplayEffect_SetByCaller`、`HealGameplayEffect_SetByCaller`、`SelfDestructGameplayEffect` | 静态 getter 转发 Manager 快照；Damage/Heal 解析接口只选类，返回值可空，不施加 GE。 |

角色专属 AbilitySet/PawnData 由各自模块配置；GA/GE/AttributeSet 仍执行能力与数值结算，System 不建立第二套执行链。实际装配见 [[GameFeature/结构|GameFeature]]。

## 启动预载与读取契约

| 调用方 → 接口 | 输入 / 前提 | 作用与输出 |
| --- | --- | --- |
| 调用方 → `UGGYGOAssetManager::TryGet()` | 游戏线程，`GEngine->AssetManager` 已存在且类型匹配 | 返回引擎实际项目实例；线程不符、未就绪或类型不符则诊断并返回空。不会新建、Root 或替换 Manager。 |
| 引擎 → `StartInitialLoading()` | 首次游戏线程启动；配置 GameData 软路径 | 先调用父类建立资产索引，再同步预载 GameData 和 Damage/Heal/SelfDestruct 三 GE；重复调用不重入或重试。 |
| 调用方 → `HasCompletedSharedAssetPreload()` | Manager 已取得，游戏线程 | 表示整次预载尝试已结束并可读，包括失败；**不是四项全成功**。非游戏线程或尚未完成返回 false。 |
| 调用方 → `GetGameData()` / `GetSharedDamageGameplayEffect()` / `GetSharedHealGameplayEffect()` / `GetSharedSelfDestructGameplayEffect()` | 游戏线程，整次预载已完成 | 返回已持有的对象/GE 类或空；完成前及非游戏线程返回空。只读，不加载、重试或刷新。 |
| 调用方 → `GetGameDataLoadState()` / `GetSharedDamageLoadState()` / `GetSharedHealLoadState()` / `GetSharedSelfDestructLoadState()` | 同一读取门禁 | 返回该项冻结状态；门禁未满足返回 NotReady。 |
| 调用方 → `UGGYGOGameData::Get()` / 三个同名 `GetShared…GameplayEffect()` | 共享读取限游戏线程 | 先 TryGet，再转发 Manager 对应 getter；Manager 不可用则返回空，不另存快照。 |

Manager 通过 `LoadedGameData`（`TObjectPtr`）及三项共享 GE（`TSubclassOf`）的 `UPROPERTY(Transient)` 维持 GC 可追踪强引用，随 Manager 生命周期管理，无手动 Root、按类 Map 或通用 `LoadGameDataOfClass` 加载器。一次预载全部尝试结束后才发布完成标记，加载回调期间 getter 不暴露部分快照。某项 GE 失败不阻止另两项；失败也保留在启动结果中，运行 getter 不重试。

| `EGGYGOSharedAssetLoadState` | 实际含义 |
| --- | --- |
| `NotReady` | 整次启动尝试尚未完成，或当前不在允许读取的游戏线程。 |
| `NotConfigured` | 本项软路径为空；GameData 与每项 GE 分别判断。 |
| `LoadFailed` | 本项路径非空但加载失败或类型不符。 |
| `DependencyUnavailable` | GameData 不可用，无法读取 GE 配置；三 GE 未尝试加载。 |
| `Ready` | 本项已加载并由 Manager 强引用保持；其它项仍可能失败。 |

## Damage / Heal 显式选择

`UGGYGOGameData::ResolveDamageGameplayEffect(EffectOverride, bUseSharedWhenUnset)` 与 `ResolveHealGameplayEffect` 接收 GE 类覆盖和**必须显式传入、无默认实参的 bool**。二者不加载、不缓存、不施加 GE；共享读取仍遵守游戏线程和启动快照门禁。

| 覆盖 / bool 输入 | 作用与输出 |
| --- | --- |
| 覆盖非空，bool 任意 | 直接返回覆盖，不访问 Manager。 |
| 覆盖为空，false | 返回空，不读取共享。 |
| 覆盖为空，true | 读取对应共享 getter；未就绪或缺失仍返回空，不选择其它 GE。 |

| 消费者 | 当前消费与可空处理 |
| --- | --- |
| [[AbilitySystem/结构|PlayerCombo]] | `DamageEffect` 与 `bUseSharedDamageEffectWhenUnset` 传给 Damage 解析；C++ 开关初始化 false。空覆盖＋shared=false 是显式无 GE 正常模式，满足原命中门禁、Builder 成功且 HitCueTag 有效时可保留 Cue；空覆盖＋shared=true 且共享缺失时，当前仍经无 GE 的 `BuildHitEffectPayload` 路径走 Cue，属于 **E14 必需依赖失败传播待修缺口**，有诊断也不视为正常模式，不推荐此路径，尚未修复。 |
| [[BossAI/结构|BossMelee]] | 配置校验与命中使用同一 Damage 解析，C++ 开关初始化 false；解析为空则校验失败，命中在 Builder 前返回，无 GE/Cue。这不改变非空类后 Spec 失败或 GE 被免疫的既有行为。 |
| [[Character/结构|HealthComponent]] | 非空 `SelfDestructEffectOverride` 优先；空时读取共享自毁 getter，仍空则在 Context/Spec/施加前返回。原死亡/Authority/Avatar 边界未由 System 扩改。 |

Heal 解析机制已实现，本批未新增治疗 GA 消费者。以上是源码配置与接缝事实，**未回读生产蓝图的实际开关值**，不能据 C++ 初始值声称资产已迁移。
