# System：结构与接口

> [[GGYGO_结构_System.canvas|结构图]] · [[计划蓝图|返回导航]]。本目录对应 `Source/GGYGO/System/`，是公共词汇和共享资产入口。

| 类 / 数据 | 关键接口 | 与其他模块的关系 |
| --- | --- | --- |
| `GGYGOGameplayTags` | 原生 GameplayTag 常量 | InputTag、Ability/Group、Restriction、State、Event、Cue 与 Message 的统一语义键；[[Input/结构]]、[[AbilitySystem/结构]] 等消费。 |
| `UGGYGOAssetManager` | `Get()`、`GetGameData()`、`StartInitialLoading()` | 从配置读取共享资产路径，启动时预加载，按类缓存；错误配置时记录错误并提供兜底 Manager，GameData 仍可能为空。 |
| `UGGYGOGameData` | `Get()`；伤害/治疗/自毁 GE 类引用 | 保存项目级、由 C++ 直接应用且不属于单一能力的 GE；调用方必须判空。 |

`UGGYGOAssetManager::StartInitialLoading` 先执行父类初始化再预载 GameData；`LoadGameDataOfClass` 使用同步加载和强引用缓存。伤害等不能等待的调用路径因此命中缓存。`UGGYGOGameData::Get()` 可为空，功能入口各自处理。角色专属 AbilitySet、PawnData 不放在这里。实际 GameFeature 装配见 [[GameFeature/结构]]。
